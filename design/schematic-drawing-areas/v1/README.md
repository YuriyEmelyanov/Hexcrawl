# Области рисунка на травянистом фоне

Два авторских шаблона по 210 × 210 px: вершиной вверх (`pointy`) и стороной вверх (`flat`). SVG содержат редактируемые слои `river-reserve` и `drawing-area`; PNG — просмотровые версии с теми же контурами. Внешние углы квадрата прозрачные.

Пунктир — предел всего рисунка, включая крайние кроны, ветви и тени. Цветная полоса — суммарный резерв на возможную реку по любому из шести рёбер, **не шесть реальных рек**. Между полосой и контуром оставлено 3 px чистой подложки.

Основа: текущая геометрия main@1962fb9a835a9c310e55c1a09415fe180f22cca9, `HEX_SIZE=28`, `getHexWidth(r)=sqrt(3)*r`, `getRiverWidth(w,f)=w*(0.04+0.035*f)`; река центрирована на ребре. F=5 даёт ширину 39.1010 px при масштабе тайла 210/56. Внутрь гекса входит половина: 19.5505 px. Отступ пунктира от ребра — 22.5505 px.

Гекс регулярный, внешняя описанная окружность R=105 px. Отступ вычислен перпендикулярно каждому ребру, включая безопасные углы. Вторая ориентация меняет геометрию контура, текстура остаётся вертикальной. Координаты и параметры — в geometry.json.

Универсальный запас по всем шести рёбрам оставляет 56.55% площади гекса для рисунка. Это консервативный шаблон для одного неизменяемого рисунка на все клетки. Увеличить область можно при динамическом учёте конкретных речных рёбер. У озёр, береговых выступов, нового масштаба или другой ширины рек нужен отдельный расчёт.

Шаблоны не подключены к карте. Подложки, рендерер, генерация и существующие файлы не изменены.
