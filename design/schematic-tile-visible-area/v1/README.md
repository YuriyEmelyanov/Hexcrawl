# Область рисунка биома на квадратном тайле

**Зафиксированное требование владельца:** весь рисунок биома должен целиком помещаться внутри светлого контура соответствующего гекса и не выходить за него. Это касается крайних крон, ветвей, рельефа, теней и декоративных элементов. Выходы рисунка за границу недопустимы; при отображении ни одна часть рисунка не должна обрезаться.

Два нормативных шаблона **210 × 210 px**, SVG и PNG: вершиной вверх (`pointy`) и стороной вверх (`flat`). В обоих случаях область — полный правильный гекс с шестью вершинами, без дополнительных прямоугольных срезов кончиков и без запаса под реку.

Базовый фон заполняет весь квадрат 210 × 210. Светлая область — допустимое размещение рисунка биома; затемнение за контуром — только подсказка для подготовки ассетов, не часть фонового материала и не оформление карты.

## Геометрия

Центр (105, 105), радиус описанной окружности 105 px. Площадь правильного гекса — **64.9519% площади квадратного PNG** в обеих ориентациях. Точные координаты и требования — в [geometry.json](geometry.json).

Для pointy гекс имеет ширину 181.8653 px и высоту 210 px. Для flat — ширину 210 px и высоту 181.8653 px. Картинка внутри композиции остаётся вертикальной.

## Требование к последующему подключению

При переключении ориентации рендерер обязан показать весь соответствующий гекс. Срезать боковые кончики горизонтального гекса узким прямоугольником изображения нельзя. Например, квадратный viewport изображения 2R × 2R с единственной обрезкой по полному гексу позволяет сохранить эту область при компенсации поворота картинки.

Эти файлы заменяют прежнюю диагностическую схему текущей обрезки: они задают требуемую область для дальнейшей подготовки рисунков. **Код приложения пока не изменён**, рендерер не переключён. Шесть базовых фоновых PNG сохранены без изменений. Шаблоны с резервом под реки ранее удалены по указанию владельца.
