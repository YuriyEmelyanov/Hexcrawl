# Видимая часть квадратного тайла — текущая отрисовка

Два шаблона **210 × 210 px**, SVG и PNG, на полном травянистом квадрате. Светлая часть картинки видна на карте; затемнённая обрезается. Тонкий светлый контур — фактическая граница видимой части. Рек и защитных отступов нет.

Описывается фактическая отрисовка режима «Тайлы» в main@1962fb9a835a9c310e55c1a09415fe180f22cca9 (`src/App.tsx`). Гекс R=28; изображение получает прямоугольник sqrt(3)*28 × 56 и `preserveAspectRatio="xMidYMid slice"`, затем обрезается clipPath гекса. Для квадратного PNG получается масштаб 56/210; прямоугольник в координатах исходника: x=14.0673…195.9327, y=0…210.

При обычной ориентации видимая область — правильный гекс вершиной вверх: **64.9519% площади PNG**.

При повороте карты на 90° картинка компенсируется поворотом -90°, но её прямоугольник шириной 181.8653 исходных пикселей остаётся вертикальным относительно зрителя. Поэтому боковые кончики горизонтального гекса дополнительно срезаются; видимая область имеет восемь вершин: **63.3975% площади PNG** (точное значение — в geometry.json). Эти срезы намеренно показаны как текущее поведение, не исправлены и не приняты как будущая норма.

Метод: пересечение геометрического контура гекса с прямоугольником SVG image, расчёт в координатах квадратного исходника. Отдельно проверена обрезка `xMidYMid slice` тестовым SVG с контрастным фоном и точками за прямоугольником. Файлы не подключены к отображению. Код приложения и шесть базовых фонов не изменены.

Предыдущие шаблоны `design/schematic-drawing-areas/v1` с резервом под реки удалены по указанию владельца.
