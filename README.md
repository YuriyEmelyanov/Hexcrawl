# Hexcrawl Region Generator

Добавлена базовая процедурная речная сеть:

- Река хранится как `River` и набор `RiverEdge` по граням между соседними гексами.
- Ключ грани нормализуется через `normalizeEdgeKey(hexA, hexB)` и не зависит от порядка гексов.
- Для региона при генерации поддерживаются:
  - продолжение существующей реки (если есть касание у точки присоединения);
  - генерация новой реки около `centralHex`;
  - вероятностные дополнительные русла/истоки по размеру региона.
- Реки сохраняются между шагами расширения карты и очищаются при сбросе.

## Запуск

```bash
npm install
npm run dev
```

## Проверка
