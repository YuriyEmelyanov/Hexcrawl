# Hexcrawl Region Generator

React + TypeScript + Vite приложение для пошагового расширения hexcrawl-карты регионами.

## Механика

1. На старте есть центральный гекс `0/0`.
2. Кнопка **«Сгенерировать регион»** доступна только для первого региона.
3. Размер каждого региона = `12dF + 1`, где каждый dF даёт `0..2`.
4. Регион строится как связная область без пересечений с уже занятыми гексами.
5. После генерации вокруг всей открытой карты вычисляются гексы-кандидаты.
6. Клик по гексу-кандидату добавляет новый регион через этот гекс (точка присоединения).
7. Точка присоединения обязательна для нового региона, но не является его центром.
8. Центр выбирается после генерации внутри гексов нового региона (предпочтительно более внутренний, с максимальной дистанцией до границы региона).
9. Все старые регионы сохраняются, кандидаты пересчитываются после каждого шага.

## Основные функции

- `generateDfRoll()`
- `getHexNeighbors()`
- `generateConnectedRegionFromAnchor(anchorHex, size, occupiedHexes)`
- `chooseRegionCenter(regionHexes)`
- `getCandidateHexes(allRegionHexes)`
- `addRegionToMap()`
- `resetMap()`

## Интерфейс

- Цвета:
  - регион;
  - центр последнего/любого региона;
  - точка присоединения;
  - гексы-кандидаты.
- По клику по гексу показывается:
  - `q/r`;
  - тип (`region`, `candidate`, `center`, `connection`);
  - номер региона;
  - был ли гекс точкой присоединения.
