# Hexcrawl Area Generator

Веб-приложение на React + TypeScript + Vite для генерации связной hexcrawl-области вокруг центрального гекса.

## Правила генерации

- Есть центральный гекс с axial-координатами `q=0`, `r=0`.
- При нажатии **«Сгенерировать область»** выполняется бросок **12dF**.
- Каждый dF даёт одно из случайных значений: `0`, `1`, `2`.
- Считается итоговая сумма броска `N`.
- Если `N = 0`, область состоит только из центрального гекса (размер = 1).
- Если `N > 0`, размер области равен `N + 1` (включая центральный гекс).
- Область всегда связная: новый гекс добавляется только рядом с уже выбранным.
- Алгоритм формирует случайное «пятно», а не идеальный круг.

## Реализованные функции

- `generateDfRoll()` — бросок 12dF, возвращает 12 значений и сумму.
- `getHexNeighbors()` — получение 6 соседей гекса в axial-системе `q/r`.
- `generateConnectedHexArea()` — генерация связной области нужного размера.

## Интерфейс

- Отрисовка центрального гекса и сгенерированной области на карте.
- Подсветка выбранной области.
- Отдельный блок с результатом 12dF (все 12 значений + итоговая сумма).
- Кнопка **«Сгенерировать область»**.
- Кнопка **«Сбросить»**.
