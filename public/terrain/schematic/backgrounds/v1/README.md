# Базовые фоны схематичной карты — v1

Подготовленные ассеты. К действующему отображению карты **не подключены**.
Переход на новый режим и его реализация — следующий отдельный этап после завершения графики.

Шесть отдельных непрозрачных PNG, каждый **210 × 210 px**, RGB/sRGB.
Фон заполняет весь квадрат. Обрезку по гексу выполняет рендерер.
Без рамок, деревьев, гор, камыша, берегов, дорог, POI и других условных знаков.
Текстуры вдохновлены картографической манерой Strategic View Civilization V;
это вновь сгенерированные изображения, а не извлечённые игровые материалы.

## Набор и согласованное назначение

| Файл | Фон | Применение | Средний цвет PNG |
|---|---|---|---|
| [grass.png](grass.png) | Травянистая | Открытые равнины и холмы; все живые леса и редколесья, включая горные, кроме заболоченного леса. | `#9DB063` |
| [stone.png](stone.png) | Серо-каменистая | Голые горы и все мёртвые леса/редколесья, включая холмистые и горные. | `#AFAA9D` |
| [swamp.png](swamp.png) | Болотная | Болото и заболоченный лес. | `#729079` |
| [sand.png](sand.png) | Песчаная | Полупустыня. | `#DFBD7A` |
| [lake.png](lake.png) | Озёрная вода | Все озёра. | `#86B6C5` |
| [sea.png](sea.png) | Морская вода | Всё море. Заметно темнее озёр. | `#45768F` |

Средние цвета измерены по финальным PNG, это описание набора, не ограничение каждого пикселя.
Густота и тип деревьев, рельеф, заболоченность и объекты добавляются отдельно.
Для горных живых лесов используется grass.png; для мёртвого горного леса — stone.png.
Заболоченный лес использует swamp.png. Море темнее озёр.

## Подготовка и проверка

Изображения созданы встроенным генератором изображений.
Точные запросы и параметры финальных файлов: [generation.json](generation.json).
Генерировался каждый фон отдельно. Финальный экспорт выполнен ImageMagick:
`magick INPUT -filter Lanczos -resize 210x210! -alpha off -colorspace sRGB -strip -define png:color-type=2 OUTPUT.png`.
После экспорта проверены PNG, 210×210, отсутствие прозрачности, различимость шести фонов и более тёмная морская вода.
В код, правила генерации, настройки отображения, существующие тайлы и deployment workflow изменений нет.

## Обязательная область рисунка

При дальнейшей подготовке рисунков биомов используем [два нормативных шаблона](../../../../../design/schematic-tile-visible-area/v1/README.md): полный правильный гекс в каждой ориентации, без срезанных кончиков. Весь рисунок (включая кроны, ветви и тени) должен целиком помещаться внутри соответствующего контура. Подложка заполняет весь квадрат 210 × 210. Шаблоны задают целевое требование; подключение рендерера будет отдельным этапом.

## Открытые холмы и горы — готовые тайлы

Четыре отдельных PNG **210 × 210 px** на соответствующих базовых фонах. Рисунок — мягкий светотеневой рельеф по присланному владельцем образцу Strategic View Civilization V, без толстой контурной обводки. Холмы — группа округлых возвышенностей, горы — основная вершина с боковыми склонами.

| Ориентация | Открытые холмы — grass.png | Горы — stone.png |
|---|---|---|
| Вершиной вверх | [open-hills-pointy.png](open-hills-pointy.png) | [mountains-pointy.png](mountains-pointy.png) |
| Стороной вверх | [open-hills-flat.png](open-hills-flat.png) | [mountains-flat.png](mountains-flat.png) |

Рисунок в обеих ориентациях остаётся вертикальным и целиком помещается в утверждённом правильном гексе. Масштабирование равномерное; склоны и вершины не обрезаны по маске. Подложка заполняет весь квадрат, за пределами рисунка исходный фон сохранён.

Проверены формат/размер PNG, отсутствие ненулевых пикселей слоя рельефа за контуром гекса, неизменность фона за контуром и визуальная различимость холмов/гор. Запросы генерации, параметры и SHA-256: [relief-generation.json](relief-generation.json). Рисунки созданы заново, материалы игры не извлекались.

**К рендереру эти четыре тайла пока не подключены.** Подключение и исправление прямоугольной обрезки при повороте остаются отдельным этапом.
