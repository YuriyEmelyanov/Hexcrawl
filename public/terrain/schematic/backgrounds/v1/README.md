# Подложки и рельеф схематичной карты — v1

Подготовленные ассеты. **К действующему рендереру пока не подключены.**
Все PNG — **210 × 210 px, RGB/sRGB без прозрачности**. Подложка заполняет весь квадрат; внешний контур гекса применяется при отрисовке.

## Текущий принятый рельеф — detail-v5

14.11.2026 владелец принял **detail-v5** и попросил заменить предыдущий вариант. Четыре основных файла без суффиксов заменены точными байтами соответствующих PNG этой версии:

| Ориентация гекса | Открытые холмы · травянистый фон | Голые горы · каменистый фон |
|---|---|---|
| Вершиной вверх | [open-hills-pointy.png](open-hills-pointy.png) | [mountains-pointy.png](mountains-pointy.png) |
| Стороной вверх | [open-hills-flat.png](open-hills-flat.png) | [mountains-flat.png](mountains-flat.png) |

Это цельные непрозрачные изображения фона и рельефа: подножия естественно переходят в землю по цвету и фактуре, крупные формы и гребни читаются, мелкая детализация сокращена. Повторное наложение отдельного слоя рельефа не требуется.

Фон внутри готового рельефного тайла согласован с соответствующей подложкой живописно; его пиксельное совпадение с отдельным базовым PNG не заявляется. У принятого detail-v5 холмы темнее и оливковее ранней версии blended-v3. Для живых горных лесов назначение остаётся **grass.png**, для голых гор — **stone.png**.

Текущий статус, основные имена и SHA-256: [accepted-relief-baseline.json](accepted-relief-baseline.json).
Проверенные параметры, запросы генерации и происхождение основных файлов: [relief-generation.json](relief-generation.json).
Исходные метаданные принятой версии: [relief-detail-v5-generation.json](relief-detail-v5-generation.json).

## Геометрия и область рисунка

Обязательны [два нормативных шаблона полного правильного гекса](../../../../../design/schematic-tile-visible-area/v1/README.md): вершиной вверх и стороной вверх, без дополнительного срезания кончиков и без расширенного отступа под реку.

Весь значимый рисунок — включая вершины, склоны, кроны, ветви и тени — должен целиком помещаться внутри соответствующего контура. В обеих ориентациях рисунок остаётся вертикальным. Фон заполняет квадрат 210 × 210 px; обрезка значимых форм по границе гекса недопустима.

Размер, RGB-формат и отсутствие прозрачности принятых PNG проверены. Целостность вершин, плавность перехода в фон и читаемость повторяющихся тайлов проверены визуально на картах в обоих положениях гекса.

## Предыдущие версии

Файлы с суффиксами `dense-v2`, `blended-v3`, `calm-v4` и исходные `detail-v5` сохранены для истории и сравнения. Они не заменяют текущие основные имена из таблицы выше. Их происхождение описано в [метаданных dense-v2](relief-dense-v2-generation.json), [blended-v3](relief-blended-v3-generation.json), [calm-v4](relief-calm-v4-generation.json) и [detail-v5](relief-detail-v5-generation.json).

Изображения созданы заново по согласованному картографическому ориентиру Strategic View Civilization V; материалы игры не извлекались. Код, правила генерации, настройки отображения и deployment workflow этой заменой не меняются. Подключение новой графики к карте будет отдельным этапом.
