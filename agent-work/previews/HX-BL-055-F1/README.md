# HX-BL-055 F1 — UI/карта P1 после интервью

Интерфейс не меняется: новых полей, кнопок и диалогов нет. Поэтому показанный владельцу P1 остаётся предложением для F1:

- [desktop.svg](../HX-BL-055-D1/desktop.svg)
- [narrow.svg](../HX-BL-055-D1/narrow.svg)

Уточнение после RW-Q01/RW-Q02: на схеме и в реализации меняется только отображаемая толщина рек в режиме 1 миля. POI, дороги, русла, озёра и переправы не перемещаются. Стыки с существующим берегом озера и производное оформление переправ пересчитываются только для рисунка.

Это схема из сохранённого fixture, не снимок React runtime и не доказательство приёмки. Следующий видимый результат — фактическое до/после на точном SHA.
