## Результат

Каталог позволяет найти и переименовать живые регионы, именованные поселения, реки, озёра и королевства. Поиск учитывает обе языковые формы; тип и координаты различают объекты. Кнопка рядом с именем в информации открывает тот же редактор.

Save записывает RU/EN одной общей транзакцией. Cancel/Escape и сохранение без изменений оставляют redo. При переходе с черновиком доступны Save/Discard/Stay; вопрос получает клавиатурный фокус. Остальные мутации защищены реальными обработчиками, экспорт и навигация доступны. Устаревшая форма и ошибка подготовки не перезаписывают новый мир. Схема имён, POI, заметки и геометрия сохраняются. Старое допустимое длинное имя королевства можно оставить без изменений.
