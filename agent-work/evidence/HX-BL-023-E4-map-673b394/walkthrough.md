# Фактический пользовательский путь — E4

Версия 673b39468a21fad89d44c05c9c6d32b6c1e83741; не опубликована, независимая приёмка впереди.

1. Нажать карандаш в информации о гексе. На карте существующие препятствия доступны для выбора; тот же объект можно выбрать строкой в «Рядом».
2. Для нового объекта нажать «Добавить препятствие». Шесть строк показывают соседей, доступность и принадлежность королевству. Доступные рёбра отмечены голубым пунктиром на карте.
3. Для переноса выбрать препятствие и «Перенести». Исходник остаётся сплошным жёлтым с тёмной обводкой до выбора новой цели. Выбрать ребро карты или строку списка; ID остаётся прежним.
4. После операции информационная панель открывается, фокус возвращается в строку. «Удалить» удаляет один объект; фокус переходит в «Рядом». Undo/Redo восстанавливает карту и счётчик.
5. Escape отменяет только выбор ребра. Done, начало другой правки, импорт/экспорт и история завершают незавершённый выбор без фиксации цели. Панорамирование/zoom/поворот не переносят объект.
