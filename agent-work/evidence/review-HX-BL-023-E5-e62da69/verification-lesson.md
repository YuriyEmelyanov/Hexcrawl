# Retained content versus entity owner

A river's global owner does not describe the footprint of every sector. Comparing both versions of the owner fixes identity relocation, but a newly created river has no checkpoint version and can still contain a sector assigned to a retained region. The last-region-only exemption must be justified from the affected content, not inferred from global owner alone.

The independent review confirmed R1/R2 and exact-tree CI, then reproduced the separate R3 through actual Add/draft/Finish handlers on one bounded valid-v7 fixture. Preserve that distinction: successful CI and fixed earlier findings remain valid evidence, while the new lost-retained-sector case requires a focused correction in the existing checkpoint lifecycle. No new broad audit or extra permanent runner is justified.
