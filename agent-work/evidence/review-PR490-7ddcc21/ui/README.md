## Последовательность

1. До: опубликованная E6 в просмотре и редактировании — переноса POI и команд региона нет.
2. После: E7 редактирует высоту/совместимый биом и передачу гекса через предварительный просмотр; `Готово` создаёт одну транзакцию, `Отменить` восстанавливает точный JSON.
3. E8 переносит обычную POI в пустой геометрический центр другого региона; после исправления F01 она остаётся обычной, не создаёт центральный дубликат и сохраняет обычный редактор.
4. Русское/английское имя хранится как единая авторская пара. Связанная с путём POI безопасно отказывает в переносе и показывает зависимость.
5. Устойчивые имена поддержаны для путей, препятствий, переправ, порогов и водопадов.

Каждый шаг сохранён в desktop 1500 px и narrow 390 px. Полный машинный перечень — `manifest.json`, принятый экспорт карты — `accepted-map.json`.

## Известные ограничения

- Морские имена исключены до появления устойчивого ID и контракта split/merge.
- Реальные центральные POI не переносятся; центр и якорь региона защищены.
- Для удаления авторски именованной POI требуется явная очистка имени.
- Публикация требует второго явного согласования владельца для точного проверенного пакета.
