## Статический путь и гипотеза
scripts/hx-bl-003-v2.mjs создаёт обе страницы заранее, обе держит открытыми, перед каждым действием импортируетJSON, ждёт data-render-phase=ready, дваrAF, fonts/assets и JSON export. Затем nav() меняет scroll, ждёт700ms и сразу начинает24wheel/rAF. Скрипт не ждёт окончания raster-cache capture и не записывает cache phase на zoom-start; единственный buffer=ready и heap записаны ПОСЛЕ zoom+pan. Idle context не приостанавливается, его timers/async work остаются активными.

src/App.tsx beginMapNavigation снимает is-navigating через180ms; zoom черезrAF меняет CSStransform/scroll, не React mapstate. src/rendering/viewportRasterCache.ts:
- scroll/style/class/resize вызывают schedule(prepare,250ms);
- prepare проверяет is-navigating только на входе; snapshot/inlineassets, SVGserialize, image.decode и drawImage идут асинхронно;
- уже начатая capture не отменяется при начале навигации (проверяется stopped при замене/cleanup);

Следовательно, ready/assets+700ms не доказывают отсутствие отложенного raster/export work или завершённую подготовку кэша. Расхождение истории idle/import/async capture — конкретная гипотеза ранних stall и порядка. Сами source paths одинаковы A/B; единственная runtimeправка — guard debugRivers вокруг derived vertex index. Это не доказывает, что guard не влияет косвенно через время/allocations.
