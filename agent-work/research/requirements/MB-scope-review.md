## Что выведено из принятого объёма

- **MB-SCOPE-C01 / out_of_scope**: Новый обязательный d12-режим вместо якобы d20 вMB. Существующий MB d12 подтверждён старым аудитом; ложная предпосылка не создаёт функцию.
- **MB-SCOPE-C02 / needs_owner_decision**: Принудительно точный размер вопреки первому региону/карманам. Предлагаемый альтернативный профиль не отменяет принятые исключения; вне принятого рабочего объёма.
- **MB-SCOPE-C03 / defer_L2**: Пересечение/обход барьера партией. Сохранение границыL1 остаётся; вычисление движения/способов преодоления относится кL2.
- **MB-SCOPE-C04 / needs_owner_decision**: Автоматически переназначать единственный Престол после ручной правки. Отдельная операция не принята; текущие ручные изменения не обязаны сохранять квоты.
- **MB-SCOPE-C05 / out_of_scope**: Обязательные номера мифов1–6впринятом интерфейсе. Источник сохраняется, но вариант продукта без номеров уже утверждён; не новый вопрос и не дефект.
- **MB-SCOPE-C06 / out_of_scope**: Движок Omens/сюжета мифов. Для пространственного размещения6мест не требуется; управление сюжетом исключено владельцем.
- **MB-SCOPE-C07 / needs_owner_decision**: UI заданного вектора квот/автоперебалансировка ручных правок. Квота начальной генерации сохранена; новая панель/ограничение не приняты.
- **MB-SCOPE-C08 / out_of_scope**: Обязательный промежуточный объект рыцаря/создание личности Провидца. Прямое разрешение имени для места достаточно проверенным цепочкам; персонажный движок не требуется.
- **MB-SCOPE-C09 / needs_owner_decision**: Произвольный N, округление и группировка многогранных барьеров. Принятая карта фиксирована144гексами; расширение не дефект текущего режима, источник не задаёт часть параметров.
- **MB-SCOPE-C10 / out_of_scope**: Фильтр активных мифов/обязательная связь руины→миф. Отозванная трактовка по прямому решению09.11; не восстанавливать.
- **MB-SCOPE-C11 / needs_owner_decision**: Автоматическое раскрытие по посещению. FAQ задаёт статическую авторскую практику, не протокол динамическогоreveal; нет принятой зависимости.

Описания конкретных руин и имя Провидца святилища сохранены как существующие принятые функции места. Из этого не следуют общий генератор NPC, развитие персонажей или движок сюжетов. Сырой ориентир N/6 не равен вероятности для каждой грани; текущая подготовка фиксированных 144 гексов и универсальный ввод N — разный объём. Номера мифов 1–6 остаются в исходном правиле, но не навязываются принятому интерфейсу.
