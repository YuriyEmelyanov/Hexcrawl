# MB: d12-группы местности из официального Realm Sheet

Источник: [страница издателя](https://chrismcdee.itch.io/mythic-bastionland), бесплатный Mythic Bastionland Realm Sheets.pdf, upload13049889, PDF1/Creating a Realm(p14)/Wilderness, первая строка. Визуально прочитано: группы d12гексов одного типа. Текстовый слой пуст; проверка по рендеру. SHA256 6082a760c7db9b81baf0180cae585feb35826b24e5feb839434c4ff33deb924d. Метаданные2024-11-07 не объявлены датой редакции; сверка с финальной книгой/Quickstart не выполнена.

Определить целевой размер группы исходом d12 и создать группу гексов одного выбранного типа. При достаточной свободной области получить ровно заданное число; сохранить результат без автоматического переброса.

Входы: выбранный тип; исходd12 — целое1…12гексов; достаточная свободная область и явно выбранный профиль. Выход: Группа из nгексов одного типа, n=1…12; при нехватке места цель и её недостижение различимы, прежнее содержимое сохранено.

- Источник задаёт d12-группы одного типа, но не алгоритм роста, выбор соседей или поведение у края.
- Связность — продуктовый перевод слова clusters; точная геометрическая/координатная процедура не специфицирована источником.
- Не отменять действующие запреты пересечений/дыр и другие ограничения ради размера; конкретное разрешение конфликта needs_product_decision.
- Не навязывать этот профиль всем существующим картам/режимам; текущий d20+XdF не изменяется исследователем.
- Равновероятность исходов d12 и проверка ввода — продуктовые критерии; выполненные тесты продукта отсутствуют.
- Сохранение/открытие/происхождение результата — продуктовая операционализация, не команда/API или схема хранения.

- **MB-REALM-001-L1-AC02**. Дано: Та же достаточная свободная область; T, d12=7. Действие: Создать группу. Ожидается: Получена связная группа из7гексов T; окружающая подготовленная карта не перегенерирована.
- **MB-REALM-001-L1-AC03**. Дано: Достаточная свободная область; T, d12=12. Действие: Создать группу. Ожидается: Получена группа из12гексов T; все12 имеют выбранный тип.
- **MB-REALM-001-L1-AC04**. Дано: Вместо исхода d12 переданы0,13 либо7.5. Действие: Попытаться применить размер по этому профилю. Ожидается: Ни один ввод не принят как корректный исход d12; группа не объявлена успешно созданной с некорректным размером.
- **MB-REALM-001-L1-AC05**. Дано: Выбран d12-профиль с равновероятными исходами; имеется нормированный случайный вход r. Действие: Для k=0…11 проверить равные интервалы [k/12,(k+1)/12) и их середины. Ожидается: Каждый интервал соответствует ровно исходу k+1; середины дают1…12, двенадцать равных исходов. Значение r=1 не считается обычным входом [0,1). Это критерий продукта, не проверенный алгоритм.

Ожидается: Существующие объекты не перезаписаны и запреты не обойдены; показано/сохранено, что цель12 не достигнута. Конкретное усечение/перенос/отказ остаётся решением аналитика, а не правилом источника.
