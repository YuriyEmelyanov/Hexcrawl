# Mythic Bastionland: Группы d12гексов одного типа местности

Ревизия 17 ноября 2026. Решение: **keep_L1**. Создание группы рельефа — принятая функция MB. Отдельный новый d12-режим из ложной предпосылки о d20 не нужен.

Источник: MB-OFFICIAL-REALM-SHEETS-SNAPSHOT-20261108; PDF1 right column Creating a Realm(p14), WILDERNESS first sentence only. Рисовать группы одного типа местности размером по d12гексов.

Параметры/исключения источника:

```json
{
  "size_die": "d12",
```

Связь с продуктом: Генерация области MB; расширение без потери карты.

Операция: тип местности; исход d12=1…12 гексов; доступная область

Входы: В свободном обычном случае исходы1/7/12 дают1/7/12 гексов одного типа; повторное открытие не перебрасывает результат..

Ожидаемый результат: Первый регион11/12, заполнение замкнутых карманов и обработка края следуют принятому профилю; правило книги не отменяет их.

Ограничения: undefined

Поддержка: **в этом запуске не перепроверена**. На SHA a246fdf292963fd534a8203f569b9ca48b6292c7 сохранено: В MB уже используется равномерная цель1–12. Проверенные свободные группы1/7/12 дают1/7/12.
