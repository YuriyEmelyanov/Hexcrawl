# PF2 Remaster: правила → функции карты → состояние поддержки

**Checkpoint. Полная сверка PF2 не завершена.** Названный корпус GM Core + Player Core целиком ещё не проверен на применимость; статусы unverified остаются открытыми. Исходные 63 строки сохранены, новый settlement-блок добавлен без перезаписи истории.

Новое решение: уровень поселения не задаёт площадь; стены >1000 — рекомендация; ассортимент допускает локальные исключения. Городская схема и карточка места — разные потребности. Для карточки предлагается общий механизм мест с игровым профилем; подробный городской редактор не утверждён.

Исследователь не добавлял задачи в backlog. Идентификаторы в таблице — ключи анализа, не новый реестр common-rules/game-bindings. Совпадение общего ID не означает реализацию.
