## Исходный смысл и текущая операция

### PF2-RM-DC-simple-v2

**Источник:** [GM Core pp.52–53](https://2e.aonprd.com/Rules.aspx?ID=2628); редакция GM Core Remaster English.

**Правило:** Простая DC выбирается по трудности задачи: untrained10/trained15/expert20/master30/legendary40. Этот ориентир обычно не требует самого ранга. Для опасных задач предпочтительнее DC по уровню.

**Решение:** out_of_scope. Общий калькулятор DC/рангов/уровней работы не требуется для создания карты. Отдельные нужные условия будущей навигации сохраняются в исходных L2-строках без принятия универсального движка.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-DC-level-v2

**Источник:** [GM Core pp.52–53](https://2e.aonprd.com/Rules.aspx?ID=2629); редакция GM Core Remaster English.

**Правило:** Можно задать DC по уровню предмета/препятствия или рангу заклинания вместо простой DC. Для металлической стены допустимы simple master30 либо уровень создателя15 и DC34. Это выбор ведущего, не масштабирование по партии.

**Решение:** out_of_scope. Общий калькулятор DC/рангов/уровней работы не требуется для создания карты. Отдельные нужные условия будущей навигации сохраняются в исходных L2-строках без принятия универсального движка.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-DC-adjust-v2

**Источник:** [GM Core pp.52–53](https://2e.aonprd.com/Rules.aspx?ID=2630); редакция GM Core Remaster English.

**Правило:** Коррекции DC −10/−5/−2/+2/+5/+10 относятся к задаче, а не бонусу персонажа. Uncommon/rare/unique обычно соответствуют+2/+5/+10. Разные навыки могут иметь разные DC. Для общей попытки с достаточным одним успехом ведущий может выбрать very/incredibly hard, но не обязан.

**Решение:** out_of_scope. Общий калькулятор DC/рангов/уровней работы не требуется для создания карты. Отдельные нужные условия будущей навигации сохраняются в исходных L2-строках без принятия универсального движка.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-DC-minimum-v2

**Источник:** [GM Core pp.53](https://2e.aonprd.com/Rules.aspx?ID=2632); редакция GM Core Remaster English.

**Правило:** Для Pick a Lock/Disable a Device у замка/ловушки бывает минимальный ранг сверх DC. Ниже ранга попытка возможна, но успех невозможен. То же можно назначить другим задачам. Обычно не стоит требовать expert при уровне≤2, master≤6, legendary≤14; это рекомендации, не абсолютные запреты.

**Решение:** out_of_scope. Общий калькулятор DC/рангов/уровней работы не требуется для создания карты. Отдельные нужные условия будущей навигации сохраняются в исходных L2-строках без принятия универсального движка.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-DC-navigation-v2

**Источник:** [GM Core pp.54](https://2e.aonprd.com/Rules.aspx?ID=2642); редакция GM Core Remaster English.

**Правило:** Ориентирование обычно имеетDC15 в обычной дикой местности,20 в глубоком лесу/подземелье,30 в безориентирной/запутанной местности,40 в странной среде иных планов. Это ориентиры ведущему, не минимальный ранг и не скорость.

**Решение:** defer_L2. Дополнение сложности уже включено в PF2-RM-039-L1-v2; не отдельная L1-функция.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Отложенный слой не означает согласованной разработки; полные боевые/персонажные движки остаются исключёнными.

**Правило:** Для Track ведущий выбирает простуюDC с поправками: армия — пример10, её следы в грязи — пример5. При Cover Tracks можно брать SurvivalDC цели. Для знакомой местности можно применить easy−2. Примеры не алгоритм всех следов.

**Решение:** defer_L2. Дополнение сложности уже включено в PF2-RM-040-L1-v2; не отдельная L1-функция.

### PF2-RM-DC-work-v2

**Источник:** [GM Core pp.53–54](https://2e.aonprd.com/Rules.aspx?ID=2635); редакция GM Core Remaster English.

**Правило:** Максимальный уровень работы обычно равен уровню поселения. Если он неизвестен, ориентиры: деревня0–1,town2–4,city5–7,столица/метрополия8–10; выше — крупнейшие города/иные планы. Порт/культурный центр могут иметь более высокие профильные задачи; редкий навык может не иметь работы. DC — по выбранному уровню с возможной поправкой условий.
