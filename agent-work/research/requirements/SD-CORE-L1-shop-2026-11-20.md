# Shadowdark · имя и специализация лавки

На опубликованном PR509 (d6daa2cd) проверены обычный Classic и та же карта со слоем Knave. Для сравнения взят сохранённый пример Shadowdark Core, с. 138–139: для обычной лавки результат 7 на d10 задаёт корабельного мастера / плотника. В тесте мастер ввёл этот результат сам.

Мастер переименовал лавку и восстановил имя при повторном открытии. При переносе лавки из 2,0 в 2,-1 имя последовало за ней. Вручную записанная специализация плотника осталась у гекса 2,0, даже когда там появилась башня. В обоих режимах карта целиком совпала с экспортом после каждой из четырёх операций. Проверены обработчики релиза; отдельного прогона на сайте не было.

**Для стратега.** SD-CORE-059-L1 — частичная поддержка. Полбалла в кандидате 1.3 уже учтены за именованное место. Добавление заметки не даёт второго полбалла. В старом примере приёмки осталась генерация покупателей; для L1 применима только актуальная проверка имени и специализации конкретного места. Экономика и ассортимент вне исследования.
