# Shadowdark. Создание карты в HexCrawl

[Проверенная версия 1721550](https://github.com/YuriyEmelyanov/Hexcrawl/commit/172155071ca1408abf6960dbc876ba030fc61613) · [Матрица, источники и воспроизводимые проверки](SD-CORE-L1-implementation.json).

На базовой карте сохраняются именованные места и их типы. Проверены городок, таверна, башня, вход и лесное логово. Расширение сохранило исходные точки и биом. Общая сетка использует 6 миль между сторонами и сохраняет географию при разных значениях экранного приближения. Shadowdark задаёт 6 миль поперёк гекса без уточнения оси.

Генератор Shadowdark задаёт первое окружение по 2d6. В следующих гексах результат может сохранить текущую строку, сдвинуть её по кругу или потребовать отдельный бросок. На результате 1 из 6 появляется один слот POI. Этот игровой профиль отсутствует в проверенных входах текущего генератора. Уровень угрозы встреч отделён от проходимости. На с. 133 остаётся открытым способ сочетать два столбца POI.

Источником служит ранее тематически проверенный предоставленный Core ©2023. Версия v4.6 указана в имени файла, её точность внутри PDF не установлена. Для реализации использовались реальные обработчики и загрузка JSON. Отрисовка в браузере и выдача материалов игрокам в эту проверку не входили.
