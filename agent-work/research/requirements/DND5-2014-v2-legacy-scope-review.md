Это исследовательское решение о применимости всех51строк, не изменение score/реестра/объявленной поддержки. Исходные28положений и84позиций по слоям (включая33пустые placeholders) сохранены в старой матрице. 24новые записи перекрываются с этим набором; это не75независимых требований.
