# PF2: справочные материалы места — журнал, сборник, карта, атлас

Проверены четыре текущие карточки предметов в издательском Player Core Free Basic Rules на Roll20. Путь: Remaster-оглавление → Equipment/Adventuring Gear → четыре карточки expansion27463; credits указывают Player Core2023 Paizo/ORC. Это закрывает прежний source-пробел журнала, но не полноту всей книги.

**Для приложения:** отдельно хранить доступность документа, его тему/географический охват и свойства выбранного варианта.1d4часа получения журнала по Scholarly и1минута обращения к нему — разные этапы. Геодезическая карта относится к конкретному месту, атлас — к набору листов. Обычный экспорт карты не становится автоматически предметом с бонусом.

| **Sample Abilities: Scholarly** (PF2-RM-ST-025-v2) — [GM Core printed p170; Sample Abilities: Scholarly](https://2e.aonprd.com/Rules.aspx?ID=3011). В поселении с доступными библиотеками/учебными местами за 1d4 часа можно получить журнал по подходящей общей теме перед Recall Knowledge. Параметры: {"duration_roll":"1d4","unit":"часы","subject":"подходящая common тема","before":"Recall Knowledge"} | Отметить библиотеку/учебное место и связать с услугой поиска журнала; показать результат в контексте выбранного поселения. Изменение сохранить с картой, восстановить после загрузки и отмены. Выход: Показана услуга 1d4 часа; сам журнал и проверка знаний не подменены простым наличием POI. Приёмка: Задан результат d4=3, common тема подходит. → Описание услуги показывает 3 часа и журнал перед Recall Knowledge; не 3 дня.; Получен указанный ожидаемый результат; затем карту сохраняют, загружают и отменяют последнее изменение. → После загрузки тот же результат и привязка; отмена восстанавливает предыдущую запись/геометрию без изменения других поселений.; Scholarly: d4=3; затем журнал о вампирах; Recall Knowledge о вампирах → Доступ3часа; обращение1минута; +1 item к подходящей проверке. Это не3минуты и не бонус ко всем знаниям. | Не проверено | Просмотрены текущие POI, заметки, модель региона и сохранения. | **Научный журнал и сборник** (PF2-RM-PC-JOURNAL-v2) — [Player Core → Chapter6 Equipment → Adventuring Gear → Научный журнал и сборник; journal print290 cross-reference, map printed page not independently verified](https://roll20.net/compendium/pf2/Items:Scholarly%20Journal?expansion=27463). Необычный научный журнал посвящён узкой теме. Минута обращения к нему перед Recall Knowledge по теме даёт +1 item bonus. Доступные в месте журналы определяет мастер. Сборник охватывает более широкую тему, стоит в5раз дороже и требует двух рук. Параметры: {"level":3,"rarity":"uncommon","bulk":"L","single":{"price_gp":6,"hands":1,"scope":"узкая тема"},"collection":{"price_gp":30,"hands":2,"scope":"более широкая тема"},"reference_time_minutes":1,"check":"Recall Knowledge","bonus":{"value":1,"type":"item","condition":"тема подходит"}} | Добавить в место доступный журнал/сборник, указать тему и условия доступа. Показать вариант, тему/охват, доступность и параметры. Сохранить эти связи при загрузке/отмене. Для L3 передавать document_id,subject_or_area,variant,check_kind,bonus_type,value,reference_duration; принимать applicability/reason, не результат броска от карты. Выход: Журнал о вампирах относится к вампирам; сборник о нежити — к более широкой группе. Получение и обращение к предмету — отдельные этапы. Приёмка: Scholarly: d4=3; затем журнал о вампирах; Recall Knowledge о вампирах → Доступ3часа; обращение1минута; +1 item к подходящей проверке. Это не3минуты и не бонус ко всем знаниям.; Тема проверки — другая страна → Бонус не объявляется подходящим; возвращается отсутствие соответствия теме.; Сборник → Цена30gp, две руки, та же величина+1, более широкая тема; не+5. | Не проверено | Первичные тела прочитаны и редакция подтверждена цепочкой PlayerCore Free Basic Rules и credits. Приложение для этих операций не исполнялось. |
| **Геодезическая карта и атлас** (PF2-RM-PC-SURVEY-v2) — [Player Core → Chapter6 Equipment → Adventuring Gear → Геодезическая карта и атлас; journal print290 cross-reference, map printed page not independently verified](https://roll20.net/compendium/pf2/Items:Survey%20Map?expansion=27463). Необычная геодезическая карта подробно описывает одно место и даёт +1 item bonus к Survival и Recall Knowledge лишь по этому месту. Атлас содержит несколько карт того же качества, нередко связанных темой; стоит в5раз дороже и требует двух рук. Доступность карт в месте определяет мастер. Параметры: {"level":3,"rarity":"uncommon","bulk":"L","single":{"price_gp":10,"hands":1,"coverage":"одно место"},"collection":{"price_gp":50,"hands":2,"coverage":"несколько карт","map_count":"не задано"},"bonus":{"value":1,"type":"item","checks":["Survival","Recall Knowledge"],"condition":"проверка относится к изображённому месту"}} | При подготовке места добавить доступную карту/атлас и явно связать каждый лист с изображённым местом. Показать вариант, тему/охват, доступность и параметры. Сохранить эти связи при загрузке/отмене. Для L3 передавать document_id,subject_or_area,variant,check_kind,bonus_type,value,reference_duration; принимать applicability/reason, не результат броска от карты. Выход: Один лист показывает границы своего охвата; атлас — список листов с их охватами. Наличие карты не открывает все тайны мира и не задаёт гексы/масштаб генерации. Приёмка: Карта долины A; проверка Survival в долине A и в долине B → Для A есть условие+1 item; для B оно не выполнено.; Атлас с двумя выбранными листами A/B → Цена50gp, две руки, оба листа и их связи сохранены; количество листов не выдумывается кубом.; Обычная схема без выбранного свойства Survey Map → Бонус+1 автоматически не назначается каждому экспорту карты. | Не проверено | Первичные тела прочитаны и редакция подтверждена цепочкой PlayerCore Free Basic Rules и credits. Приложение для этих операций не исполнялось. |
