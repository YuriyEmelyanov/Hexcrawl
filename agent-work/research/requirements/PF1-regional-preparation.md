# PF1: создание следующего гекса — текущий объём

Ревизия 17 ноября 2026. Точные исходные параметры и прежние операции сохранены в [матрице](../../market/rules/PF1-UltimateCampaign.json); текущая применимость описана ниже. Не новая спецификация/очередь.

| Строка | Решение | Основание / операция |
|---|---|---|
| PF1-UC-001-L1 | keep_L1 | Физический размер и конвенция гекса относятся к карте; это профиль подсистемы, не разрешение менять принятую геометрию. Сохранить длину и конвенцию без подмены размером экранной сетки. |
| PF1-UC-002-L1 | keep_L1 | Выбор стартового/следующего гекса и сохранность созданного — непосредственное создание карты; движение партии сюда не включено. Принять выбранный начальный тип; подготовить содержимое выбранного нового гекса, сохраняя ранее созданное. |
| PF1-UC-003-L1 | keep_L1 | Первый бросок определяет основной рельеф нового гекса, не навык персонажа. Разрешить первый бросок по указанным диапазонам; повтор использовать из явного предыдущего типа. |
| PF1-UC-004-L1 | keep_L1 | Второй независимый бросок определяет содержимое гекса; не событие или ежедневная встреча. Определить категорию элемента вторым броском и сохранить пару результатов без замены местности. |
| PF1-UC-005-L1 | keep_L1 | Основной рельеф и локальная география — принятые объекты карты. Сохранить основной тип и локальные детали без сведения всей территории к однородной заливке. |
| PF1-UC-006-L1 | keep_L1 | Выбранная ведущим климатическая трактовка меняет отображаемый рельеф; не требуется климатический движок. Сохранить явную авторскую интерпретацию категории отдельно от исходного результата таблицы. |
| PF1-UC-007-L1 | out_of_scope | Общий совет сделать описание запоминающимся не задаёт отдельную пространственную операцию; интересность и возможность заметки недостаточны. Конкретные выбранные места/особенности остаются по009. Вне принятого рабочего объёма. |
