## Исходный смысл и текущая операция

### PF2-RM-GMC1C-001-v2

**Источник:** [GM Core pp.10](https://2e.aonprd.com/Rules.aspx?ID=2480); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

**Правило:** Пока деталь не объявлена игрокам, ведущий может пересмотреть свой план по контексту и предложениям группы; это не требует автоматически переписывать уже установленную истину мира.

**Решение:** out_of_scope. Пересмотр неозвученного плана — управление повествованием, а не изменение географии.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-GMC1C-002-v2

**Источник:** [GM Core pp.12](https://2e.aonprd.com/Rules.aspx?ID=2488); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

**Правило:** Критический провал Recall Knowledge может дать неверную информацию. Совет: правдоподобная ошибка с близкими, ограниченными последствиями; не обязательно важная ложь и не повод уводить кампанию на долгий ложный путь.

**Решение:** out_of_scope. Ложные знания при критическом провале — исполнение Recall Knowledge и управление информацией сюжета.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-GMC1C-003-v2

**Источник:** [GM Core pp.13](https://2e.aonprd.com/Rules.aspx?ID=2491); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

**Правило:** При создании NPC полезно начать с одной запоминающейся черты/зацепки, затем дополнять биографию при повторном участии. Важному NPC могут требоваться характер, роль и дополнительные подсказки. Помощник не должен решать за героев все задачи.

**Решение:** out_of_scope. Генерация характера и биографии NPC прямо исключена; имя/услуга конкретного жителя не требует такого генератора.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-GMC1C-004-v2

**Источник:** [GM Core pp.14](https://2e.aonprd.com/Rules.aspx?ID=2493); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

**Правило:** Если планируется предательство NPC, заранее дать обнаружимые признаки или документальный след, чтобы поворот был обоснован задним числом. Это совет подготовки зацепок, не случайная вероятность предательства каждого жителя.

**Решение:** out_of_scope. Предвестники предательства — подготовка сюжета; документ у POI не обосновывает подсистему.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-GMC1C-005-v2

**Источник:** [GM Core pp.19–20](https://2e.aonprd.com/Rules.aspx?ID=2512); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

**Правило:** Три подхода: собирать идеи игроков при сохранении авторитета ведущего; поручать им отдельные регионы/NPC с учётом авторства и согласованности; либо совместно импровизировать мир. Опциональные Story Points обычно2–3 за сессию позволяют небольшой поворот/факт, но не исход всей сцены или радикальную переделку мира.

**Решение:** out_of_scope. Story Points и авторство импровизации — управление рассказом, не совместное редактирование карты.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-GMC1C-006-v2

**Источник:** [GM Core pp.22–23](https://2e.aonprd.com/Rules.aspx?ID=2530); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

**Правило:** Common обычно доступно при выполнении prerequisites; uncommon требует доступа/усилий; rare вводит ведущий; unique — конкретный единственный объект/NPC. Редкость не означает силу. Она зависит от региона и контекста: оружие может быть uncommon в одном регионе и common в другом. Access отличается от механических prerequisites; ведущий может менять местные условия.

**Решение:** out_of_scope. Региональные Access/редкость и prerequisites относятся к каталогу предметов/возможностям персонажа.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-GMC1C-007-v2

**Источник:** [GM Core pp.28](https://2e.aonprd.com/Rules.aspx?ID=2558); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

**Правило:** Бой можно вести без сетки, на обычной квадратной сетке, с вариантом одинаковых диагоналей5футов вместо чередования5/10 либо на гексах/смещённых квадратах. Гексы выравнивают движение по направлениям, но усложняют фланг, большие фигуры и прямоугольные комнаты. Радиус эффекта для одинаковых диагоналей выбирают по принятому способу, возможно круговым шаблоном.

**Решение:** out_of_scope. Боевые сетки и диагонали не относятся к региональной гексагональной карте.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

**Правило:** Укрытие в сложной сцене определяет ведущий с учётом трёхмерных деталей. Линия на плоской карте полезна лишь в простом случае; баннер может прикрывать, а высота уступа — давать обзор поверх низкой стены.

**Решение:** out_of_scope. Трёхмерное укрытие и линии обзора боевой сцены прямо исключены.

**Текущая функция L1:** не предъявляется. Прежнее продуктовое предложение не является рабочим требованием. Не передавать в разработку/интеграции автоматически.

### PF2-RM-GMC1C-009-v2

**Источник:** [GM Core pp.29](https://2e.aonprd.com/Rules.aspx?ID=2562); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

При гонке на полной скорости можно отказаться от сетки и использовать относительные позиции/подсистему погони.

### PF2-RM-GMC1C-012-v2

Полезно разбить цель на стадии, показывать последствия; успех вероятен для разумной цели, но не гарантирован. Пример бизнеса: лоток→спрос→магазин→первые успехи→клиенты→служащие→снабжение/конкуренция→расширение в другом поселении.

**Решение:** out_of_scope. Стадии бизнеса/политики/восстановления — менеджер проектов/сюжета. Ручная правка POI не обосновывает его.

Время существенно: достаточная оплата не строит форт за день. Долгий проект может продолжаться во время приключений при надёжном компетентном управляющем.

### PF2-RM-GMC1C-015-v2

**Источник:** [GM Core pp.59](https://2e.aonprd.com/Rules.aspx?ID=2656); редакция Remaster GM Core English; AoN snapshot 2026-11-16.

**Правило:** Бюджет Party Treasure by Level относится ко всему уровню группы из4PC, не каждой встрече/локации. Отдельно считают permanent, consumable и валюту; total приблизителен.
