# MB: Провидец выбранного святилища

Лист Realm Sheet назначает святилище домом Провидца и отсылает к таблице рыцарей. Официальный бесплатный Quickstart p14 уточняет переход на страницу рыцаря; p26 задаёт упорядоченную пару d6, затем d12.

Проверены две полные цепочки:1/1 → The True Knight → The Rotted Seer(p28);1/2 → The Snare Knight → The Swollen Seer(p30). Житель святилища — Провидец, промежуточный рыцарь не создаётся там автоматически. У2/1 известен только The Trail Knight, у6/12 — The Rat Knight; их Провидцы остаются неизвестными без карточек.

Ведущий назначает результат одному святилищу, может заменить только его и открыть сохранённую карту с прежними исходами/источниками. Невалидная пара не стирает прежнего Провидца; недоступная карточка сохраняется как незавершённая ссылка. Семь примеров в [JSON](MB-sanctums-L1.json) — требования, не результаты проверки продукта.
