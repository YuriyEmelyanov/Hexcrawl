# D&D 5e — рельеф и дорога через проход

В Classic на 6-мильной карте штатными правками получен переход «горы → предгорья → равнина». В горной области можно задать одному гексу биом холмов. Высота всей области при этом остаётся прежней.

| Действие | Проверенный результат |
| --- | --- |
| Назначить рельеф трём смежным областям | Сохранены горы уровня 3, открытые холмы уровня 2 и равнина уровня 1. Редактор отклонил замену средних холмов равниной из-за несовместимости биомов в этом примере. |
| Провести дорогу через единственный открытый проход | Шесть из семи рёбер между хребтом и предгорьями закрыты препятствиями. Редактор отклонил попытку пройти через закрытое ребро и сохранил ручную дорогу через гексы `0,1 → 1,0`. |
| Оставить также свободный обход | Редактор принял другой ручной путь, минующий гекс `0,1`. Переопределение его биома не определяет маршрут само по себе. |
| Сохранить и снова загрузить карту | В JSON сохранились рельеф, локальный биом, препятствия и трасса. Отмена и повтор корректно убрали и вернули дорогу в исходном сценарии. |

Ручной сценарий рельефа **подтверждён** на `d6daa2cdbc1c17b942d51fe050fac51752cf9fee`. Для дороги подтверждён **ручной выбор и блокировка явных препятствий**. Автоматическое распознавание перевала и прокладка через него остаются открытыми. Проверка проходила через обработчики редактора и JSON, без проверки отрисовки в браузере.

Историческая выписка из DMG 2014, печатные стр. 14 и 108 русского перевода PHantom 2016, лежит в основе выбора сценария. Полный первичный текст остаётся отдельным условием приёмки.
