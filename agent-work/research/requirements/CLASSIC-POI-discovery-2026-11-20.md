# Обнаружение точек интереса в Classic

На `d6daa2c` обычный Classic сохраняет столицу и портал без свойства «Обнаружение». Автогенерация с seed 42 создала четыре точки без этого свойства. Старая деревня загрузилась из JSON v7 и сохранилась в v10 без назначения режима.

Knave показывает «При прохождении» при пустой записи обнаружения. Его генератор заполнил содержимое четырёх точек и сохранил ноль записей обнаружения. Секрет с уликой сохраняется после отключения генерации Knave. Попытка сохранить секрет Knave с пустой уликой отклоняется.

| Сценарий | Критерий для HX-BL-062 |
| --- | --- |
| Создать столицу | В карточке и сохранении «При прохождении». Повторный просмотр читает назначенное значение. |
| Создать портал | Три допустимых исхода воспроизводятся на контролируемых входах будущей политики. Каждая POI сохраняет присвоенное значение при загрузке. |
| Загрузить прежнюю деревню | Объект остаётся на карте. Тест различает сохранённый режим и подпись по умолчанию. Поведение отсутствующей записи определяет спецификация. |
| Открыть прежнее сохранение Knave | Сохраняется уже заданный секрет и его улика. Обязательная улика подтверждена для Knave. |

Сопоставление источников ограничено подготовкой карты. D&D 5e отделяет наблюдаемый признак от скрытой части места в ранее сохранённой выписке. Knave различает места, заметные при прохождении, улики при исследовании и секреты, открываемые взаимодействием. Crows описывает разведку существующих неизвестных мест. Режим обнаружения Classic и знание группы в ходе игры проверяются раздельно.

Проверены обработчики App, JSON и статический вывод панели. Браузер и выдача данных игрокам не проверялись. Точные вероятности и поведение прежних карт оставлены этапу спецификации.
