# MB: по3–4ориентира каждого вида

Официальный Realm Sheet, PDF1, LANDMARKS: по3или4каждого вида, с буквенной меткой либо значком. Прочитаны две вводные фразы и заголовки шести видов: Dwellings, Sanctums, Monuments, Hazards, Curses, Ruins. Их эффекты не извлечены.

Ведущий выбирает по3места каждого вида — получает18; по4 —24; смешанный выбор3/4/3/4/3/4 —21. Это наша арифметика из правила, не новое вероятностное распределение. Правило не означает3–4объекта всего на край и не требует броска для выбора3или4.

Тип можно обозначить инициалом или выбранным значком; смена обозначения сохраняет тип и положение. При нехватке одного вида набор не объявляется полным. Открытие сохранённой карты восстанавливает количества/метки/положения; предзнаменования, Провидцы и эффекты из этого профиля не создаются. Семь примеров в [JSON](MB-landmarks-L1.json) — критерии, не выполненные проверки продукта.

Переиспользуются content.site_density и map.reference_labels. Дополнен existing proposed HX-BL-053; перед разработкой проверить текущие MB/редактор/метки. Стратег выбирает объём, аналитик специфицирует. Реализация unknown; рейтинг и баллы неизменны.
