# Shadowdark — ручное нанесение результатов Overland Hex Maps

Проверены штатные инструменты Classic на `d6daa2cdbc1c17b942d51fe050fac51752cf9fee` по ранее извлечённой печатной стр. 132 Shadowdark RPG Core. Броски разрешались по сохранённой таблице вне приложения, затем ведущий наносил результаты на базовую 6-мильную сетку.

| Гекс | Вход | Выбранный результат в HexCrawl |
| --- | --- | --- |
| `−3,0` | Hex Terrain 4+5 | Сухой берег у моря |
| `−4,0` | New Hex 1+1 | Океан. Редактор сохранил его как море из `−4,0` и `−4,1` |
| `−3,−1` | New Hex 4+5 | Сдвиг океана на две строки по кругу. Выбрана Арктика, нанесена снежная равнина |
| `−2,−1` | New Hex 2+2 | Та же категория, нанесена снежная равнина |
| `−1,−1` | New Hex 6+6, затем Hex Terrain 3+4, отдельный POI d6=1 | Лиственный лес и одна POI «Руины» |
| `0,−1` | New Hex 1+1 | Выбрана река. Русло проходит по рёбрам и впадает в сохранённое море |

В пяти остальных гексах результат d6 не добавил точек интереса. После загрузки JSON сохранились биомы, море, направленное русло и одна точка. Одиночный морской гекс редактор отклонил без изменения карты. Второй морской гекс добавлен для соблюдения геометрии HexCrawl.

Это частичная поддержка ручной подготовки. Категории и броски записаны в исследовательском сценарии. Профильная автоматизация, событие входа в пустой гекс и хранение результата проверки POI отдельно от географии остаются за границей доказательства.
