Разместить выбранные овраг/уступ/пороги или другую конкретную географическую деталь в выбранном гексе, сохранив основной рельеф; детали только про лазание/движение не становятся новыми статичными POI. |

Разместить выбранный источник воды/ресурса/торговый пост как содержимое конкретного места с известным видом снабжения; не рассчитывать доход/добычу/запасы/крафт. |

| PF1-UC-013-L1 | keep_L1 | Сезонная трактовка холодной пустыни относится к выбранному рельефу карты; автоматический календарь/климат не требуются. | PF1-UC-014-L1 | keep_L1 | Поселение не заменяет подстилающий рельеф; оба объекта карты нужны для отображения места. Записать поселение и отдельный тип местности, на котором оно расположено. |
| PF1-UC-015-L1 | keep_L1 | Берег и существующий мост/проход — геометрия воды и перехода, не симуляция плавания. Отметить преобладающую воду, тип прилегающего берега и выбранный проход, если он есть. |
| PF1-UC-016-L3 | integration_L3 | Только внешняя проверка, непосредственно связанная с навигацией/выживанием/преодолением географии; без внутреннего движка навыков/персонажей. Передать выбранный контекст, идентификатор навыка, исходныеDC/итог и точный kind/value внешнему механизму проверки; принять раздельныеDC/итог и связанный результат путешествия. Самостоятельно не бросать и не менять лист персонажа. |
| PF1-UC-017-L2 | defer_L2 | Выбор следующей меньшей скорости и расчёт времени относятся к ведению гекскроула, не созданию карты. Для табличного времени использовать ближайшую меньшую строку скорости; исходную скорость персонажа не переписывать. |
| PF1-UC-018-L3 | integration_L3 | Условные параметры встреч нужны внешнему разрешению дорожного события; не генерировать бой/статы/мнимую частоту. Передать внешнему механизму встреч выбранный контекст и исходную надбавку10%/25%; без определённой композиции принять unknown итоговой вероятности, а не случайную встречу или бой. |
| PF1-UC-019-L2 | defer_L2 | Множитель времени исследования леса — состояние исследования; не карта скрытыхмест. Умножить обычное время исследования на1.5; не распространять на обычное пересечение. |
| PF1-UC-020-L2 | defer_L2 | Дорожное сокращение времени — движение партии; дорога как объект отдельноL1. Показать допустимый диапазон времени после сокращения; конкретную долю выбрать только с обоснованным профилем местности. |
| PF1-UC-021-L3 | integration_L3 | Проверка обнаружения конкретного прохода/пещеры выполняется внешним механизмом; HexCrawl принимает результат для исследования карты. Передать тип места, допустимый навык,DC и внешний итог; принять обнаружение места без перемещения партии. Для mountain/secret отдельно PerceptionDC20 и исключение кL2времени, не другие навыки. |
| PF1-UC-022-L3 | out_of_scope | Бюджет снаряжения/сокровищ по уровню каждого героя — исключённый расчёт наград и персонажей; простой тайник как место может остаться по012. Вне принятого рабочего объёма. |
| PF1-UC-023-L3 | integration_L3 | Защита в конкретном укрытии и отдельный риск встречи — ограниченная зависимость состояния пути; не общий движок шторма/боя. Передать выбранное укрытие и факт нахождения внутри; принять ограниченную защиту от шторма, сохранив отдельную надбавку встреч и неизвестную композицию вероятности. Выход из укрытия прекращает эту льготу. |
| PF1-UC-024-L3 | integration_L3 | Только частота дорожной опасности/точная внешняя ссылка и явное исключение; полный урон/бой/магия не входят. Передать дорожной внешней механике5%за один час difficult-леса либо точную ссылку avalanche/collapse с указанным исключением погребения. Принять только подтверждённые данные; урон/полные непрочитанные зависимости оставитьunknown, не рассчитывать внутри приложения. |
| PF1-UC-025-L2 | defer_L2 | Лодка/скорость плавания меняют допустимость маршрута партии, не геометрию воды. При отсутствии лодки и swim speed предложить обход как рекомендуемый вариант; при наличии средства отметить, что это ограничение само не запрещает пересечение. |

## Статус и ограничения

[Аудит15L1профилей](../audits/PF1-L1-2026-11-14.json) относится к1962fb9a835a9c310e55c1a09415fe180f22cca9: текст/локальные общие редакторы не доказывают точный PF1профиль. Difficultне общий множитель для всех типов; resourceне всегда пища/вода. Huntinggroundне обязательное логово. Простые сведения о конкретном месте разрешены, но не новыеконтроллеры ради заметки.
