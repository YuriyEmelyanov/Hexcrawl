## OSE-ORR-2026-006-L1: Наличие и примечания служб базового города

**keep_L1**. Простые сведения о ночлеге/помощи относятся к необходимому содержимому конкретной базы для подготовки карты; это явное разрешённое исключение владельца, а не основание из произвольной заметки.

Источник: OSE-OFFICIAL-ORR-2026-BASE-TOWN-EN; 2. Note Services, HTML259–270. Отметить наличие служб, полезных приключенцам, и возможные подробности; не делать необоснованный вывод о доступности каждой услуги.

Параметры и исключения:

```json
{
  "service_categories": [
    "black_market",
    "guard",
    "healing",
    "lodgings",
    "rumour_locations"
  ],
  "organised_thieves_guild": "may_exist",
  "bribery_and_patrol_notes": "useful_to_note",
  "numerical_rules": "not_given"
}
```

Связь с продуктом: Описание услуг выбранного населённого пункта; существующий редактор содержимого места.

Действие: При подготовке выбранного города указать известные местные услуги, исправить одно сведение и сохранить его без выдумывания неизвестных услуг.

Входы: ГородT; известен ночлег«комнаты у мельника»; лечение болезней неизвестно; ведущий меняет ночлег на«ночлега нет».

Ожидается: УT сохранено«ночлега нет», лечение болезней остаётся неизвестным. Не сгенерированы гостиница, гильдия, цены, расписание патрулей или слухи. После открытия сведения не переброшены.
