# PF2: местность и независимые дополнительные элементы

GM Core p206/Designing the Map рекомендует один преобладающий тип местности, но допускает другие особенности, реку, дорогу и места. Это не запрет неоднородности и не алгоритм генерации.

Ведущий выбирает лесной H, добавляет реку R, дорогу D и пещеру P. Получает лес и все три элемента одновременно. Переименование Pсохраняет R/D/лес; удаление Dсохраняет R/P/лес. При допустимых позициях смена преобладающей местности не стирает подготовленные элементы. Небольшая поляна может оставаться описанным местным отличием без выдуманных процентов.

Семь [примеров](PF2-RM-003-L1.json) охватывают отдельные правки и открытие сохранённой карты. Один из них отдельно следует направлению владельца OVERVIEW1: большой обзорный гекс, пересекающий лес/холмы/объекты, остаётся смешанным. Рекомендация PF2для подробной ячейки не превращается в требование перекрасить большой гекс одним биомом; точная PF2совместимость масштаба здесь не заявлена.

Новой задачи нет: proposed051получает только source-связь/проверку уже существующего ограничения сохранности, не новый редактор. Текущий продукт не проверен; статусыunverified/evidenceunknown, рейтинг/баллы без изменений. Руины MBостаются атмосферой, карта игроков —L2по свежему решению владельца.
