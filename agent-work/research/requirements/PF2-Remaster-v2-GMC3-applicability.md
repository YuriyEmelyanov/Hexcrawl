# PF2: Age of Lost Omens — проверенная часть и точный остаток

18 ноября 2026 · HX-RSR-001 · Remaster GM Core · [JSON](PF2-Remaster-v2-GMC3-applicability.json)

**Вся глава пока не принята.** Прочитаны все доступные разделы её страницы AoN, но это не весь печатный материал. Обзоры регионов pp146–155 только упомянуты; карта не проверена. Диапазон pp156–165 ещё не сверен с первичным оглавлением. Отдельные24описанияпланов по индексу не объявлены прочитанными.

Основной новый вывод: границы десяти регионов Внутреннего моря **тематические, а не политические**. Они не задают государственную принадлежность гексов. Из этого не следует новая функция тематических слоёв или импорт атласа.

Для приложения остаётся прежняя узкая операция **задать имя и тип конкретного поселения и сохранить с картой**. Пример: C → деревня «Ольховка»; после загрузки тип и имя те же. Это ST009, не новая функция. Уровень PF2 не преобразуется в площадь/численность. Старое partial проверяло только именование POI на `b7d0a5637ac5980efc8b91ed425dd7bab5577c8f`; имя+тип/save/load/undo на свежем SHA этим запуском не проверены.
