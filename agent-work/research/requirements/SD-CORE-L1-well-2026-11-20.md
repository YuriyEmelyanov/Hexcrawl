# Колодец из сцены Shadowdark

Именованный колодец пережил три повторных открытия в Classic и Classic с Knave. При переносе имя осталось с маркером, запись об исходной сцене осталась в прежнем гексе. Проверка уникальности имени допускает вторую точку с другим названием.

Мастер закрепил место как обычную именованную постройку. После переноса из `2,0` в `2,-1` в новой позиции сохранилось имя Old Well. Ссылка, введённая текстом, осталась в `2,0`. При повторном ручном размещении имя Old Well вызвало ошибку уникальности. Под другим именем сохранились две точки. При трёх импортах одной сохранённой карты осталась ровно одна точка.

Функциональный вывод по SD-CORE-063-L1 — частичная поддержка. Для полного зачёта нужен проверяемый источник сцены у самого места. Время пользовательского действия отдельно не измерялось.
