## WWN-RU-KNG-002 — Предлагать шестимильную гекс-карту с основным типом местности и несколькими POI

Источник: Уточнять карту можно по необходимости. Для гекскроула удобна точная гекс-карта;6миль названы популярным выбором с одним основным типом местности и несколькими точками интереса. Художественная детализация не обязательна.

Действие: Ведущий решает, нужна ли точная гекс-карта для исследования, и при необходимости выбирает её масштаб.

Входы: точность — схематическая карта либо точная гекс-карта по необходимости; размер — необязательный предложенный вариант6миль; измерение — отдельно известная/заданная ведущим геометрическая конвенция, иначеunknown; гекс — один основной тип местности и размещённые POIбез заданного книгой максимума.

Операция: Предложить6миль как один из вариантов физического масштаба точной гекс-карты, сохраняя выбор ведущего и известность конвенции измерения. В выбранном профиле хранить один основной тип местности гекса и несколько отдельных POI, сохраняя содержимое при изменении основного типа. Не менять существующие карты автоматически.

Результат: Выбранная карта имеет известный размер/единицу и отдельно известную либо неизвестную конвенцию; у гекса различимы основной тип и несколько POI. Схематическая подготовка остаётся допустимой.

Ограничения: Шесть миль — популярный выбор, не универсальная обязанность и не причина пересчёта всех существующих карт. Источник не определяет сторону/диаметр/расстояние между центрами; точную геометрию не выводить из6миль. Несколько POIне равно фиксированным2/3объектам или обязательному максимуму; локальные отличия местности не запрещены. Основной тип — характеристика гекса, не утверждение отсутствия любых иных объектов/местностей внутри. Расчёт времени пути/стоимости движенияL2из этого абзаца не следует. Сохранение, разделение zoom/физического размера и адресная правка — продуктовый перевод; API/архитектура/интерфейс не проектируются.
