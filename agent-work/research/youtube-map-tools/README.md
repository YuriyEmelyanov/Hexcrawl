### Запуск сбора

Сборщик [collect_youtube.py](collect_youtube.py) использует `YOUTUBE_API_KEY` из окружения и сохраняет каждый завершённый запрос. В файле результатов фиксируются глубина выдачи, продолжение и ID каналов. Для запуска в разрешённом окружении:

```sh
python collect_youtube.py --output native-search-v1.json
python build_ranking.py --native native-search-v1.json --output ranking-v1.csv
```

При проверке ролика записывай точный таймкод, UTC-дату и постоянный ID канала. Используй `video_fragment_verified` и `confirmed_independent` или `confirmed_official` после подтверждения работы над картой. Для одного видео с двумя подходящими инструментами допустимы две строки свидетельств. Пересчёт оставляет нули и ранги пустыми, пока сопоставимый поиск и проверка кандидатов не завершены.
