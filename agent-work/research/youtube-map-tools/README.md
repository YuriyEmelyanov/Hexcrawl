# YouTube и Reddit — пилот по инструментам гекс-карт

Период 1 ноября 2025 — 31 октября 2026, UTC. В выборке 20 внешних продуктов и HexCrawl.ru. Сумма складывается из независимых каналов YouTube и уникальных авторов Reddit. Один человек может фигурировать на обеих площадках. При равенстве сумм инструменты занимают диапазон мест.

[Фиксированная выборка](cohort-v1.json) · [Свидетельства](evidence.csv) · [Сводная таблица](ranking.csv) · [Запросы и охват](search-log.json).

Разобраны метаданные 52 уникальных видео. YouTube запросил проверку при открытии видео в браузере. Порядок нативной выдачи за точный период и просмотр фрагментов пока не подтверждены. Пустая ячейка YouTube означает незавершённую проверку. В столбце суммы указан подтверждённый минимум. Места рассчитываются после сопоставимого прохода.

Общий запрос обнаружил Dungeondraft за пределами первой десятки Reddit. У продукта 3 автора Reddit и один независимый канал YouTube по авторскому описанию и главе о переработке гекс-карты НРИ. Минимум по двум столбцам — 4. [Mystic Arts, начало работы в 34:38](https://www.youtube.com/watch?v=sDqJTd5kK5E&t=2078s).

В официальном уроке HEXROLL 3 на 00:27 начинается глава о редактировании и генерации карты. Её отметили отдельно. [Описание и главы](https://www.youtube.com/watch?v=WA2XnYgLpdY&t=27s).

Модуль Augur: Hexlands и Campaign Cartographer уже есть в реестре. Для них найдены демонстрации разработчиков. [Продолжение проверки](checkpoint.json).
