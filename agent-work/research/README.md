## Текущий результат: PF2 Remaster, незавершённое выравнивание

[Понятная таблица](requirements/PF2-Remaster-v2-review.md): 24 положения региональной подготовки → конкретные операции приложения → приёмка → фактический статус. Использована 21 существующая общая механика; новых реестров и продуктовых задач нет.

**Масштабы несовместимы автоматически:** PF2 рекомендует 12 миль между вершинами; внутренний шаг проекта 12 — между сторонами. Площади 93.530744 и 124.707658 квадратной мили различаются на треть. Нельзя считать совпадение числа доказательством поддержки PF2. На main b7d0a56 прошли 13 существующих проверок одномильного слоя и 2 диагностические проверки геометрии; это не полный UI/runtime-аудит игры.

Исправлены локаторы: Navigating — GM Core 36 / AoN2582; Getting Lost — GM Core37 / AoN2583. Совет о 2–3 начальных ориентирах относится к Navigating.

**Полный разбор PF2 не принят.** Остались [39 известных L1-строк](requirements/PF2-Remaster-v2-remaining.json), проверка всей книги на применимость, ссылка Settlements168 и полные UI/save/history проверки. [Покрытие](requirements/PF2-Remaster-v2-coverage.json), [RA-Q01–15](requirements/PF2-Remaster-v2-quality.json), [evidence](requirements/PF2-Remaster-v2-evidence.json), [результат](runs/2026-11-16-PF2-L1-v2-233326.json).
