# Исследования игр HexCrawl

**Последний результат — тематический разбор предоставленного Shadowdark Core.** Все 332 PDF-страницы просмотрены на применимость к карте/гекскроулу: 98 редакционных групп, 165 применимых требований (**64 L1, 35 L2, 66 L3**), 355 случаев приёмки. v4.6 указана в имени файла, внутренняя ревизия не подтверждена. Это не новый показатель сложности или популярности.

[Операции и приёмка](requirements/SD-CORE.md) · [Матрица Shadowdark](../market/rules/Shadowdark-Core.json) · [Страницы/исключения](../market/rules/Shadowdark-Core-coverage-ledger.json) · [Отчёт](runs/2026-11-06-SD-core-thematic-audit.json).

Для L1 важны начальная местность и условное продолжение гексов по 2d6 с кольцевыми шагами по семи категориям, POI на 1 из 6, уровень опасности и связанные генераторы мест/поселений. Для L2 — 6-мильный масштаб, время переходов, навигация, встречи и ресурсы. Внутренняя геометрия данжей/поселений и общий боевой/магический движок не входят в текущую региональную карту.

Переиспользованы **62 существующих общих правил**, новых канонических функций не добавлено. Параметры Shadowdark хранятся отдельными привязками; совпадение rule_id не подтверждает численную эквивалентность или реализацию. Свойства обнаружения используют существующие content.discovery_levels/S05-C03.

В едином бэклоге дополнены предложенные задачи 042–046; новое **HX-BL-047 proposed** описывает условное создание следующего гекса и переиспользует RNG/расширение. Разработка/выпуск не запущены. Покрытие продукта **unverified**. Неясны геометрическая конвенция 6 миль, связность бросков двух колонок POI, отдельные взаимодействия travel/effects и ряд параметров; они сохранены в матрице, не заменены выдуманными значениями.

**Рейтинг v1.4 и баллы не менялись; новых согласований рейтинга нет.** Knave остаётся 3-м, Shadowdark — 4-м в reference общем/create. Полный тематический [разбор Knave](requirements/KNAVE2.md) сохранён. Идея «Поддержка игр» под Classic остаётся предложением для будущей спецификации.

**Следующий кандидат:** Адресно проверить общий механизм таблиц MB и редактор POI на точном опубликованном SHA: фиксированные результаты, provenance, сохранение/загрузка и undo. Начать с профиля Knave rank3, проверить применимость того же механизма к Shadowdark rank4 без отдельного движка.
