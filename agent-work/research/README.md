Семь категорий источника не являются24биомами продукта. Река/побережье относятся к другим слоям; ocean может иметь отображение через sea override, а desert/arctic/jungle не имеют точных отдельных ID в прочитанном словаре. Полупустыня не объявляется пустыней автоматически. Swamp, grassland/open_plains и mountain/mountains — кандидаты отображения, а не доказанная эквивалентность. Подтипы и ограничения остаются явными.

**Для proposed HX-BL-047 предложено хранить исходную категорию отдельно от отображения.** Кольцевой переход New Hex использует семь строк источника, независимо от картинки/высоты/весов Classic. Нельзя молча восстанавливать категорию Shadowdark из биома старого сохранения или создавать фиктивный POI ради metadata: текущий TagOwner не описывает произвольный гекс без POI.

Приёмка конкретна: 1+1 даёт desert_or_arctic с subtype=null; river_or_coast не создаёт произвольную реку/море; mountain+1 возвращает desert_or_arctic; forest_or_jungle+2 даёт ocean. Заданы сохранность категории при export/import и Undo/Redo, явная approximation и старые карты. Это продуктовые предложения, не runtime evidence. Формат per-hex хранения/миграции ещё требует ограниченного анализа после разрешения разработки.
