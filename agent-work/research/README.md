[Crows PT3 · создание карты](requirements/CROWS-PT3-L1-implementation.md) · [Матрица и проверки](requirements/CROWS-PT3-L1-implementation.json).

Подтверждены сохранение моста вместе с дорогой и рекой, ручное превращение руины в деревню и размещение именованных входов. Связь лесопилки с берегом и тайником не следует из её типа. Подпись «5–6 миль» уже согласована в HX-BL-058. В проверенной версии по-прежнему «6 миль».

Поиск уже существующих мест у разведчика Crows — безопасное действие без отдельного броска. Это критерий ведения гекскроула. Далее проверка создания карты Shadowdark. Решений владельца сейчас не требуется.
