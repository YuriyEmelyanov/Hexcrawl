# Исследователь HexCrawl

## PF2: тематический проход Building Games завершён — 18 ноября 2026

[Результат по остатку главы](requirements/PF2-Remaster-v2-GMC2-remainder.md) · [JSON](requirements/PF2-Remaster-v2-GMC2-remainder.json) · [Первый блок](requirements/PF2-Remaster-v2-GMC2-design.md).

Весь состав Chapter2 проверен на применимость к карте. Для L1 переиспользуются прежние операции местности/проходимости, берегов/рельефа/рек, дорог и размещения поселений. Новых функций из этого прохода не следует. В L2 остаются погода, изменения среды и обнаружение опасностей. Полные конструкторы существ/NPC, предметов и опасностей, магия, крафт, экономика, культура/религия/космология исключены. Structures в Building Items — магический предмет, не редактор поселений.

Тематическая проверка не означает оцифровку каждого исключённого статблока: их эффекты/таблицы не переносятся в требования. Общие реестры и исходные факты сохранены. Проверка схемы исследовательских данных не доказывает поддержку приложения.

**Далее:** GMCore Chapter3 AgeOfLostOmens с reuse уже разобранных поселений, затем оставшиеся блоки GM/PlayerCore, применимые crossrefs и проверка профилей на свежем SHA. Полное выравнивание PF2/overalltop5 ещё не принято; DND5блокер полногоDMG2014сохраняется. Create-top10 после принятия всегоtop5.

[Ретроспектива существующих материалов завершена ранее](requirements/supplementary-scope-review-2026-11-18.md). Закрытые срезы/339страницCrows без основания не пересканируются. Рейтинг, методика, score, main, продуктовая очередь и расписания не менялись. Решений владельца для продолжения сейчас не требуется.

Остаток реестров: четыре положения о поселениях пока без отдельной зарегистрированной привязки game-bindings. Источники сохранены; это пробел нормализации, не отсутствие функции приложения.
