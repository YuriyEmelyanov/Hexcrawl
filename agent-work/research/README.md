# Исследования игр HexCrawl

Завершена [сверка всех семи гидрологических положений WWN EN/RU](collations/WWN-regional-hydrology-EN-RU-v1.md). Разделение реки без обратного слияния есть в английском оригинале; это не ошибка перевода. EN уточняет иной поглощающий сток и низкий путь при слиянии независимых рек. Метрика длины всё ещё не задана.

В JSON сохранены конкретные операции и три дополнительных кандидатных примера приёмки. RU профиль и статусы реализации сохранены; источники не повышают score. Сверка ограничена выбранным абзацем Free EN и supplied Deluxe RU.

HX-BL-005 остаётся proposed. Новых согласований нет, рейтинг и очередь команды сохранены. Следующий кандидат — L1 Dungeon World с проверкой свежих приоритетов и существенных рыночных пробелов.
