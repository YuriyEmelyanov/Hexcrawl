**WWN: перенос семи L1-требований в общие реестры завершён.** Зарегистрированы семь игровых профилей, добавлены обратные ссылки к двум существующим общим правилам и связи с предложенной задачей HX-BL-005. Все 519 прежних профилей сохранены; новых общих правил и продуктовых задач нет.

Корпус — только региональный шаг 3 русского WWN Deluxe, печатные страницы 120–121. Семь требований содержат конкретные действия, входы, результаты, исключения и 24 исходных примера; ещё один сценарий описывает сохранение и Undo/Redo. Рейтинг v1.4, его численная методика, когорты и баллы не менялись. Разработка и выпуск не начинались. Задача HX-BL-005 остаётся proposed.
