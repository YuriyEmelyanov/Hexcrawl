# Исследователь HexCrawl

## Daggerheart: рабочие границы исправлены — 17 ноября 2026

[Правила → операции → ограничения](../market/rules/Daggerheart-SRD2.md) · [Все решения](requirements/DH-scope-audit.json).

Из 4 существующих требований для карты остаются 3: размер/форма региона, habitat/признак порчи, масштаб. Прежний пакет «встреча + дни пути + слух» исключён как единая L1-операция. Из него отдельно сохранено размещение выбранного конкретного места, препятствия или простой добычи. Время пути — L2; генерация слухов/NPC/боевых ситуаций и adversary effects не входят в текущий продукт.

Исправлен отставший читаемый обзор: страницы SRD2 203–205 были уже прочитаны и классифицированы позднее. Источник и история сохранены, повторного сканирования не было. Поддержка приложения по каждому профилю остаётся **не проверено**, а не «отсутствует». Старые 008/042/043/047/051/054 не восстанавливать и не использовать для расширения текущей очереди.

Рейтинг, методика, score, общие реестры и очередь не менялись. Дальше **VAARN**, затем сверка полного свежего инвентаря разобранных игр до закрытия всей ретроспективы. После неё — незавершённое полное выравнивание overall top5, затем свежий create-top10. Решений владельца для продолжения не требуется.

Предыдущие ревизии: [Cairn 2e](../market/rules/Cairn-2e-scope-review.md), [ROOT](../market/rules/ROOT-scope-review.md); полный курс и история — в [state.json](state.json) и [плане](work-plan.json).
