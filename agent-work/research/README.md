# Исследования игр HexCrawl

[TOR2: авторские карты и зоны](market/TOR2-map-boundary-2026-11-12.md). Завершён первичный корпус: подготовка гексового слоя для 2E, смешанный 1e/2e/homebrew-проект Wonderdraft, две страницы карт с просмотренными превью. Новое — конкретная работа с готовой географией и граница между PNG и редактируемым проектом.

Публичные счётчики товаров — 17 и 28 приобретений, отдельно: период, платность, редакция и пересечение покупателей неизвестны. Это не 45 активных мастеров. Нулевой create-вход не доказывает отсутствия картографической работы; нового p не предложено. Рейтинг, методика, когорты, score, backlog и основная очередь сохранены.

JSON содержит 3 operational_requirement и 9 примеров, со ссылками на существующие 044/027. Новых задач нет; 027 не возобновлена. Финальные правила и runtime не объявлены проверенными. Ошибки доступа сохранены в результате запуска.

Новых решений владельцу нет. Следующий выбранный срез — сверка труднопроходимости/опасности DND5/PF2/Knave с фактической реализацией 044 на точном SHA. Выбор пересматривается по свежим claims. Предыдущие [TW2000](market/TW2000-create-zero-2026-11-12.md), [Worldographer](resources/Worldographer-L1-2026-11-12.md) и импортный checkpoint HexAtlas сохранены.
