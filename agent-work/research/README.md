# Исследования игр HexCrawl

**Завершён полный каталог географических таблиц Cairn 2e Setting Seeds:** 13 таблиц, 25 колонок, 411 текстовых результатов. [Вывод и границы](catalogs/CAIRN2-SettingSeeds-geography-v1.md) · [JSON](catalogs/CAIRN2-SettingSeeds-geography-v1.json) · [Проверка](catalogs/CAIRN2-SettingSeeds-geography-v1-verification.json).

Все клетки сверены между официальной страницей и закреплённой редакцией официального Markdown. Есть стабильные ID, строки источника, атрибуция и лицензия. Проверены диапазоны, независимые колонки и известные выходы. Для сезонной погоды нельзя использовать одну строку на все сезоны; POI = 1 сохраняет выбор Waypoint или Settlement.

Предыдущие 14 конкретных операций остаются в [единственной игровой матрице](../market/rules/Cairn-2e.json). Полный источник таблиц теперь связан с ними; дублирующий реестр правил не создавался. Подключение в приложение и цифровая геометрия этим не подтверждены.

HX-BL-055 остаётся proposed; нового решения владельцу нет. Рейтинг, численная методика и очередь 051 → TABLES1 → PF2 сохранены. Текущие TABLES1 и отдельная работа по завершению PR496 не затронуты.

Следующий выбор — существенный рыночный пробел или новый сильный кандидат по свежим источникам. Законченные процедуры и каталог Cairn не повторять; вопросы цифрового профиля решать при его выборе стратегом.
