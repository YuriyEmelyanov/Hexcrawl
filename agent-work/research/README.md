Ядро умеет выбирать terminal строку d100, воспроизводимо бросать кости, хранить значения и редактировать интерпретацию. Семь компонентных проверок прошли. Это отдельный модуль, а не полный пользовательский цикл.

**Не нужен второй движок на Knave.** Предлагается общий адаптер ручного выбора, независимых вхождений A,A, происхождения результата и ограниченных ссылочных переходов. Прямой повтор rollTag сейчас заменяет прежний результат; это штатный переброс MB, который нельзя ошибочно принять за сохранение двух компонентов Knave. В опубликованном обработчике используется mythicDefinitions, а пассивный импорт неизвестного тега не делает новый профиль доступным в UI.

Пути document transaction, JSON export/import и remap при переносе POI найдены статически. Полный браузерный save/load/Undo/Redo пока **unknown**, покрытие KNAVE2-070/071 и баллы не повышались. HX-BL-043 остаётся **proposed**; разработка и публикация не запускались.
