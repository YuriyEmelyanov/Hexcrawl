# Исследования игр HexCrawl

[HexAtlas: размер рисунка и заполнение территории](resources/HexAtlas-footprint-fill-2026-11-12.md). На пяти исходных экспортных снимках проверены три операции: Size 1↔6 меняет только размер рисунка POI при той же географии; Fill по пустому соседнему месту не добавил ячеек; Fill Desert по существующему лесу перекрасил ровно шесть ячеек, сохранив водный гекс и POI.

Вывод: размер значка не доказательство физической площади объекта, а Flood Fill — не достраивание свободной части региона. Для HX-BL-051 эти результаты проверяются отдельно. Другие режимы HexAtlas исчерпывающе не обследованы; глобальная уникальность HexCrawl не заявлена.

[Карточки проверены ранее](resources/HexAtlas-local-cards-2026-11-12.md), как и [правка, Undo/Redo и reload](resources/HexAtlas-retained-lifecycle-2026-11-11.md). Успешный импорт остаётся прежним внешним блокером; chooser не повторялся. Закрытые проверки не повторять без нового основания.

Следующий выбранный результат — законченный тематический корпус текущего руководства Worldographer по уровням, размеру объектов и сохранению содержимого. Рейтинг, численная методика, score, backlog, чужие claims и очередь ONE-MILE1/PR503 не изменены. Новых решений владельцу нет; обе автоматизации проверены включёнными.
