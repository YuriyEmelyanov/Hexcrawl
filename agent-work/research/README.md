У Yora найдено прямое описание созданной карты и её переработки. Незавершённая большая настенная версия не означает отсутствие всех карт. Восемь статей одного автора не стали восемью ведущими; прежняя сыгранная кампания была D&D5e, другие планы — Dragonbane и D&D3e.

Подтверждён рабочий процесс: GIMP для сетки, бумага/карандаш для быстрых исправлений контуров, печать и сканирование. Масштаб 3 мили — авторская адаптация, не установленное официальное требование. Dormir остаётся индексированным сообщением о частном заказе; сессии и потребность заказчика не подтверждены.

Рейтинг, методика, исторические входы и очередь не изменены. Новых продуктовых задач и решений владельцу нет. [Trudvang](candidates/Dragonbane-Trudvang-screen-2026-11-10.md) остаётся отдельным watch-кандидатом.
