# Исследования игр HexCrawl

[HexAtlas: локальная карточка и смешанная территория](resources/HexAtlas-local-cards-2026-11-12.md). Проверено: выбор дочернего Region-гекса с видимой пустынной правкой открывает родительскую карточку Mountain. Выбор смешанной группы Continent из 7 ячеек (5 forest, mountain, coast) открывает обычную карточку центра Forest, без сводки трёх биомов и POI.

Вывод: наличие нескольких масштабов и редактирования мелкой сетки не доказывает эквивалентность локальных/агрегированных карточек. Это ограниченный результат проверенных сценариев, не отсутствие функции во всём HexAtlas и не доказательство уникальности HexCrawl. Сохранены JSON, DOM и два фактических снимка.

Ранее [подтверждены правка, Undo/Redo и reload](resources/HexAtlas-retained-lifecycle-2026-11-11.md). Импорт остаётся блокированным прежним зависшим chooser; его не повторяли. Следующий шаг того же benchmark — площадь POI и заполнение частично занятой территории с сохранением прежней географии.

Рейтинг, численная методика, score, реестры, backlog и очередь ONE-MILE1/PR503 не изменены. Новых решений владельцу нет. Обе автоматизации проверены включёнными; это не заменяет evidence исследования.
