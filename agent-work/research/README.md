# Исследования игр HexCrawl

[HexAtlas: проверенный цикл правки и сохранения](resources/HexAtlas-retained-lifecycle-2026-11-11.md). Шесть исходных JSON сохранены в GitHub: правка одной ячейки, Undo/Redo, смена настроек и уровней, перезагрузка. Проверены все поля POI, заметка, привязки и точки дороги; после перезагрузки отличается только exportMetadata.

Новое знание: редактируемая многоуровневая карта с обратимой правкой и восстановлением уже есть у конкурента. Базовые сохранность и Undo/Redo не являются доказанным отличием HexCrawl. Наблюдались 1,5/6/24 мили; точная лестница 1/6/12/24 не подтверждена.

Импорт остался внешним блокером: выбор файла завис и был прерван. Дефект HexAtlas не установлен. Следующий выбранный шаг — законченная проверка локальных карточек и смешанного состава гекса на сохранённом наборе; импорт возобновлять только с рабочим документированным способом загрузки.

Почему сейчас: это завершает недостающую доказательную часть прежней проверки; повтор L1-аудита Knave 2e без нового основания менее полезен. Новых решений владельцу нет; обе автоматизации проверены включёнными.
