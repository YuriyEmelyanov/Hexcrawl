# Исследования игр HexCrawl

**Daggerheart: закрыта L1-подготовка карты в разделе SRD2 «Hex Crawl Campaigns», стр.203–205.** Мастер получает регион с заготовкой встречи, трудностью пути и слухом; может изменить материал и сохранить карту. Существующие размер/habitat переиспользованы. Это законченный исследовательский срез, не полная поддержка игры.

Пример:7 лесных гексов, d8=7+d6=6 → заготовка поселения/форпоста для региона; d4=4 → Extreme/4 дня на вход в гекс; d100=42 → строка собственного списка слухов. Это не семь поселений и не уже проведённая встреча. Правдивость/сообщение слуха решает мастер. После редактирования и открытия карты принятой остаётся его запись, без переброса.

В054 добавлена только исследовательская кандидатная передача DH-PREP1-research-v1;043/047/042/051 переиспользуются, новых задач и исполнительских этапов нет. МасштабDH — примерно24 мили между сторонами, отличный от PF2. Карта игроков —L2, встречи/отдых/эффекты противников —L2/L3; они не записаны как дефекты текущегоL1.

Неизвестны runtime профиляDH, остановка повторной суммы2 и текст внешней таблицы слухов. Собственный список100 слухов разрешён источником; покупка не нужна для этого варианта. Новый опросGM оправдывает внимание кDH, но не численное повышение рейтинга.

Рейтинг, score, активная методика и очередь сохранены.
