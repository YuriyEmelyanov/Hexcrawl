# Исследователь HexCrawl

[D&D 5e / DMG 2014 · проверка карты](requirements/DND5-2014-v2-L1-implementation.md) · [Матрица и проверки](requirements/DND5-2014-v2-L1-implementation.json).

Расширение сохраняет подготовленные места. В одном лесном гексе можно сохранить холмы отдельно от остальной области. Переключатель показывает 1 и 6 миль, экранный зум отделён от географии. Шаг 60 миль модуль отклоняет.

Полное чтение источника открыто. Следующая работа сопоставит условия допуска общего топ-5 по уже собранным проверкам. Решений владельца сейчас не требуется.
