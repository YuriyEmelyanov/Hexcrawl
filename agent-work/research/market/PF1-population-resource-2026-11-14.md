# PF1: независимый ресурс раскрытых продаж

Проверен один исторический ресурс — Humble RPG Book Bundle: Pathfinder2016. [Интервью с Paizo](https://icv2.com/articles/news/view/34011/pathfinder-humble-bundle-hits-1-298-million) сообщает77 499продаж; [материал с данными Humble](https://www.publishersweekly.com/pw/print/20160321/69718-humble-bundle-had-6-1-million-in-2015-e-book-revenue.html) —77 503. Оба описывают одну завершённую кампанию, не две аудитории. Причина расхождения4не установлена; среднее и сумма не используются.

| Что установлено | Граница применения |
|---|---|
| Объявленный период24февраля–9марта2016; core+дополнения; PWYW | Точный момент закрытия/распределение по tiers неизвестны; это продажи наборов, не отдельныхPDF или только core |
| Около77,5тыс. сообщённых продаж | Исторический масштаб приобретения, не число нынешних ведущих |
| По словам издателя, примерно2/3впервые регистрировались вPaizo | Новизна аккаунта не доказывает нового игрока, проведённую игру или роль мастера |
| Издатель выводит из этого не менее50тыс. новых игроков | Это его интерпретация; отдельное измерение игры/retention не предъявлено |
| Отдельный последующий набор комиксов | Не прибавляется к RPG-счётчику/аудитории |

Издание отнесено кPF1 по идентичности кампании2016 и [официальному запускуPF2в2019](https://paizo.com/blog/pathfinder-second-edition-launches-now). DirectPaizoстраницы вернули403; их индексированный текст помеченsearch_snippet. Интервью/републикованный пресс-релиз прочитаны полностью. Детали и локаторы — [JSON](PF1-population-resource-2026-11-14.json).

**Решение:** сохранить как независимое историческое evidence о продажах, не вводить его вactive anchors/M/p. Разница4в счётчиках мала по смыслу задачи, но неизвестный переход покупка2016→активныйведущий2026→собственнаярегиональнаякарта остаётся главным ограничением. Продажи больше нынешнего экспертногоM не доказывают занижениеM: разные единицы и период.

Это новый пригодный качественный ресурс, а не новая метрика или численный коэффициент. Вobservationsдобавлены4записи с одним ключомкампании; формат/дубли проверены. Рейтингv1.4/входы/места/когорты/методика/score и очередь разработки сохранены. Новых правил/продуктовых задач/согласований нет. Отдельный редактор PF1 по-прежнему не следует из продаж; предыдущая проверка L1 сохранена.

Поиск Foundry не выявил нового годового среза сверх уже разобранного2026; повторного расчёта не было. Следующий выбранный кандидат — ресурс PF1organised play: пригодность публичного расписания/уникальных мастеров для отдельного, ограниченного по месту/периоду среза, без экстраполяции клуба на весь рынок. Перед выбором проверить новизну корпуса и актуальные приоритеты.
