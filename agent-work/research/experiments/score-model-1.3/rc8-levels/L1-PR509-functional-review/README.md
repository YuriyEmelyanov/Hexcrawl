## Что это даёт мастеру

- На 20 малых картах мастер достроил соседнюю область и сохранил старые гексы. Настольный P95 составил 1,10 с при создании и 0,92 с при расширении. В новом испытании мастер переименовал две соседние области и поселение. После открытия на чистом экземпляре восстановились документ и генератор. Поиск привёл в прежние координаты (3,6), (3,7) и (3,6). [Сценарий и результат](territory-probe-result.json).
- В Mythic Bastionland сработали все 7 зарегистрированных операций, включая шесть мест мифов и одно владение с резиденцией правителя плюс три остальных. У правила Провидцев проверены две контрольные пары. Проверка остальных 70 текстов открыта. Время генерации королевства с целью 144 гекса выходит за 1,51 с во всех 20 испытаниях, отдельный бюджет целого королевства не утверждён.
- Для D&D 5e мастер может нарастить карту и подготовить рельеф. Для PF2 он может найти поселение, но при составлении обзорной карты выборочно убрать деревню из представления с сохранением исходной карты не удалось. Для Shadowdark имя места следует за объектом при переносе, а заметка старой клетки может остаться на прежнем месте. Полный балл за соответствующие операции преждевременен.

## Как читать и воспроизводить оценку

Общая шкала 1000. У каждой из трёх частей один и тот же вес. Внутри ядра сохранены веса 34 критериев, сумма 675. Рабочий балл ядра равен сумме произведений веса на наблюдаемую ступень G/4, делённой на 675 и умноженной на 1000. Ограниченное подтверждение даёт G1, обычная рабочая операция — G2. Четыре неизвестные ступени не дают заработанных баллов. Приёмка G3/G4 требует дополнительных свидетельств, включая сохранность, производительность, варианты режима или пользовательские испытания там, где они предусмотрены.

Игровая треть — среднее 20 отдельных долей, по 16⅔ итогового балла на игру. Каждая операция имеет положительный вес 1000/(3×20×число операций своей игры). Полная даёт 1, частичная в отсутствие разложения — ½, при наличии разложения используется фактическая доля пройденных случаев. Неизвестная сохраняет статус и пока не приносит баллов. Например, переход одной операции D&D 5e из частичной в полную даёт +0,521 балла к функциональному L1 при неизменном перечне. Расширение перечня требует новой версии знаменателя. Переход теста качества влияет на отдельный строгий результат.

Все 430 повторно запущенных Node-тестов дерева PR509 прошли. Они подтверждают свойства своих сценариев. Для строгой приёмки действуют утверждённые профили действий с P95, максимальной задержкой, устройствами и сохранением результата. На неизменном прежнем перечне строгий минимум 5,75. На расширенном перечне он равен 9,91 за счёт повторного использования настольного теста расширения для той же операции в AWN и S&W. Формальный интервал на новом перечне при нулевом рынке 9,91–612,88. Это пределы на перечисленных строках. Ни один из 20 тематических корпусов пока не закрыт целиком.

Ближайшая проверка для приёмщика — на среднем Android повторить по 20 созданий и расширений Classic с seed 42–61, сверить P95 с 3 с, максимум с 10 с и после открытия сравнить старый регион и состояние генератора. Она проверяет один общий механизм сразу для нескольких игр. Для роста полноты игрового перечня в первую очередь требуется полный тематический проход первой игры с новым срезом — Pirate Borg (№10). Исследование рынка для этого результата не требуется.

## Передача стратегу

Из действующего бэклога по результатам аудита рекомендована [HX-BL-062 — обнаружение POI в Classic](https://github.com/YuriyEmelyanov/Hexcrawl/blob/5a3b281858f18090b18e57fba462470c9c860199/agent-work/backlog.json). Критерий приёмки для существующего типа — в чистом Classic создать место, проверить назначенную категорию, изменить её, перенести объект и после импорта сверить категорию у того же объекта. У HX-BL-061 (плавные повороты рек и дорог) другой результат — качество геометрии. Для 062 уже воспроизведён пробел в рабочем пути D&D и Shadowdark. Скрытие объекта на карте для игроков остаётся отдельным условием и не закрывается одним полем обнаружения.
