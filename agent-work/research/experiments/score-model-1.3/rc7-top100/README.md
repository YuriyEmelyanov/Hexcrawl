# Место HexCrawl среди приложений · модель 1.3-rc7

Владелец определил цель 20.11.2026. Вход в первую сотню приложений даёт первые рыночные баллы. Первое место означает лидерство при любой доле рынка. В rc5 рост оценки зависел от процента рынка и 1000 требовали полного охвата. В rc7 место приложения определяет рыночные баллы. Доля и число пользователей служат самостоятельными показателями рядом. Готовность функций и поддержка правил сохраняют собственные баллы даже до входа приложения в топ-100.

**На утверждение предложена линейная шкала 0–1000.** Для подтверждённого места r рыночные баллы равны 10 × max(0, 101 − r). При равенстве сопоставимых аудиторий предлагаем делить место: два приложения на первом месте получают 1000, следующее занимает третье. Первое место при равенстве отмечается как совместное лидерство. Победитель на рынке с долей 20% получает те же 1000 рыночных баллов, что и победитель с долей 60%.

| Место | Рыночные баллы |
|---:|---:|
| 101 и ниже | 0 |
| 100 | 10 |
| 99 | 20 |
| 50 | 510 |
| 2 | 990 |
| 1 | 1000 |

В отчёте по модели показывать готовность продукта, аудиторию, место среди приложений и рыночные баллы. Место в общем рынке считается по уникальным внешним пользователям, посетившим инструмент за одни и те же 28 завершённых дней. Каталог сравнения включает приложения для подготовки региональных гекс-карт или ведения гекскроула. Для универсального инструмента нужны пользователи сопоставимого назначения. Источники, допущения и полноту каталога фиксировать на дату замера. Для отдельных срезов L1 и L2 требуются сопоставимые аудитории соответствующего сценария. Для L3 отдельный рынок пока не определён. Общие посещения и сегменты считаются по [rc6](../rc6-visitors/README.md). Топ-20 НРИ определяет приоритет поддержки игр, отдельно от списка конкурирующих приложений.

**Неопределённость места.** Объединяем повторные публикации об одном приложении. У каждого инструмента указываем нижнюю и, если доступна, верхнюю границу числа уникальных пользователей. Лучшее возможное место равно единице плюс число известных приложений, гарантированно опережающих HexCrawl. Худшее возможное место равно единице плюс число известных конкурентов, которые могут опережать HexCrawl, плюс обоснованный максимум пропущенных конкурентов. При неизвестном максимуме пропущенных худшее место открыто. При наличии только нижних оценок сортировка по ним полезна для поиска конкурентов, но обычно недостаточна для доказательства места. Для рыночных баллов нужен хотя бы один внешний пользователь. Пока возможный диапазон пересекает границу топ-100, гарантированный кредит равен нулю, а само место остаётся неопределённым. Если подтверждены места 99–100, гарантированно заработано 10, возможно 20. Подтверждённые 100 конкурентов впереди устанавливают ноль даже при незакрытом каталоге.

**Исходная оценка.** В rc6 за 23 октября – 19 ноября 2026 нет сопоставимого измерения аудитории HexCrawl и полного сравнения. Текущее место неизвестно. Доказанных рыночных баллов 0, фактическое значение открыто. Нового измерения аудитории при этой поправке не проводилось. Ранги и состав когорт НРИ, численные веса продуктового рейтинга и действующие баллы в этой редакции эксперимента не менялись.

Проверка граничных мест, совместного лидерства и неполных данных: `node market-rank.mjs --test`. Расчёт границ: `node market-rank.mjs baseline.json`. В baseline.json неизвестная верхняя граница задана null.
