# HexCrawl 1.3.0-rc2-scenarios · прогресс и лидерство

Предложение владельцу к версии 1.3.0-rc1. Выпуск PR509, `d6daa2cdbc1c17b942d51fe050fac51752cf9fee`. Меняются выбор игр в знаменателе и представление в баллах. Рыночный рейтинг, веса игровых слотов и исходные приёмки взяты из зафиксированных данных. Решение об активной методике остаётся за владельцем.

| Цель | Сценарный топ | Подтверждено из 1000 за правила | Остаток до 1000 | Игры с разобранными требованиями уровня | Полностью подтверждены по всему корпусу | Общие критерии уровня |
|---|---|---:|---:|---:|---:|---:|
| L1. Создание и подготовка карты | create | 298,44 | 701,56 | 12/20 | 0/20 | 10,5/16 = 656,25/1000 |
| L2. Ведение гекскроула | play_now | 4,79 | 995,21 | 10/20 | 0/20 | 0/2 = 0/1000 |
| L3. Сопутствующие механики | Требуется определить когорту и корпус интеграций | — | — | — | — | — |

**Почему исправление важно.** В rc1 разные списки задавали приоритет работ, но функция report применяла общий топ ко всем уровням оценки. В сценарных топ-20 совпадают 12 игр. В create Mythic Bastionland пятая, в play_now — шестнадцатая. «Развитие имеющейся карты» остаётся отдельной рыночной осью develop для выбора задач по редактированию и наполнению. Сравнение именно этого пользовательского сценария потребует отмечать его приёмки отдельно. L3 не получает список develop автоматически.

**Операция → баллы.** Каждый игровой слот имеет 1000/N баллов, где N — число игр в опубликованной сценарной когорте (сейчас 20). Его заработанная доля равна сумме подтверждённых кредитов правил игры этого уровня, делённой на число применимых уникальных правил. Подтверждённая часть учитывается дробно по правилам rc1. Отсутствующий корпус оставляет игровой слот в знаменателе и пока не даёт доказанных баллов. Это нижняя оценка по текущему каталогу. Правило из игры, которая входит только в один сценарный топ, влияет только на соответствующий уровень. Если она присутствует в обоих, на каждом уровне нужна его собственная приёмка. Приоритет разработки внутри уровня даёт сценарный ранг. Ранги не используются в качестве количественных долей рынка.

**Общие функции.** Сохранность карты, читаемость, масштабы и другие общие критерии имеют собственный знаменатель. Их можно показывать на шкале 1000, не суммируя с игровыми баллами. Для управленческой цели «полная поддержка топ-20» отдельно считать число игр с закрытым тематическим корпусом и всеми выполненными требованиями. Даже результат 100% на небольшом извлечённом корпусе не сертифицирует всю игру.

**Динамика.** Сравнивать предыдущий и новый релиз по одной версии каталога и когорты. Отдельно публиковать пересчёт старого релиза при изменении состава топа или требований. PR509 дал +50/29 = +1,7241379 игрового балла L1 за проверенную комбинацию гор и снега PF2 и +1000/16 = +62,5 по общей шкале L1 за ручное редактирование биома. Для L2 в собранных сравнениях PR509 положительная дельта не доказана. Все десять ранее разобранных PR пересчитаны в report.json. Пустая выборка проверенных изменений конкретного PR не доказывает отсутствие всех эффектов. Изменение методики на том же PR509 даёт нулевую дельту подтверждённой суммы при разных составах групп; это совпадение текущих входов. Условная чувствительность SD-031 (+0,5 из 18 при согласии учитывать слой Knave) даёт +1,3889 игрового балла L1 и не входит в базу.

**Как установить лидерство.** Сохранить официальный продуктовый контроль 1.2 (50 критериев, 1000 возможных, текущий полный балл неизвестен). Его действующие условия — минимум 950/1000, каждый из 10 шагов не ниже 80%, шаг внешнего подтверждения не ниже 60/70, отсутствие критических дефектов и внешнее подтверждение. Полная цель — 1000/1000, все критерии G4. Два показателя готовности в таблице основаны на другой методике; порог 950 из 1.2 применяется к официальному итогу 1.2.

Для заявления о лидерстве в отдельном уровне фиксировать редакции игр, соперников и критерии победы заранее, отдельно собирать результат одинаковых задач у HexCrawl и аналогов. Для L1 — восстановить карту, найти заданное поселение, изменить масштаб, исправить объект и восстановить правку. Для L2 — провести также заданный переход партии, обработать обнаружение и восстановить следующую сессию. Оценить успешность, потерю данных, время и действия мастера. При переносе планки G4 шага 10 на отдельный уровень — минимум пять ведущих аналогов и первое место на одинаковых сценариях; слепой тест не менее 50 мастеров, ≥60% выбирают HexCrawl лучшим и отрыв ≥15 п. п. Полный набор внешних критериев и пороги использования указаны в действующей [модели](../../../../strategy/score-model.md). До внешней проверки статус лидерства по каждому уровню открыт.

**Воспроизведение.** Запустить `node scenario-score.mjs` из этой папки. Калькулятор сверяет обе когорты с baseline, использует принятую функцию дробного зачёта rc1, пересчитывает десять PR и проверяет изоляцию групп на примерах SI и TOR2.
