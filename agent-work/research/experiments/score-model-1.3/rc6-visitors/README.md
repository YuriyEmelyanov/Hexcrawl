# Пользователи инструмента и консервативное сравнение · 1.3-rc6

Основание — решение владельца 20.11.2026. Факт использования HexCrawl подтверждает посещение самого приложения внешним человеком. Сохранение карты, запуск сессии и выбор конкретной игры для зачёта пользователя не требуются. Повторный визит того же пользователя в том же окне учитывается один раз. В модели rc5 требовались более глубокие действия; настоящее решение заменяет это условие для общего охвата. Пороги технической приёмки продолжают относиться к готовности функций.

## Какие числа показывать владельцу

* По каждому инструменту: период, единица, измеренная или заявленная аудитория, независимо подтверждённый минимум, источник, охват источника и возможные дубли. В сравнительной таблице указывать отдельно пользовательский минимум и масштаб аудитории по косвенным данным. Сортировка минимумов ранжирует доступные доказательства; вывод о фактическом лидерстве требует сопоставимых границ.
* Для HexCrawl базовый отчёт — уникальные посетители приложения за выбранное окно из статистики посещаемости, с исключением роботов, тестов и собственных заходов. Для нативного приложения эквивалент — открытие программы. Показатели cookie/устройств сохранять как оперативную оценку числа посетителей. Для гарантированного минимума людей объединять известные повторные идентичности. Если известен только факт человеческого визита с нескольких несвязанных устройств, надёжно установлен один человек. Регистрация и отдельное наблюдение за каждым мастером не нужны для обычного подсчёта посетителей.
* Для конкурента вначале искать опубликованных уникальных пользователей за то же окно; допустим датированный минимум по независимым авторам, отзывам от первого лица с признаками фактического использования и опубликованным работам. Одинаковых людей и перепечатки сводить. При возможном пересечении двух массивов использовать максимум нижних границ, если непересечение не доказано. Модельные посещения, продажи, установки и количество карт указывать с исходной единицей. Если известен гарантированный максимум k действий на человека, T проверенных человеческих действий дают минимум ceil(T/k). Без такого ограничения переводить все действия в людей нельзя.
* Для сегментов L1/L2 и игр — только фактически известная принадлежность; один пользователь может входить в несколько сегментов. Общий зачёт при неизвестном сегменте сохраняется. Цели export_json, повторное открытие, сегменты и удержание отвечают на вопросы о поведении. Ими не фильтруется посещаемость.

## Как учитывать результат в рейтинге

Всегда выводить абсолютный подтверждённый прирост аудитории рядом с готовностью. Не распределять посетителей неизвестного профиля по уровням или играм. Правило rc5 для балла реализованного охвата использует долю в совместимой совокупности. Гарантированная нижняя доля = минимум людей HexCrawl / верхняя граница общего числа уникальных пользователей объявленного рынка за тот же период. Опрос — один из способов уточнения, для подсчёта пользователей и работы с конкурентными оценками он необязателен. При известных только минимумах конкурентов отношение минимумов можно показать как ориентир по обнаруженным аудиториям с явной меткой. Оно не даёт гарантированного процента рынка. Для процента по сегменту требуется сопоставимый сегмент у числителя и знаменателя. Действующие места игр и продуктовые баллы сохраняются до отдельного утверждения версии численной модели.

## Первая выборка

* Worldographer: за историю подтверждены как минимум два отдельных автора: Brian C. Rideout (карта кампании Dungeon Crawl Classics) и Sean (Mighty Empires). Ссылки и даты в sources.json. Повторы публикаций того же проекта не прибавляют людей. Строгий минимум демонстрирует работу метода, его нельзя трактовать как оценку всей клиентской базы.
* Inkarnate: издатель заявляет 2 млн+ создателей миров для продукта в целом. Записываем отдельным косвенным ориентиром масштаба. Период, метод исключения дублей и доля пользователей гекс-карт не раскрыты. 16 млн+ созданных карт — другая единица.
* HexCrawl: исходная управленческая оценка владельца — 0. В распоряжении исследователя нет выгрузки уникальных посетителей. За 23 октября — 19 ноября 2026 года сопоставимых измерений в этих источниках нет. Архивные примеры не переносятся в свежий период.

Проверка: node visitors.mjs --test; node visitors.mjs < sources.json. Подтверждённые минимумы — в report.json, заявленные издателем и прочие косвенные данные — в sources.json.
