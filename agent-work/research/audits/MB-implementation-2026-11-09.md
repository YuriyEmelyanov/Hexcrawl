# Mythic Bastionland: что уже реализовано

Проверен опубликованный `main` **a246fdf292963fd534a8203f569b9ca48b6292c7**, 9 ноября 2026. Это сопоставление девяти уже разобранных L1-профилей с кодом и текущими проверками, не полный аудит книги.

Основной режим уже реализует большую часть разобранной подготовки карты. Прежнее blanket «реализация unknown» не означало отсутствие функций. Полные исследовательские примеры местами предлагали дополнительные операции сверх текста; они не становятся обязательным ТЗ.

| Правило/возможность | Фактическое состояние | Ограничение |
|---|---|---|
| Группы d12 | Есть равномерные цели 1–12; свободные 1/7/12 проверены | Первый регион 11/12, карманы увеличивают размер: решения владельца |
| Четыре владения, один Престол | Генерация 1+3 и сохранение работают | Ручное редактирование не переносит роль/не перебалансирует квоты |
| Шесть мест мифов | Есть, в разных диких регионах, с именами и кубами | Номера 1–6 отсутствуют по ТЗ владельца; численная удалённость неизвестна |
| Шесть типов ориентиров | По 3–4 каждого, значки, сохранение | Заданный вектор квот из исследовательских примеров не отдельная готовая функция |
| Барьеры | 24 на 144 гекса = N/6; грани, ручные правки, дороги, сохранение | Универсальные размеры края не входят в текущий режим; движение партии относится к L2 |
| Провидец святилища | Прямой d6+d12 lookup, имя/кубы/переброс/сохранение | Первично сверены пары 1/1 и 1/2; остальные 70 карточек повторно не прочитаны |
| Руины: атмосферный намёк | Описание уже поддерживается | Обязательная механическая связь/фильтр не нужны |
| Отдельная карта игроков | Будущий этап L2 VTT | Не считать пробелом текущего L1 |

В опубликованном коде присутствуют 72 имени мифов, 432 подсказки ориентиров, 72 имени Провидцев и 72 справочных материала мифов. Совпадение каталогов проверено; это не повторная сверка всей транскрипции с оригиналом. Большая часть английских текстов использует русский fallback.

## Уточнение владельца 9 ноября 2026

Уточнение владельца 09.11.2026: руины — атмосферное описание. Проверка списка активных мифов, обязательная связь/фильтр/переброс не требуются как механика L1. Карта игроков относится к следующему общему этапу L2 VTT/ведения гекскроула, а не к недостающим правилам текущего генератора.

Прежние два вывода ниже заменены этим решением; они не являются текущими пробелами L1.

## Что учтено после уточнения

- По **HX-BL-053** отозвана интерпретация обязательной связи руин с неактивным мифом. Атмосферное описание уже поддерживается.
- Карта игроков в **HX-BL-044** относится к будущему общему этапу **L2 VTT/ведения гекскроула**, а не к недостающим правилам текущей подготовки карты.
- Не начинать заново квоты, d12, Провидцев или сохранения. Прямой выбор Провидца по соответствующему каталогу эквивалентен обращению к странице рыцаря для проверенных исходов; новая функция ради промежуточной ссылки не нужна.
- Номера мифов и автоматическую перебалансировку после правки не добавлять молча: это изменение прежних решений владельца.
