В PR496 таблица умолчаний совпадает с CLASSIFY1; валидатор допускает JSONv11 иv14. Реальные обработчики App проверены через существующий harness с имитацией React hooks, без DOM-браузера: **4 существующих теста и42 адресные проверки прошли**. Проверены manual dangerous/normal/difficult/unknown/auto, скрытие normal/unknown в чтении, сохранение и повторный импорт, Undo/Redo, переход к детализации и JSONv14. На заданной карте сохранились рельеф, POI, заметки и RNG.

Ключевое различие: unknown — явное подавление умолчания, auto — его восстановление. Для лесного гекса normal не равен auto. dangerous — одна из утверждённых категорий, не второй независимый флаг. Исследовательский пример двух осей из TOR2 не становится поручением переделать утверждённую политику.
