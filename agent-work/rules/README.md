# Единая система правил HexCrawl

## Общие правила и профили игр — 4 ноября 2026

Решение владельца: одинаковая суть правила разных игр хранится один раз. Главный реестр: agent-work/rules/common-rules.json. Игровые источники/редакции привязываются через agent-work/rules/game-bindings.json. Исходные цитаты/пересказы и страницы сохраняются; это свидетельства, не отдельные реализации.

Перед добавлением правила аналитик ищет общий rule_id по действию, входным данным, результату и инвариантам, а не словам. Та же суть — добавить привязку/профиль. Числа, единицы, граничные условия, обязательность, исключения и варианты задаются профилем. Иная процедура/результат — отдельное правило. Составное положение книги разбивается на несколько общих правил; его полное покрытие требует всех применимых компонентов. Одно общее правило может частично закрыть несколько исходных положений.

Стратег выбирает пробелы общих правил и показывает все затрагиваемые проверенные игровые профили (обратный индекс binding_ids). Программист реализует общее правило/адаптер один раз. Проверяющий сохраняет evidence exactSHA, профиль входов/исключений, метод и ссылку на проверку. Совпадающие проверенные профили разных игр используют одно evidence автоматически; отличающийся профиль требует проверки именно отличий, не дублирования реализации. Непроверенные параметры не считаются совместимыми по умолчанию. Положения других НРИ нельзя создавать без источника.

Производное покрытие вычисляется evaluate-coverage.py из rules/bindings/evidence/release_sha. Непроверенные профили/evidence=unverified; совпадение строкиrule_id само по себе не даётfull. СменаSHAне переносит evidence автоматически: требуется проверенная применимость evidence к новому пакету. Конфликтующие результаты требуют разрешения. fullпоодному компоненту даётpartialдлясоставного требования, не полную поддержку игры. Баллы начисляются за общий продуктовый результат один раз; широта выводится отдельно по играм, не суммой дублированных баллов.

Начальное наполнение: только ранее разобранные28правилDND5/51применимое требование, нормализованные в общие правила/составные привязки. Другие игры пока не привязаны; PF2будет следующим исходным корпусом после отдельного разбора. Никаких новых подтверждений реализации/изменений50весов/баллов/очереди этот пакет не содержит.


Пример: физический масштаб гекса — одно общее правило. D&D и PF2ссылаются на него с собственными значениями, единицами и способом измерения. Поддержка одного размера не доказывает поддержку другого; один проверенный механизм может покрыть оба после проверки обоих профилей. Это иллюстрация модели, не уже подтверждённый разборPF2.

## Формат evidence

`{id,rule_id,release_sha,review_status:"verified",status:"full|partial|absent",profile:{parameters,exceptions,conditions},method,evidence_ref}`

Не включать имя игры в ключ совместимости: совместимость определяется значением профиля. Происхождение сохраняется в source/game/edition/page полях привязки. Нельзя удалять различие профилей ради переиспользования evidence. Исторические наблюденияDNDостаются в traceability; рабочий evidenceпока пуст.
