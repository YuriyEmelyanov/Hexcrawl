# HX-BL-074 · Интервью MANUAL-DELTA · раунд 001

Черновик D1 проверен целиком. Согласованные границы не переоткрываются. Для решения владельца остались три существенные развилки.

| ID | Решение | Варианты | Рекомендация |
| --- | --- | --- | --- |
| DELTA-Q01 | Вход в создание рукава | A — из карточки выбранной реки. B — из общей команды «Добавить реку». | A |
| DELTA-Q02 | Полноводность нового рукава | A — обязательный явный выбор допустимого значения. B — максимальное допустимое значение по умолчанию с возможностью изменить. | A |
| DELTA-Q03 | Пересечение с дорогой или тропой | A — предпросмотр, мост по умолчанию и допустимые альтернативы. B — обязательный явный выбор. C — отказ в первом выпуске. | A |

Полные последствия и связи с требованиями хранятся в `round-001.json`.

## Уточнение без решения владельца

D74-AC01 следует воспроизводить на исходной версии после удаления только существующего рукава. Иначе занятое ребро смешивает исходный продуктовый пробел со штатным конфликтом. Аналитик исправляет порядок шагов в чистовой спецификации.
