## BIO-Q04. Частоты

Причина: Даже неизменные старые веса дают другие нормированные вероятности после добавления новых.

- **A — Начать с редких: вес1 каждому новому варианту.** Старые веса не меняются; для запрещённых Q03 типов вес0. Равный вес не означает равный итоговый шанс из-за высоты/соседей.
- **B — Делегировать аналитику разные частоты по семействам.** Аналитик фиксирует точные числа и обоснование до разработки, старые веса сохраняются.
- **C — Задать собственные числа.** Веса фиксируются для каждого нового варианта и разрешённого типа; без чисел контракт остаётся открытым.

Рекомендация: **A**, Сохранить утверждённый объём и действующие механизмы, сократить риск скрытого расширения; это предложение, не решение владельца.

Условие: Требуется приBIO-Q03=A/B; приC отложить вместе с Авто.

Связи: R03, R10, AC03, AC04. Собственный вариант допустим.

## BIO-Q05. Соседство

Как новые биомы сочетаются с соседями в Авто?

Причина: От этого зависит появление пустыни рядом с джунглями и поведение при нехватке подходящих кандидатов.

- **A — Делегировать точную матрицу по сухим/влажным семействам.** Аналитик готовит симметричную таблицу, избегает прямого пустыня↔джунгли/болото, сохраняет старые пары и ограничения высот; без нового симулятора климата.
- **B — Разрешить любые новые пары при допустимой высоте.** Разнообразнее и проще размещать, возможны резкие климатические переходы.
- **C — Владелец задаёт свои исключения.** Аналитик переводит их в полную симметричную таблицу; незаданные существенные пары уточняются.

Рекомендация: **A**, Сохранить утверждённый объём и действующие механизмы, сократить риск скрытого расширения; это предложение, не решение владельца.

Условие: Для автоматического выбора; ручной режим не получает новых ограничений сверх отдельно согласованных/действующих.

Связи: R03, R04, AC03. Собственный вариант допустим.

## BIO-Q06. Нет подходящего соседа

Причина: Нынешний автоматический подбор имеет ослабление; строгая матрица сама по себе не гарантирует её соблюдение на итоговой карте.

- **B — Новые запрещённые пары не ослаблять.** При исчерпании допустимого поиска отказ с сохранением карты; аналитик определяет совместимость со штатным аварийным урочищем. Старые пары не меняются.

Рекомендация: **B**, Сохранить утверждённый объём и действующие механизмы, сократить риск скрытого расширения; это предложение, не решение владельца.

Условие: При ограничивающей матрицеQ05=A/C. ПриQ05=B новых запретов нет, отдельного решения не требуется.

Связи: R02, R03, R11, AC03, AC06. Собственный вариант допустим.

## BIO-Q07. Продолжение старых карт иseed

Причина: Принятая карта должна оставаться прежней, но будущий результат Авто оттого жеseed может измениться.

- **A — Использовать новый каталог при дальнейшем росте.** Уже построенные регионы не меняются; будущие результаты и карта заново по старомуseed могут отличаться от прежней версии.
- **B — Для старых карт сохранить старый автокаталог.** Новые биомы автоматически только в новых картах; дополнительные версия/профиль генерации и проверки совместимости. Ручной выбор новых биомов в старой карте остаётся возможным.

Рекомендация: **A**, Сохранить утверждённый объём и действующие механизмы, сократить риск скрытого расширения; это предложение, не решение владельца.

Условие: ПриQ03=C Авто не меняется этим выпуском; тему отложить до его подключения. Не обещать битовую идентичность между версиями без evidence.

Связи: R08, R09, R10, AC04. Собственный вариант допустим.
