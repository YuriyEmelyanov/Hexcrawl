# HX-BL-059 — решения по черновику D1

Проверен весь черновик. Уже решённое не спрашивается повторно: устойчивый обход слева/справа, прибрежные POI в своём6mile, сдвиги обычных незакреплённых объектов, короткая допустимая дорога, сохранение типов переправ и atomic failure для locked/measured.

## RE-Q01 — применение к существующим картам

**A — автоматически при переходе в1милю (рекомендуется).** Старые и импортированные карты сразу показывают согласованные реки по рёбрам. Связанные незакреплённые объекты в fine-виде адаптируются вместе; исходный6mile не переписывается от просмотра, смена масштаба не становится новой Undo-операцией. При несовместимой закреплённой привязке карта сохраняется без изменений с понятной причиной.

**B — через «Уточнить геометрию».** Старые карты остаются как сейчас до отдельного применения. Уточнение — одна отменяемая операция; простое переключение1mile ещё может показывать старую трассу через центры. Это осознанное ограничение требования.

**Иной вариант** допустим свободным текстом. РекомендацияA не считается ответом владельца. До решения зависимая реализация не готова.

Остальные технические замечания переданы аналитику в draft-review.json; для стыка с берегом допустим отрезок вдоль части ребра, но не диагональ по суше. Интервью не закрыто; публикация отдельно.
