## Inhabited: ограниченный второй шаг

Источник: [авторский Hexfill, 11.04.2024](https://vaultsofvaarn.com/2024/04/11/vaarn-hexfill-procedure/), раздел Inhabited Hex, строки22–35. Прочитана целиком таблица d10; тексты связанных генераторов не прочитаны. Автор/проект тот же: это не новый независимый мастер.

Мастер после категории inhabited получает один подтип по d10. Общая операция content.roll_table_resolution уже зарегистрирована; новый игровой профиль не доказывает новую реализацию. Конкретные входы/выходы и пять примеров — в JSON, VAARN-HF2024-002-L1. Например, исход7 даёт оазис; сохранение/открытие не перебрасывает его и не удаляет реку.

054: отдельное кандидатное продолжение для решения стратега; текущий объём первой категории и разрешения не расширены. 043: опубликованный общий компонент — аналог для переиспользования, exact Vaarn evidence unknown. Ни полный Hexfill, ни полная поддержка Vaarn не заявлены.
