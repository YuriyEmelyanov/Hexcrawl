## Где вероятнее найти полезные «алмазы»
**Первыми проверять по правилам:** HeroesofAdventure,Errant,VaultsofVaarn,WolvesUpontheCoast,AshesWithoutNumber,ScarletHeroes,SpearsoftheDawn,TalesofArgosa иMutant:YearZero. Основание — конкретные заявленные карты/процедуры/места, а не популярность. Внутри каждой проверки сохранять3отдельных сценария.
- Для **создания** особенно интересныHOA,Ashes,Vaarn,Spears;Scarlet открываетduet/solo-срез.
- Для **развития** —Wolves,UVGиготовыеHSI/FeverSwamp/AtomicSky. Большой размер готовой карты не даёт автоматического спроса на генератор новой.
- Для **использования сейчас** —Errant,Ryuutama,ArgosaиMYZ: искать реальные действия ведущего у места/в пути, не считать наличие журнала достаточным.
CWNиTrespasser — полезные пограничные проверки: городскойsandbox и тактическаяигра могут иметь подходящий региональный слой, но не вся их аудитория подходитHexCrawl.

## Дубли, редакции и аудитория
- TalesofArgosa истарыйLowFantasyGaming сохранены одной новой строкой с явными редакциями; не два независимых рынка.
- Wolves правила+GrandCampaign — одна игроваяэкосистема; Reavers,карты/листы/хроники не отдельныеигры. UVG — гибридигры/сеттинга,учёт одной строкой.
- NUKED иUnderanAtomicSky связаны; Vaarn иего дополнения связаны; HSI/FeverSwamp не объявлены системами.
- OtherDustиAshes — самостоятельные родственные продукты; общую аудиторию без evidence не складывать. То же относится к семействуWithoutNumber/RedTide иKnave-derived.
- У всех17новых строк **M/D/U и3ранга unknown/null**. Число отзывов/рейтингов/подписчиков не превращалось в ведущих. ДопускD>1000 не подтверждён; это кандидаты на исследование, не доказанные участники приоритетного пула.
- Действующий three-scenario-ranks-1.0 остаётся срезом45вычислимых игр. Расширение реестра не меняет его ранги задним числом; после появления данных нужна новая версия с единым составом. Старые6unknown не забыты: теперь23игры безM.
- Разработка по найденным играм не утверждена. Score1.2,веса/пороги/поддержкаигр не менялись. Активныеclaimsиочередь команды сохраняются.
