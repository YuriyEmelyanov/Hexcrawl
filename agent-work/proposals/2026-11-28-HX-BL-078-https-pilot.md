# HX-BL-078 · временный HTTPS-стенд для PR №519

## Предложение владельцу

Выделить один Selectel VDS 1-2-25 на срок до 72 часов для внешней приёмки первого выпуска. Проверщик сможет провести один игровой ход на подготовленной карте, перезапустить сервис и проверить, что оба игрока остаются в той же комнате по прежней ссылке. Сейчас этот сценарий подтверждён на временных адресах CI. Поставляемая сборка Pages не получает адрес сервиса комнат. [Заключение проверяющего](../results/2026-11-28-reviewer-HX078-775cb6c-0600.json) · [Сборка Pages на текущей main](https://github.com/YuriyEmelyanov/Hexcrawl/blob/3858b059ec940cc77c63b99c29ca17825268ab38/.github/workflows/deploy.yml) · [Уточнение владельца о стенде](../decisions/owner-2026-11-27-HX078-no-https-stand.json)

## Вариант размещения и затраты

- Один VDS с 1 vCPU, 2 ГБ RAM, 25 ГБ диска и одним публичным IP. Опубликованный тариф на 28.11.2026 составляет 0,34 ₽/ч. Расчёт до 72 ч даёт 24,48 ₽. Предлагаемый лимит потребления составляет 30 ₽. Точную ставку и включение IP сверить в панели до создания ресурса. [Тариф](https://selectel.ru/services/cloud/vps-vds/hourly-paid/) · [Комплектация](https://docs.selectel.ru/vds-servers/about/about-vds-server/)
- Для нового аккаунта минимальное первое пополнение составляет 200 ₽. Это зачисление на баланс, а расчёт выше относится к потреблению стенда. Существование аккаунта и доступный остаток не подтверждены. Если пополнение потребуется, оно входит в явное решение владельца. [Регистрация](https://docs.selectel.ru/account/registration/)
- На сервере разместить тестовую статическую сборку редактора и один экземпляр сервиса комнат. Состояние хранить в выделенном каталоге на локальном диске вне каталога сайта. Три тестовых HTTPS-адреса для редактора, мастера и игрока могут использовать один IP. Предлагаемый обратный прокси Caddy обеспечивает TLS при выполнении условий DNS и доступности портов. В пилоте доступ ограничить согласованными участниками, а вход игрока продолжать проверять по ссылке и с отдельного адреса. [Документация Caddy](https://caddyserver.com/docs/automatic-https) · [Спецификация F1](../specs/HX-BL-078-vtt-movement-fog-F1.md)

Временная среда CI остаётся средством регрессии. На одном стенде с отдельными адресами можно проверить конфигурацию выпуска и реальный перезапуск с тем же диском. Наличие готового стенда владельцем опровергнуто. База данных и перенос редактора с Pages не входят в предложенный этап. Постоянное размещение потребует отдельного решения о сроке, поддержке и бюджете.

## Границы и проверяемый результат

1. После разрешения программист подготавливает отдельную интеграционную ветку и сборку. Синтетическое объединение `775cb6c` с `main 3858b05` дало дерево `e20e04d07ca5a6162ee6f125c1d1046998101b14` без текстовых конфликтов. Текущая main содержит изменение `src/App.tsx` из PR №520, поэтому прогон на исходном PR не заменяет проверки интеграционного SHA. [Сравнение с main](https://github.com/YuriyEmelyanov/Hexcrawl/compare/3d85da66a5d115c049a512664ef72ca448eabc20...3858b059ec940cc77c63b99c29ca17825268ab38)
2. Владельцу подтвердить доступ к панели Selectel и DNS для трёх временных поддоменов, назначить ответственного за стенд и подтвердить лимиты. Предлагается, чтобы владелец проекта предоставил доступ и лимиты, а назначенный программист отвечал за запуск, наблюдение расходов и удаление. Роль проверяющего остаётся независимой. Секретные данные в репозиторий и артефакты не включать.
3. На тестовой карте Classic 5–6 миль мастер открывает комнату из собранного редактора. Два независимых сеанса подключаются по одной ссылке, предлагают ход, мастер подтверждает его один раз. После перезапуска сервиса та же открытая вкладка и заново открытая старая ссылка показывают ту же подтверждённую позицию и только разрешённую карту. Явно отозванная ссылка перестаёт давать доступ. Сохранить SHA редактора и сервиса, контрольную сумму сборки, браузерный протокол и результат сравнения с конфигурацией будущего выпуска. Отдельно предъявить границу доступа к операциям мастера на целевой публичной схеме до запроса публикации. [Покрытый сценарий CI](https://github.com/YuriyEmelyanov/Hexcrawl/actions/runs/46091727619)
4. Программист закрывает пилот после проверки либо при достижении 72 ч, лимита расходов или невозможности обеспечить согласованный доступ. Удаляет тестовый VDS и временные записи DNS, проверяет остановку начислений и сохраняет обезличенное доказательство. Используется только тестовая карта. Выключение VDS само по себе тарификацию не прекращает. [Управление VDS](https://docs.selectel.ru/vds-servers/manage/manage-server/) · [Оплата и потребление](https://docs.selectel.ru/vds-servers/about/payment/)

Оценка первого этапа после решения владельца — подготовка, проверка и закрытие стенда за 2–3 рабочих этапа. Приёмка конфигурации для сайта и выпуск потребуют ещё 1–2 этапов после решения о постоянной среде. Прогноз ориентировочный, время ожидания решений не включено. Пилот сам по себе баллов не даёт. Потенциальный вклад S04-C03 L2 остаётся неопределённым, по S02-C05 L1 подтверждённая дельта нулевая. [Оценка 1.3-rc8](../evidence/HX-BL-078/review-775cb6c/score-assessment.json)
