# HX-BL-058 · Название базового масштаба и выбор размера гекса · F1

Чистовая спецификация. [Ответы владельца](../interviews/HX-BL-058/BASE-SCALE/decisions.json). Основание — [решение владельца](../decisions/owner-decision-2026-11-16-base-hex-five-six-miles-ui.json) и [передача аналитику](../handoffs/2026-11-20T0000-strategist-score-PR509-HX-BL-058-analyst.json). На выпущенном d6daa2c в src/App.tsx кнопка координат уже предшествует полю. Внутри поля сначала подпись, затем список со значениями «1 миля» и «6 миль». Цель — мастер сразу узнаёт общий базовый масштаб для игр с пяти- и шестимильными гексами.

| Требование | Приёмка |
|---|---|
| R1. Базовый пункт и выбранное значение «5–6 миль» / «5–6 miles». | AC1. Открыть старую карту, проверить выбранный пункт, раскрыть список на RU и EN. Сохраняются два существующих значения и их порядок. |
| R2. В панели сразу после кнопки координат идёт строка выбора. Слева список, справа подпись «Размер гекса» / «Hex size», обе части по центру по вертикали. | AC2. При 1280, 390 и 320 CSS px в обоих языках строка читается без горизонтальной прокрутки. Кнопка координат независима от масштаба. Нажатие подписи фокусирует выбор, Tab, стрелки и подтверждение работают. |
| R3. Переключение работает на текущей карте. | AC3. Перейти с базового вида на 1 милю и обратно. Та же карта, исходные регионы, объекты, координаты и физическая сетка. Сохранить и загрузить старую и текущую поддержанную карту, сравнить данные с эталоном для той же последовательности. В JSON остаются числовые шаги 1/6. PNG сравнить на одинаковом масштабе и ориентации. |
| R4. При пустой карте, импорте или занятой генерации сохраняется действующая блокировка списка. | AC4. Поле имеет читаемую подпись в недоступном состоянии. На ошибке подготовки одномильного вида восстанавливается исходный вид с сообщением «1-мильная карта не открылась.» / «The 1-mile map did not open.» (HX058-Q01). |
| R5. Тексты вне списка. | AC5. В обоих языках флажок подписан «Knave 2e», без дополнительной подписи о милях (HX058-Q02). Проверить включение и выключение профиля. Точные расстояния в географических данных и механика профиля сохранены. |

Новая настройка физического расстояния, миграция карты и новые уровни масштаба выходят за границы решения.
