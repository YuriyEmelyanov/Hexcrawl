Версия 1.0, 28.10.2026. Роль: business_analyst. Статус: ready_for_development после предъявления приложенного UI. Родительская задача HX-BL-023; связанные013/028, без нового ID бэклога. ## Цель и границы

Ведущий корректирует несколько гексов под своё приключение без повторения одиночного редактора. До: изменить лесную полосу из 8 гексов можно только восемью отдельными правками. После: выбрать 8 гексов, назначить открытые равнины, применить один раз; один Undo восстанавливает все прежние биомы. Это пакетный выбор щелчками/касаниями, не непрерывное рисование перетаскиванием.

Основной сценарий develop_existing: довести созданную или загруженную карту. Вторичный create_from_scratch: корректировка после генерации. Play_now не является результатом этого среза. Первый срез не закрывает всю задачу023 и не снимает запрет приглашения ведущих. Выбран прежде переноса POI/дорог/воды: расширяет уже сохранённый ручной слой без смены географических правил, идентичности объектов и формата. Ориентировочный объём M: состояние выбора, доступный UI, одна атомарная операция и ограниченные регрессии; не оценка расхода подписки.

Входит: отдельный компактный блок «Редактирование карты»; вход в «Групповая правка биома»; выбор существующих сухопутных гексов, в том числе нескольких регионов; один известный BiomeId или снятие ручных биомов; предпросмотр выбранного набора; применение/выход; общий Undo/Redo; текущие JSON и PNG. Существующие одиночные редакторы и заметки сохраняются вне режима.

Не входит в реализацию A: изменение воды, heightLevel, состава/границ/принадлежности регионов, генерационных параметров, дорог, переправ, POI и имён; многогексовая кисть радиусом; drag-paint; подложка027; контент041; новый движок/автосохранение на диск/аналитика. Слой биома означает ту же ручную характеристику/отображение, что существующий карандаш, а не физическое преобразование региона. В UI короткая подсказка «Меняет биом суши. Вода и высота региона сохраняются». Не добавлять неработающие вкладки будущих инструментов.

## Состояния и взаимодействие

1. По умолчанию обзор/генерация ведут себя как прежде. Вход в инструмент доступен при наличии хотя бы одного сухопутного гекса и отсутствии documentBusy/import/generation/pendingRegen. Вход завершает текущую группу заметок обычным способом, закрывает одиночные редакторы, не добавляет историю. Начальный выбор пуст, действие «Назначить биом», значение — открытые равнины (видимое, не применённое).
2. В инструменте обычный короткий click/tap по существующей суше переключает её членство в Set ключей q,r. Повторное касание снимает выбор. Центральный гекс допустим. Вода, кандидаты и пустота не добавляются; на воде/кандидате показывается короткое «Выбирайте существующие гексы суши», без генерации и записи истории. Учитывать фактический terrainOverride lake/sea, даже если гекс входит в region.hexes. Не очищать скрытые исторические override воды.
3. Поддержать видимую рамку/маркер выбранных гексов и счётчик «Выбрано: N». Цвет не единственный признак. Выбор не заменяет обычный selectedHex: его положение сохраняется. Pan/zoom/поворот и скрытие панели доступны; перетаскивание/скролл/длинный жест навигации не меняет выбор, pointercancel не добавляет гекс. Инструмент и счётчик заметны после возврата панели. Не требовать Shift или drag для мобильного сценария.
4. Клавиатурная альтернатива карте: подписанные поля q и r, «Добавить / убрать гекс» с тем же валидатором и правилами. Только целые безопасные числа; ошибка у поля, никакого округления/NaN/частичного parseInt. Обычный Tab, видимый focus, Enter для кнопок. Escape вне select/текстового поля выходит и снимает выбор; в поле Escape не должен стирать ввод неожиданно. «Очистить выбор» оставляет инструмент открытым; «Выйти» снимает выбор и возвращает обзор без изменений документа. Переключение языка сохраняет выбор и действие.
5. Действие «Назначить биом» показывает существующий локализованный список BIOMES. «Снять ручные биомы» скрывает этот список; результат каждого гекса — его исходный региональный биом, поэтому возвращаемые биомы могут различаться. Смена действия/биома не пишет в документ. Предпросмотр показывает контуры выбранных гексов, число реально изменяемых гексов и текст результата; перекраска черновиком не требуется. Нет нового поля «высота» и обещания изменения рельефа.
6. Счётчики: N — все выбранные допустимые ключи, M — ключи с изменением сохранённого слоя. Assign: для каждого выбранного ключа записать выбранный BiomeId, если он отличается от сохранённого override (даже если равен региональному биому: явный override сохраняется, как у одиночной правки). Reset: удалить только существующие override выбранных ключей. Нельзя нормализовать остальные ключи или неявно удалять override, равный базовому. При M=0 кнопка применения недоступна и виден текст «Изменений нет»; история и redo не меняются.
7. «Применить к M гексам» повторно проверяет revision, доступность и весь набор, готовит новую Map вне записей state и выполняет одну транзакцию общего механизма. Частичное применение запрещено. Успех: сбросить выбор, выйти из инструмента, status «Биом изменён: M гексов» / «Ручные биомы сняты: M гексов»; selectedHex/камера прежние. Один Undo возвращает точный прежний документ, один Redo — результат, без RNG-вызовов. Предыдущая история, включая generation checkpoints и заметки, сохраняется; успешная новая правка очищает redo по существующему контракту.
8. Пока инструмент открыт (даже пустой), прочие изменения документа — генерация кликом по кандидату, reset, regenerate/delete-region, import, mode/world-seed changes, одиночные biome/POI/name/notes edits и общий Undo/Redo — недоступны. Видимое пояснение «Примените правку или выйдите из инструмента». Нельзя перекрыть лишь кнопки: старые обработчики/отложенные события также обязаны отказаться. Нельзя добавить инструмент в общий mutationBlocked так, чтобы его собственное применение всегда блокировалось; различить владельца операции. При открытии во время busy — отказ. Если документ всё же сменился/стал busy извне, черновик инвалидируется, весь apply отклонён, ни нового документа, ни истории не трогать; показать причину и предложить новый выбор. Не восстанавливать старый документ поверх нового.
9. Экспорт доступен: сохраняет/рисует только применённый документ, без выделения набора/координатного фокуса инструмента/черновика. В инструменте рядом с экспортом: «Выгружается карта без неприменённой правки». После apply JSON содержит ровно изменения нужных ключей слоя; PNG соответствует обычному отображению этих биомов. Существующее поведение SVG-ассетов в PNG не менять; отдельной кнопки векторного SVG-экспорта не обещать, если её нет.
10. Ошибка подготовки/валидации/устаревший вызов — явное локализованное сообщение, атомарный отказ; состояние документа/RNG/обе истории/счётчики неизменны. При обычной ошибке подготовки выбор можно сохранить для исправления, при смене документа снять как устаревший. Технический Error.message пользователю не выводить. Перезагрузка страницы теряет неприменённый выбор; сохранение на диск выполняется обычным JSON-экспортом, как сейчас.
