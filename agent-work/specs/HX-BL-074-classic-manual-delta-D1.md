# HX-BL-074 · Ручное восстановление рукава дельты · D1

Черновик для интервью. Владелец согласовал старт 26.11.2026. Основание: `agent-work/decisions/owner-2026-11-26-approve-HX074-delta.json`. Исходное дерево продукта: `3d85da66a5d115c049a512664ef72ca448eabc20`.

## Цель и границы

- **D74-R01.** В Classic 5–6 миль мастер вручную восстанавливает один короткий рукав существующей прибрежной реки. Рукав идёт по одному ребру от допустимой развилки родительской реки к отдельной морской вершине. Принимается один пользовательский выпуск. Автогенерация, новый расчёт стока, многорёберные рукава и другие масштабы вне выпуска.
- **D74-R02.** Сохраняются геометрия и идентичность основной реки, её имя, течение, полноводность, ручные отметки и переправы. Рукав связан с основной рекой через существующее представление `deltaParentRiverId`. Числовой ID восстановленного рукава может быть новым. Действующие проверки допустимой развилки, разных устьев, полноводности, владения ребром, перекрытия и циклов сохраняются. Обычная команда добавления реки и обычные притоки сохраняют поведение.
- **D74-R03.** Для эскиза используется существующая панель «Редактировать» и карточка выбранной реки. Предлагаемое действие «Добавить рукав» открывает выбор развилки и соседнего устья на карте с доступным выбором из панели. Затем используется существующий предпросмотр с «Подтвердить» и «Остаться». Действие, шаги и подтверждение показаны последовательно в приложении, на эскизе собраны рядом для обзора. Формулировки и способ входа открыты для интервью.
- **D74-R04.** До подтверждения карта и история не меняются. Недопустимая или переставшая быть допустимой операция даёт объяснение, сохраняет данные и доступность Undo/Redo. Успешное добавление фиксируется одной обратимой операцией. JSON использует действующий формат, PNG показывает оба морских устья.

Техническая опора: `src/manualRivers.ts`, `src/manualRiverDependencies.ts`, `src/App.tsx`, `docs/river-editing.md` на исходном SHA. В существующей проверке дельты рукав содержит ровно две вершины, основная река заканчивается у моря, её полноводность у устья не ниже 4, развилка выбирается из допустимого участка устья. В работе сохранить текущие ограничения числа рукавов, полноводности и конфликтов. Проверяющий сверяет фактические значения с действующим кодом.
