# HX-BL-074 · Ручное добавление короткого рукава дельты · F1

Чистовая спецификация от 26.11.2026. [Утверждение границ](../decisions/owner-2026-11-26-approve-HX074-delta.json) · [Закрытое интервью DELTA-Q01–Q03](../interviews/HX-BL-074/MANUAL-DELTA/decisions.json). Исходный SHA продукта `3d85da66a5d115c049a512664ef72ca448eabc20`.

## Пользовательский результат

В Classic 5–6 миль мастер открывает «Редактировать» → «Добавить реку», выбирает точку развилки на существующей прибрежной реке и соседнюю вершину у моря. Интерфейс показывает короткий рукав и полноводность. После подтверждения на карте два устья. Основной участок остаётся на месте. Результат виден в PNG, восстанавливается из JSON и отменяется одной операцией.

## Оценка продукта и прогноз

- **1.3-rc8, L1, S03-C01 / EDIT-30.** Принято 50% критерия, 6,1728395062 из 12,3456790123 балла по [истории 1.3-rc8](../score/history.json), событие HX-BL-056 / PR510 и критерий S03-C01. Успешная приёмка отдельного остатка EDIT-30 может дать переход 0,50 → 0,54 и до **+0,4938271605** балла. Отдельное доказательство — D74-AC01–AC05 на точном SHA. Прогноз условный.
- **S01-C02 / RIV-019.** Сохранение принятой ручной части, дельта 0. Проверка D74-AC01–AC03 по [принятым правилам гидрологии](../score/rules/S01-C02.md). Автоматическая часть в HX-BL-065. **S01-C04 / ROAD-10.** Повторное использование действующего правила переправ, прогноз 0, проверка D74-AC05. Источник — [правила дорог](../score/rules/S01-C04.md). L2/L3 не входят в оценку выпуска.
- Ориентир исходного плана 9–15 рабочих этапов от D1 до проверки выпуска. После чистовой спецификации остаётся ориентировочно 5–10, включая реализацию сквозной карты, независимую проверку, возможное исправление и проверку публикации. Ожидание разрешения выпуска учитывается отдельно. Основной риск — совместить выбор типа переправы с предпросмотром и атомарной историей.
