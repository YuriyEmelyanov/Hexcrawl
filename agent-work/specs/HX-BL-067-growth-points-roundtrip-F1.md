# HX-BL-067 · Точки роста после открытия карты Classic

Чистовая спецификация F1 · 24 ноября 2026 года

Открытие сохранённой карты Classic должно восстанавливать тот же набор координат, доступных для добавления следующего региона. На контрольной карте при первом открытии из 34 точек роста получается 35. Добавленная координата −3/3 занята озером Vargsjø. При втором открытии лишняя точка сохраняется.

## Требования и приёмка

| Критерий | Действие и ожидаемый результат |
|---|---|
| AC1 · Сохранение точек | Взять [контрольную карту seed 42](../research/acceptance/L1-PR509/classic-common/coastal-lake-seed42.json). Через интерфейс открыть и снова сохранить карту дважды. На каждом цикле сравнить множества координат с исходным JSON. Совпадают все 34 точки. |
| AC2 · Озеро | На каждом цикле в масштабе 5–6 миль нажать −3/3. Открывается Vargsjø, карта всё ещё содержит три региона, координаты озера нет среди точек роста. |
| AC3 · Продолжение карты | После повторного открытия нажать доступную точку −2/−3. Создаётся четвёртый регион. Сохранить и открыть эту карту, сравнить новый набор точек роста до и после открытия. |
| AC4 · Совместимость | Открыть ранее пересохранённый файл с 35 координатами, копию с 33 координатами (убрана −2/−3) и копию без поля списка. В каждом случае после открытия и экспорта получить исходные 34 допустимые точки, включая −2/−3 и без −3/3. Повторное открытие сохраняет этот набор. Озеро, три региона и их содержимое сохраняются. |

При открытии JSON Classic сохранять допустимые точки из файла и восстанавливать пропущенные по текущей геометрии и действующим правилам роста Classic (GP-Q02). Те же правила применяются, когда поле отсутствует целиком. Подтверждённые ложные координаты исключать при открытии и при следующем экспорте (GP-Q01). Для Vargsjø исключается запись точки роста, а гекс и карточка озера сохраняются. Допустимость водных координат определяется действующими правилами роста. ## Проверка AC1–AC3 в браузере

На локальной копии опубликованной сборки a4184a6 открыть исходную карту Classic с seed 42. Дважды выполнить цикл «открыть JSON → выбрать озеро −3/3 → выгрузить JSON». На каждом цикле сверять координаты трёх наборов: 34 исходные точки, отображаемые точки роста, точки в выгруженном файле. На исправленной сборке все три множества совпадают. Одна карточка озера Варгшё, три региона и отсутствие маркера роста на −3/3 проверяются отдельно.

На текущей сборке оба цикла сохраняют все 34 видимые точки. В JSON добавляется одна лишняя координата −3/3. Щелчок по −2/−3 добавил четвёртый регион, после чего все 61 точки расширенной карты совпали при повторном открытии, без добавлений или пропусков. Число 61 описывает этот прогон. Для AC3 сравнивать множества координат до и после открытия уже расширенной карты.

Для модели 1.3-rc8 в строке REG-07 критерия S01-C01 подтверждена половина веса (около 0,2147 L1) за выбор озера. При совпадении наборов в AC1 и сохранении поведения AC2 и AC3 проверяющий может подтвердить вторую половину (до +0,2147 L1).
