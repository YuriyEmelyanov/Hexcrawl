# HX-BL-073 · Проверка связности регионов при открытии карты Classic

Черновик D1 · 24 ноября 2026 года

## Проблема

На карте Classic с seed 42 один из регионов состоит из восьми гексов, соединённых по рёбрам. Если в JSON вписать в этот же регион девятый гекс с координатами 500/500 и обновить размер региона, текущий импорт принимает файл. Этот гекс оказывается отдельным кусочком того же региона далеко от остальных.

## Предлагаемое поведение

При открытии JSON карты Classic приложение проверяет каждый регион. Из любого его гекса можно дойти до любого другого, переходя через общие рёбра и оставаясь в границах региона. Касание углами и путь через гексы другого региона связность не дают. Водный гекс учитывается, если он входит в состав региона. Один гекс сам по себе образует связный регион.

Проверку выполнить после проверки структуры файла и до замены открытой карты. Использовать правило смежности, которое уже действует при переносе гекса в редакторе. Если найден разрыв, отклонить импорт и показать ID проблемного региона. Предлагаемый текст «Регион №{id} состоит из несвязанных частей. Карта не загружена». Открытая карта и история Undo/Redo сохраняются.

Объём D1 охватывает явное открытие JSON в Classic. Исправление структуры файла, генерация и перегенерация регионов остаются отдельными задачами.

## Приёмка

| Сценарий | Ожидаемый результат |
|---|---|
| Открыть исходную карту seed 42 с регионом из восьми связанных гексов. | Файл открывается, регион содержит те же восемь гексов. |
| Открыть копию с девятым гексом 500/500 и обновлённым размером региона. На открытой карте заранее создать правку и отменить её, чтобы было доступно Redo. | Импорт отклонён с ID разорванного региона. Открытая карта сохраняется, Redo по-прежнему возвращает отменённую правку. |
| Открыть карту, где части региона соединены только цепочкой гексов другого региона. | Импорт отклонён с ID разорванного региона. |
| Открыть одногексовый регион и регион, где единственная связь между частями проходит через водный гекс, принадлежащий этому региону. | Обе карты открываются. |
| Открыть файл с одним гексом, записанным в два региона. | Срабатывает действующая проверка дублирования гекса. |

## Дополнение · Удаление последнего региона

При удалении последнего региона на карте 5–6 миль исчезновение малого озера на одномильной карте не должно вызывать отдельного предупреждения, добавлять строку про малые озёра в общий диалог или само по себе открывать диалог. Малые озёра, потерявшие опору после удаления региона, удаляются вместе с регионом. Остальные малые озёра сохраняются. Undo восстанавливает регион и его озёра, Redo повторяет удаление. Подтверждения, вызванные другими правками, работают по прежним правилам.

Приёмка. В Classic создать два региона. На одномильной карте разместить малое озеро в последнем регионе и ещё одно в первом. Возвратиться на 5–6 миль и нажать «Удалить последний регион». Проверить отсутствие предупреждения о малом озере, затем в масштабе 1 миля сверить оба озера после удаления, Undo и Redo. Если на принятой сборке сценарий уже проходит, зафиксировать результат без правки кода для этого пункта.
