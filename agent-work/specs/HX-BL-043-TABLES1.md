## Поведение и команды
1. В карточке места действующие строки остаются компактными: назначение перед кубом/значением; язык на общей плашке — текущий. Меню строки «…» даёт «Выбрать строку», «Добавить по ссылке» при известной ссылке и «Удалить». Добавить подсказку открывает общий выбор одной из четырёх таблиц и режима «Бросить d100»/«Выбрать строку». Любая из четырёх таблиц допустима для ручной подготовки land/settlement/water; это текстовая подсказка, не изменение карты. Случайная явная команда TABLES1 выбирает равномерно1..100 из выбранной таблицы; существующее автоматическое fill новых мест остаётся прежним compatible_pool+trait.
2. Выбор строки: в popover/dialog доступны номер1..100 (печатная00 явно отображается как100·00, ввод00 НЕ равен0), поиск по доступному тексту, предпросмотр и Применить/Отмена. Номер0,101,дробь,NaN,пустое — ошибка без изменения документа/счётчиков. Точный контракт ввода: числовое поле принимает1..100; отдельная доступная строка «100 (00)» выбирает последнюю; «00» в текстовом поиске находит эту строку, не передаётся как0 в API. Ручной выбор не бросает кубы. Показывать #номер, не изображать его выпавшим d100.
3. Добавить всегда создаёт новый id, даже если table/row/text совпали. Открытие, поиск, выбор/закрытие меню и предпросмотр ничего не записывают и не расходуют RNG. Применение — одна транзакция. Повторный Apply с тем же draftToken/id или устаревшим owner/document revision — отказ/no-op без повторного добавления.
4. Переброс одного обращения меняет только его принятый результат и его локальный counter. Совпадение с прежним законно, принудительного перевыбора нет. Не пересчитывать siblings/другие места/толкование/географию/world RNG. Вызов «перебросить все» прежнего контекстного меню применяется только к показанным root обращениям выбранного места, одной атомарной транзакцией; текст ведущего не меняется. Старые two-component shortcuts не должны затронуть скрытые другие места.
5. Ссылку выполнять только явной командой из конкретного обращения. Сначала сохранить root; отдельный выбор/бросок целевой таблицы создаёт child с parentId/edgeId, сохраняя root. Не скрывать исходную ссылку и выпавший результат. У одного parent в этом этапе один принятый child; повторная команда открывает его/редактирование, не плодит неявных children. Для двух независимых уточнений добавить второй root той же таблицы. Это ограничение формы цепочки, не ограничение числа подсказок.
6. Профиль KNAVE2-070: если child B/n снова ссылка, третью таблицу автоматически не открывать. Предложить «Взять следующую строку» B/(n+1) как явное применение рекомендации источника, без нового броска. Сохранить и фактический B/n, и выбранный B/(n+1), и основание перехода. n=100: следующей нет; действие недоступно с короткой причиной. Если следующая тоже ссылка: сохранить открытый вопрос, не сканировать дальше, не выполнять цикл/100→1. Можно вручную заменить результат child через обычный selector; это явный выбор ведущего, не утверждение книги о продолжении. Контроллер ограничивает цепь root→child и допускает лишь одну nextEntry annotation; импортер отклоняет более глубокие/циклические связи.
7. Замена/переброс root с child: на предпросмотре предупредить о потере конкретного уточнения. Apply атомарно заменяет root и удаляет его child/nextEntry; отмена сохраняет всё и counters. Без child нет лишнего подтверждения. Замена child удаляет только его nextEntry, root и siblings сохраняются. Удаление root с child — одна подтверждённая транзакция; удаление leaf без дополнительных данных — обычная команда. Удаление всего принятого списка не удаляет description автоматически.
8. «Описание места» — отдельный owner-owned текст ведущего (до20000UTF16); пустое допустимо. Это не gmNotesByHexKey и не перенос существующей координатной заметки. Не составлять описание автоматически, не менять прежние имена/улики/классификацию. Редактирование по существующему draft lifecycle: Save/Cancel, dirty navigation Finish/Discard/Stay, Escape, ошибки/IME; draft привязан к owner+revision, не к случайно текущей панели. Markdown/HTML не исполняется; текст экранирован. Смена языка не переводит авторский текст автоматически.
