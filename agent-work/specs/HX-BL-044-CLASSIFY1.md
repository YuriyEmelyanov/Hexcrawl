## Предлагаемая классификация

Для краткого чтения достаточно трёх категорий владельца: обычная, труднопроходимая, опасная. Обычная не выводится. Для опасной показывать короткую конкретную причину: «Опасная · риск падения», «Опасная · ожоги», а не длинное объяснение правил.

Уточнение владельца в этом же обсуждении: «Опасная, скорее всего труднопроходимая, это норм». Принимается простая трёхуровневая классификация: опасная по умолчанию включает труднопроходимость и конкретный риск. Второй обязательной шкалы в интерфейсе нет. Сохраняются причины, исходный игровой профиль и ручное переопределение; необычное исключение не требует новой общей категории. Особо трудная/неровная поверхность PF2 сохраняется как профильная подробность без новой обязательной категории общего UI. Непроходимая грань/вода без подходящего способа движения не считается преодолимой из-за ярлыка «опасная».

### Биомные умолчания — политика HexCrawl, не нормы всех НРИ

| Контекст | Краткое значение | Причина/условие |
|---|---|---|
| Открытая равнина, редколесье, плотное ровное покрытие | Обычная, скрыта | Нет описанного препятствия/риска |
| Холмы, леса, лесистые холмы; мёртвые аналоги | Труднопроходимая | Подъёмы либо растительность; состояние «мёртвый» само не создаёт ядовитую опасность |
| Горы и горные леса, мёртвые горные аналоги | Опасная + трудность сохраняется | Потенциальное падение/осыпь; это дефолт профиля, не утверждение, что в каждом гексе уже произошёл обвал |
| Болото и болотный лес | Опасная + трудность сохраняется | Потенциальное увязание/скрытая вода; ручная тропа/настил может локально менять контекст |
| Лавовая местность, если явно задана как местность/свойство | Опасная | Ожоги/жар. Не добавлять несуществующий биом или лаву по одному названию |
| Полупустыня, снег/лёд и иные неоднородные покрытия | По конкретным известным свойствам | Плотный песок не равен рыхлому; при недостатке данных unknown скрыт, не normal |
| Озеро/море | Отдельная среда | Не маркировать всю воду обычной для пешего движения; способ передвижения относится к следующему уровню |

Ручная правка важнее автоумолчания; известные локальные особенности важнее биома. Дорога не снимает автоматически риск пожара/падения со всего гекса. Правка дороги влияет только на связанный маршрут, не на всю территорию. Не придумывать DC, урон, шанс события и время движения.

## Обнаружение по контексту

Порядок: явное ручное назначение → проверенное свойство скрытости/тег → фактическое положение относительно пути и обзорности → тип POI и местность → unknown. Хранить причину определения и способ получения. Теги влияют через проверенное соответствие семантического ID/строки, а не поиск подстроки в локализованном тексте; «незатерянный» не становится «затерянным».

| Случай | Ожидаемое условие |
|---|---|
| Таверна, действительно стоящая на проходимой дороге, без скрывающего свойства | Заметна с этой дороги при прохождении; не обещать видимость с любого края гекса |
| Логово в лесу без видимого входа/вывески/пути | Требует исследования |
| Место с подтверждённым тегом «Затерянный» | Как минимум требует исследования; сам тег не означает секрет, требующий особого взаимодействия |
| Скрытый вход с уликой и способом взаимодействия | Секрет: исследование даёт улику; само место — после взаимодействия |
| Башня на открытом холме с явно заданной видимостью | Заметный ориентир; ближайшее логово не наследует её видимость |
| «Таверна» без сведений о дороге/укрытии | Не выдавать предположение за факт; unknown скрыт в просмотре |
| Тег «скрытый» против явно открытого положения; нет однозначной трактовки | Не делать автоматическое раскрытие; сохранить противоречие для редактирования |

Слово «опасный» не определяет обнаружение: опасность может быть заметной или скрытой. Лес не делает секретом любое место, а дорога не отменяет явную маскировку. Нужна проверенная небольшая таблица семантики фактически используемых тегов до разработки; все400литературных строк не считать готовыми триггерами. Смена языка не меняет результат классификации, RNG карты не расходуется от открытия карточки.

## Представление и совместимость

- В просмотре не показывать unknown/null/пустые сведения и «Не определена/Не задана». Не превращать неизвестное в обычное. В редактировании состояние неизвестности доступно явно.
- «Поверхность» и select суша/озеро/море видны только при редактировании. В просмотре остаются сами карта, имя озера/моря и содержательный контент.
- Броски — исключение: доступное действие броска/переброса показывается даже до первого результата, без фиктивного выпавшего числа.
- Условия обнаружения показывать коротко, когда они известны и полезны: «Заметна с дороги», «Нужно исследование», «Секрет · …»; не повторять ничего не обоснованное passage.
- Не добавлять Source/страницы/описание алгоритма в карточку. Причины/происхождение auto/manual доступны редактору, не постоянный справочник.
- Авторские значения существующих карт и улику сохранять; отсутствие ключа в старом сохранении не доказывает normal. Авто-классификация новых мест и предложение пересчёта старых различаются: без молчаливой перезаписи авторского материала. Версия политики фиксируется; миграция и точный schema delta должны быть уточнены до developer_ready.
- Переопределения входят в существующие документ/history/save/load; undo возвращает значение и его происхождение. E7/E8 сохраняют прежнее различие свойств гекса и перемещаемого POI.

## Приёмка будущей реализации

1. Равнина без особых свойств: обычная проходимость не занимает строку; неизвестный объект не получает заглушку. В редактировании значения доступны.
2. Лес по умолчанию труднопроходим; горный/болотный участок опасен с короткой причиной и сохранённой трудностью; ручная обычная тропа не делает весь горный гекс безопасным.
3. PF2-подлесок может оставаться особо трудным и колючим; MB-барьер остаётся непроходимой гранью. Общая карточка не уничтожает эти сведения.
4. Таверна на дороге и лесное логово получают разные обоснованные условия обнаружения. Тег «Затерянный» переводит таверну из проходного обнаружения, но не выдумывает секрет/улику.
5. Авторское обнаружение/проходимость важнее авто; смена языка/zoom/открытие панели не меняют классификацию и случайные потоки.
6. Секрет, улика и взаимодействие различимы; нет автоматического раскрытия игрокам или добавленной проверки поиска для всех игр.
7. Сохранение/загрузка и undo/redo сохраняют исходные значения, причины, ручные исключения и карту. Старое unknown не заменяется ordinary незаметно.
8. Desktop и390px: содержательная карточка без Surface/unknown; редактирование содержит Surface и явное unknown; действие первого броска остаётся.
