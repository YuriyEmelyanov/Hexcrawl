# HX-BL-064 · Морской старт и продолжение карты Classic

Черновик D1 · 24 ноября 2026 года · Первый выпуск

Мастер может начать пустую карту Classic в открытом море в масштабе 5–6 миль и продолжать построение через доступные пустые гексы на внешней границе акватории, даже когда рядом нет суши.

## Требования

1. На пустой карте мастер может выбрать морской старт и стартовый гекс средствами обычного интерфейса. Выбранный гекс входит в построенную акваторию. Вариант выбора старта, параметры первого участка и значения по умолчанию уточнить на интервью.
2. При выборе следующего гекса морской участок примыкает к существующей акватории и включает выбранный гекс. Ранее построенные гексы и объекты сохраняются, новая граница предлагает доступные точки для дальнейшего расширения. Правила определения внешней морской границы и выбора параметров участка уточнить на интервью.
3. JSON сохраняет морские гексы, их координаты и доступные точки роста. После загрузки мастер может продолжить карту с той же границы. Undo/Redo восстанавливают карту и точки роста на соответствующем шаге. PNG отображает построенную акваторию. Точки роста доступны в редакторе.
4. Прежний сухопутный старт доступен. Озеро внутри карты открывается как озеро.

## Приёмка

| Сценарий | Ожидаемый результат |
|---|---|
| В Classic на пустой карте выбрать морской старт и стартовый гекс. | Гекс входит в построенную акваторию, виден край для расширения. |
| Дважды подряд продолжить карту с внешнего морского края, включая ход из области без соседней суши. | На каждом шаге выбранный гекс входит в акваторию, прежние гексы сохраняются и доступны следующие точки роста. |
| После второго продолжения сохранить JSON, открыть его в новом сеансе и выбрать точку роста. | До нового расширения совпадают морские клетки, объекты при их наличии и координаты точек роста. Выбранная точка позволяет продолжить карту. |
| В исходном сеансе отменить и повторить второе продолжение. Выгрузить PNG. | Состояние карты и набор точек роста совпадают с соответствующими шагами. На PNG отображаются оба построенных участка моря. |
| Начать обычную сухопутную карту и открыть контрольную карту с озером. | Сухопутный старт работает, щелчок по озеру открывает его карточку. |
