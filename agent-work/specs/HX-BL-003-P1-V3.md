Native данные сравнивать внутри страницы либо передавать типизированным форматом: Map со всеми key/value, Set со всеми значениями, различая undefined/null, массивы и числа. 1. Штатный import замороженного AFTER → S0, экспорт J0 через JSON/download.saveAs; записать native D0,RNG0,U0,R0. Import уже является транзакцией; не ожидать пустой undo без основания.

Штатный отказ сохраняется, но положительная continuation-часть incomplete; другой anchor и повтор запрещены.
