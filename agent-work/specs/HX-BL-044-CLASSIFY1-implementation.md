## Документ и совместимость

Необязательный map.classification/version1 содержит difficultyByHex и discoveryByPoi. Значения difficulty: unknown/normal/difficult/dangerous. Discovery: unknown/passage/exploration/interaction; auto допустим при сохраняемой авторской улике. Автоумолчания выводятся из контекста без записи/расхода RNG. Auto-сброс снимает ручное значение; unknown явно подавляет вывод.

Общий слой применяется во всех режимах, без включения Knave на обычной карте. Сохранённые Knave значения используются как прежние ручные исключения; изменение одного поля не меняет остальные. Критично: clue-only правка секрета сохраняет interaction. Повторный выбор текущего значения не мигрирует данные и не создаёт историю. При действительном изменении заменяемое legacy поле снимается атомарно, чтобы оно не возникло повторно из-за скрытого fallback.

Непустые общие отметки экспортируются в JSONv11; при полном отсутствии общих отметок — v10. Пустой общий слой после удаления/воды/checkpoint/импорта нормализуется при экспорте, а не заставляет v11. v2..10 не получают сохранённых отметок при открытии. Новая программа читает v11; прежняяv10 не обязана читать его. Unknown версия/значение/владелец, null/массив/лишний ключ и interaction без непустой trim-улики до512UTF16 отвергаются до изменения карты/истории/RNG.

Общие свойства включены в backup/capture/restore/copy/import/export/history; E7/E8 меняют адрес POI, а проходимость остаётся по координатам. Потери при воде/удалении включены в штатное подтверждение; checkpoint сохраняет живые ручные отметки и подтверждает потерю исчезнувших. Undo/Redo возвращают точный принятый документ. Редактор использует уже существующие dirty/stale/composition/exit gates. Копия специфического для игры движка движения/бросков не создаётся.
