# SEA-UI1 — предложение интерфейса морей

Спецификация: [SEA-1.0](../../specs/HX-BL-023-E8-N-SEA.md).
Источник: опубликованный SHA7547a67bbcfb621f1e7c7189518583842ccb055a, tree79b69059c70eed7430bcda93db5d72a6097695d3. Исследованный локальный4053f30 имеет идентичное дерево.

Это макет на реальной панели и CSS текущего интерфейса. Он не исполняет Sea reconciler/импортv9/сохранение. RU выбрано явно для показа; реализация сохраняет EN startup и проверяет обе локали. Нет нового постоянного пояснения о центральной точке.

При расширении имя сохраняется. При разделении один выбранный потомок наследует имя. При слиянии выбрано сохраняемое море, потери авторских имён подтверждаются отдельно, до этого Применить недоступно.

Показ владельцу в текущем чате06.11.2026: merge-1500.png и split-390.png, явно как предложение. Отсутствие ответа не блокирует разработку. Фактические интерфейс/до-после и проверки точного будущегоSHA обязательны перед выпуском.

Метод: render-preview.mjs запускает локальный Vite с текущим dist, импортирует fixture.json, выбирает морской гекс, снимает фактическую панель и заменяет её DOM для предложения. PNG обрезаны до панели; ширина в имени — viewport. Требуются Node24, Playwright, Chromium и идентичный dist. В скрипте пути окружения нужно задать под свой checkout. 12 предложенных компоновок без горизонтального overflow/page errors, см. manifest.json. Проверено визуально merge desktop/split narrow. Это временная диагностика макета, не постоянные тесты продукта, не доказательство поведения Sea. Экран320/EN/IME/touch/AT и региональная строка Вода проверяются на реализации по AC10.
