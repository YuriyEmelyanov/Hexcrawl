# HX-BL-041 — статус UI-материалов

Текущий договор UI: компактное inline-дополнение существующей карточки, для всех объектов/тегов обоих этапов. Основание — прямые поправки владельца03.11.2026 и скриншот1000018710.jpg.

## Действующие материалы
- HX-BL-041-inline-v2.0.html — предложение на основе текущей карточки. Параметр URL object выбирает пример: monument (по умолчанию), myth, sanctum, dwelling, hazard, curse, ruin, holding, throne, lake, river, region. Отдельного экранного переключателя нет.
- HX-BL-041-inline-desktop-v2.0.svg и HX-BL-041-inline-mobile-v2.0.svg — компактные векторные схемы. HTML является основным референсом сохранения native emoji и точных правил переноса.
- TAGS spec1.1 и MYTHS spec1.2 — общий UI-COMMON-01..06 и последнее ограничение1em–1.15em.

Кубы16–18px при16px тексте, цифра внутри — результат. В строке нет d6/d12/страниц/версий/инструкций. В независимых столбцах каждый куб рядом со своим текстом; в составном индексе оба перед единым результатом. Никаких новых карточек/тулбаров или расширения текущей типографики и отступов.

## Проверки и пределы
Конечный HTML — статическое предложение12вариантов существующей карточки, без полного каталога и без рабочего переброса. Нативные кнопки показывают размеры/семантику, поведение бросков задают спецификации. Функциональная реализация не заявляется. Браузерная проверка вёрстки не выполнена: Chromium в среде отсутствует.

SVG отрисованы локально для просмотра, но локальная система не содержит emoji-шрифта: PNG изInkscape могут потерять исходныеemoji. Не использовать такиеPNG как доказательство сохранности иконок. Исходныеemoji сохранены вHTML иSVG; нативный браузер использует свой системныйemoji-шрифт. Само приложение/main не менялись.
