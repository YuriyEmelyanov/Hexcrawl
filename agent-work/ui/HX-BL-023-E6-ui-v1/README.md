# E6 UI-v1 — предложение интерфейса

Основа: main27b230fc5fc5ac2f998141626fa091e1085d7a47. Спецификация: [E6-1.0](../../specs/HX-BL-023-E6.md).

Макеты подготовлены и показаны в текущем чате: desktop1500 mask и390 preview, явно как предложение. Они не являются реализацией E6 или разрешением выпуска.

Публикация PNG в публичный GitHub blocked: автоматическая проверка отклонила current-1500.png как неосмотренный; после фактического осмотра повторно отклонила тот же payload, потребовав явного разрешения владельца на публикацию конкретного изображения. Другие попытки передачи PNG остановлены; не обходим отказ другим каналом/кодированием/обрезкой. Никакой полный набор PNG/галерея здесь не объявляется сохранённым. Конкретный комплект14PNG и HTML-галерея подготовлены локально и предъявляются владельцу для разрешения внешней передачи; manifest содержит имена и SHA256.

Исходник preview.mjs воспроизводит предложение на текущем интерфейсе; задайте HEXCRAWL_SOURCE_DIR к checkout27b230f, HEXCRAWL_PREVIEW_DIR к временному выводу и CHROMIUM_EXECUTABLE_PATH к установленному браузеру. Это временная диагностика, не постоянный тест продукта. Карта — публичная синтетическая test/fixtures/terrain-display-map.json из репозитория; UI scale изменён только для показа.

Состояния current/read/edit/mask/preview/error/after ×1500/390. Рендер дополнительно проверен на320 без горизонтального переполнения. Данные/имена/конфликтные примеры иллюстративны и не доказывают фактический дефект fixture.

Основной вид: текущая общая информационная панель и прокрутка, те же16px/интервалы. В Edit строка воды выбирает Суша/Озеро/Море; маска клеток остаётся временной; Enter/Done завершает, Esc сбрасывает. Именованный preview запрашивает явное удаление POI/имён/тегов, notes сохраняет. Ошибка объясняет конкретный водоём/устье и не меняет документ.

Просмотр/ответ на макет не блокирует утверждённую разработку. Внешняя передача изображений потребует разрешения, затребованного автоматической проверкой; это не новый блокирующий этап продуктового дизайна. Разработчик сохраняет фактическое UI/evidence точного SHA и показывает результат до выпуска.
