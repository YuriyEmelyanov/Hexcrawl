# S02-C03 · Версии схемы, миграции и продолжение карты

Приёмка L1 в Classic на PR511. Максимум 20 × 1000 / 2025. Все пять правил приняты полностью.

| Правило | Условие | Вес, % |
|---|---|---:|
| SAVE-01 | Поддерживаемое старое сохранение открывается без ручной конвертации | 20 |
| SAVE-02 | Сохраняются состав регионов, их ID и геометрия | 25 |
| SAVE-03 | Отсутствующие в старом формате поля обрабатываются при открытии | 15 |
| SAVE-04 | После открытия мастер может продолжить карту и повторно открыть экспорт | 25 |
| SAVE-05 | Версии схемы и генератора проверяются отдельно. Отказ при несовместимости сохраняет текущую карту | 15 |

Десять сохранений (8 версии 2, по одному версий 3 и 10) открылись, сохранили геометрию и позволили добавить регион. Повторное открытие экспорта сохранило данные. Прошли 48 тестов saveSafety и отдельный тест повторного открытия версии 16 после правки реки. Известный случай добавления озёрного гекса в точки роста при импорте учтён в REG-07.
