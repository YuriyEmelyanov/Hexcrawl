Сводка очищена 22.10.2026 без изменения генератора. Нормативные требования:
[road-model.md](road-model.md). Полный аудит 23.09.2026, baseline
`28245b23824745fa34c2d124991ee211ce259c4b`, метод, все ROAD-AUD/ROAD-EX ID,
исходные сценарии и прежний план сохранены
[в историческом отчёте](archive/2026-10-22/road-model-audit.md).
Он не является списком текущих неисправностей или указанием повторить исправления.

Первоначальные подозрения о пустых внутренних окончаниях и недоборе диких троп
не были подтверждены в той серии. Глобальная связность всех освоенных областей,
матрица переправ и произвольные старые сохранения не покрыты целиком.
Новая задача требует воспроизведения на актуальном baseline; прошлые успешные
прогоны не доказывают корректность любой карты.

Исходные [наблюдения](audit/road-model-observations.jsonl) и
[результаты после исправления](audit/road-model-after.jsonl) сохраняются.
Seed серии относится к LCG тестового harness, а не к пользовательскому seed карты.
Метод: настоящий `safelyAddRegionToMap` с тестовым React storage, без подмены
алгоритмов; seeds 7/42/103, освоенная/дикая местность, материк/побережье,
по 6 расширений и проверка отмены после каждого. DOM этим не проверяется.

Добавлены 7 регрессионных тестов в `test/roadContinuation.test.mjs`.
Первоначально воспроизведены четыре сценария закрытых выходов, ложное

После достройки все эти тесты проходят, включая старые участки, JSON и отмену.

Повтор исходных 72 генераций: 0 закрытых/внутренних тупиков, 0 недоборов
в обычных освоенных регионах, 0 изменений старых участков, 0 ошибок отмены.
24 аварийных урочища; их числовой минимум остаётся открытым вопросом.
Результаты: `audit/road-model-after.jsonl`. Полный `npm run check`:
91 тест, TypeScript и production-сборка прошли.

Вывод ограничен проверенными сценариями. Глобальная связность всех освоенных
регионов и невозможность недобора при любой геометрии этим не доказаны.

## Устранение преждевременного выбора входа (24.09.2026)

Карта пользователя сохранена в `test/fixtures/road-entry-zigzags.json`.
`test/roadEntry.test.mjs` сначала воспроизвёл лишний участок в каждом из двух
маршрутов к тому же выходу: регион 3 — 5 вместо 4 участков, регион 4 — 4 вместо 3.
После удаления выбора входа полные маршруты имеют 4 и 3 участка соответственно;
число пересечений рек остаётся 1 и 0. Старые участки не изменяются.
Дополнительно проверены прямое подключение освоенного региона и запрет
соединительного участка целиком в старой территории.

`npm run check`: 95 тестов, TypeScript и сборка прошли. Существующие тесты
настоящего обработчика генерации проверяют расширение, старые участки,
сохранение и отмену. Локальный `test:browser` не запустился: Chromium отсутствует;
браузерная проверка обязательна в GitHub Actions перед публикацией.
