# Случайность и формат JSON v3 (ADR HX-BL-030)

24.10.2026. Внутри утверждённой HX-BL-030; [спецификация 1.0](HX-BL-030.md).

Контекст: общий Math.random не позволяет повторить продолжение после загрузки
или отмены. Топонимы и отрисовка уже имеют независимые механизмы.

Решение: `src/worldRandom.ts`, версия генератора `regions-2026-10-24-rng.1`,
алгоритм `mulberry32-v1`. Документ содержит masterSeed uint32 и два независимых
uint32 состояния geography/poi. Сложение и умножение выполняются по модулю 2^32;
ответ draw — число [0,1). geography начинается с seed, poi с seed XOR 0x9E3779B9.
Seed имён: seed XOR 0x85EBCA6B. Формулы закреплены независимыми Python векторами.
Это воспроизводимость, не криптографическая случайность.

Потоки передаются явно через аргументы помощников. Совместимые default callbacks
остаются для старых изолированных API-потребителей; production не использует их,
что проверяется guard тестом. Ref принадлежит одному App/документу и живёт между
тиками королевства; копии состояния входят в историю и резервные снимки. Глобальная
подмена Math.random и общий активный генератор не используются.

Экспорт v3 требует верхнее generation. Импорт v2 без generation детерминированно
получает seed существующих топонимов или legacyToponymSeed; принятые объекты
сохраняются. v2 с generation проходит ту же строгую проверку. v3 требует все поля,
только текущие generatorVersion/rngVersion поддержаны. Неизвестные версии
отклоняются атомарно. v3 не читается старым клиентом; архивируйте исходный v2,
если он необходим для работы в старой версии. История сеанса не экспортируется.

Последствия: старая последовательность Math.random невосстановима; одинаковые
версии, seed, исходная карта, параметры и действия дают одинаковое продолжение.
Seed в панели меняется на пустом мире. Reset создаёт новый seed один раз,
undo/redo точно возвращают предыдущий/новый снимок. Regenerate восстанавливает
базовую географию, но использует текущие потоки для нового варианта; undo и
повтор regenerate воспроизводят его. Отказ без commit не расходует RNG, поэтому
повтор без изменения условий может повторить тот же отказ. Успешное урочище
сохраняет расход всех внутренних попыток. Распределения и RIV/ROAD не менялись.

Альтернативы: хранить только seed недостаточно для продолжения; глобальная
подмена Math.random смешивает независимые документы/асинхронные действия.
Откат до выпуска — закрытие PR; после отдельно разрешённого выпуска — reviewed
revert пакета. Для v3 при откате приложения нужен новый совместимый клиент,
молчаливое удаление generation не является безопасной обратной миграцией.
