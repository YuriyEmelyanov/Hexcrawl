# Отложенная отрисовка королевства

Во время kingdomJob все три режима показывают только базовую заливку и сетку
гексов. Подробные слои (тайлы, эмодзи, лес, естественные озёра, реки, дороги,
POI, препятствия и границы королевства) появляются после завершения построения.
Геометрия лесов и озёр не вычисляется на промежуточных шагах.
Готовая базовая карта получает кадр перед подробной отрисовкой.
PNG недоступен до готовности полного изображения. JSON содержит завершённую
географию и не зависит от этого этапа. Ошибка построения восстанавливает
предыдущую карту, затем её графику. Правила генерации не изменяются.

Поиск ближайших точек для лесных перемычек использует пространственный индекс
с ячейкой 0.15R. Индекс содержит исходные точки, сохраняет исходный порядок при
равном расстоянии и не меняет формы, размеры, цвета, фильтры или стволы.
На 20 картах по 192 лесных гекса старая и новая геометрия полностью совпали.
Локальный суммарный расчёт: 55.277 с до, 6.880 с после (8.03 раза).
Дополнительный индекс кромки по областям 1.15R и сужение окна до текущего
лучшего расстояния сохранили точный результат на тех же 20 картах.
Повторный локальный расчёт: 6.053 с для первого индекса, 3.111 с для итогового
(дополнительное ускорение 1.95 раза). Эти локальные измерения относятся к JS
геометрии, а не ко всей отрисовке. Регрессионные контрольные суммы закрепляют
три больших композиции.

## Браузерный замер

scripts/benchmark-kingdom.mjs сравнивает текущую сборку и dist-baseline на
одном сервере в Chromium. Один прогрев исключается для каждого режима.
10 одинаковых seed, 30 измерений, порядок режимов чередуется.
Таймер браузера отдельно считает построение до завершённой базовой карты
и подробную отрисовку до двух animation frames после полного SVG commit.
Последний этап включает запланированный кадр базовой карты.
Ассеты и шрифты загружены заранее. Без CPU throttling, viewport 1500x1000.

Только в сборках замера источники случайности фиксируются, аналитика отключается,
а подсказка выбора кандидата не расходует RNG. Исходники продукта не меняются
этой подготовкой. Проверяется совпадение итоговых карт для всех трёх режимов.

Для каждого цветного королевства старая версия получает тот же JSON.
Замер старой отрисовки начинается с перехода Эмодзи → Цвет.
Сравниваются полный SVG и PNG снимок карты до/после.
Серия прекращается при отличии изображения или географии.
Результат и отдельные прогоны сохраняются в reports/kingdom-benchmark.json.
Результаты относятся к проверочному серверу, а не телефону пользователя.

Проверки: npm run check, npm run test:browser, раздельный браузерный benchmark.
