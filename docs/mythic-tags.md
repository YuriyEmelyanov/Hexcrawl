# Универсальные теги и Mythic Bastionland

Реализация HX-BL-041 объединяет TAGS1.1 и MYTHS1.2 из agent-operations. Действует прямое разрешение владельца03.11.2026; main/публикация требуют отдельного решения. UI-поправки владельца приоритетны над ранними макетами.

## Формат и команды

`src/tags/engine.ts` — независимые от географии определения и команды. `TagState.schemaVersion=1` содержит instances и rollCounters. Экземпляр хранит owner, definitionId/version, resolver, revision, sides, values (массив фактических кубов на слот), entryIds, texts по языкам и отдельные overrides. Имена физических полей отличаются от примера спецификации; сохраняются все требуемые значения и семантика. Ключ владельца стабилен: region/river/lake ID либо составной ключ regionId+hexKey POI. Имя объекта не используется как ID.

`independent` разрешает отдельный столбец каждого слота; `product` использует упорядоченную пару d6×d12 для единой записи72. Поддерживаются одиночный куб и сумма одинаковых кубов слота. Нет универсального парсера формул или редактора таблиц. Изменение одного куба составной пары пересчитывает весь текст, сохраняя второй куб.

RNG тегов — отдельный детерминированный домен по masterSeed/owner/definition/version/slot/counter. Хеширование32бит и rejection sampling устраняют modulo bias; ambient Math.random не используется. Порядок открытия карточек и броски других владельцев не расходуют этот поток. Повтор числа допустим. Счётчики восстанавливаются историей вместе с результатом.

JSONэкспорт теперь v6; v2–v5 читаются без автоматических бросков. map.tags сохраняется во всех снимках карты, транзакциях, backups и checkpoints. Валидатор проверяет ссылки владельцев, дубликаты, диапазоны/размеры, счётчики, версии и совпадение известных entryId/snapshot. Будущие словари сохраняются как read-only snapshot; будущий TagState отвергается атомарно. Неизвестные тексты отображаются как обычный Reactтекст. Пределы:64тега/владелец,8слотов,8языков,256кодовыхточек на перевод/override.

## MB-пакет

`mythic.ts` задаёт policy существующих типов карты; ядро не знает о MB. `mythicData.ts` содержит13 таблиц со стр22–23,72мифа,432подсказки и72названия провидцев. Источник — предоставленные пользователем русские правила и английский Quickstart; исходныеPDF не добавляются.

Автоматические теги новых объектов: у Престола и всех подтипов Удела — Удел/Подворье/Замок; у мифа — имя; у6типов ориентиров — описание, у Святилища также отдельная пара Провидца. У старых карт ничего не генерируется при открытии: в существующем режиме редактирования есть компактная команда заполнения недостающих тегов. Она не перебрасывает существующие.

По нажатию: Земля/Флора/Фауна региона; Вода озера или реки; Еда/Товары/Роскошь удела; Особенность у Жилища/Монумента/Опасности/Руин, Чудо у Монумента/Святилища, Иномирье у Проклятия. При смене типа POI несовместимые теги остаются неактивными; удаление владельца удаляет его теги и счётчики с отменой.

Провидец содержит только название и кубы, без статов/биографии/способностей. Руины не имеют механической ссылки на миф, фильтра по активным мифам или каскадных изменений. Тег не изменяет географию или квоты. Правители, нижние подсказки рыцарей, влияние мифов на географию, карта игроков и игровые процедуры вне этого PR.

Для72мифов/провидцев и432описаний заполнены обе локали. Первые12пар сохраняют прежний английский Quickstart; остальные переведены из предоставленного RU и сверены по английскому оригиналу2025года. Имена всех72мифов сопоставлены с английским указателем27. EN не подставляет русский текст при отсутствии перевода. Точное происхождение и покрытие сверки — [реестр локализации](myth-material-localization.json). В приложении хранится индекс результата; номера страниц не выводятся.

Старые русские снимки принимаются по явно закреплённым `legacyTables` того же словаря/версии/entryId; произвольный изменённый текст по-прежнему отвергается. Английская подпись старой записи разрешается только для совместимой сохранённой пары кубов без исправления JSON, переброса или изменения счётчиков. Авторский override текущей локали имеет приоритет. Неизвестная версия без EN показывает английское сообщение о недоступном переводе. В EN редактор имени показывает текущую локаль; существующее RU-имя сохраняется, при создании нового имени отсутствующая пара инициализируется введённым именем. Явная очистка поля EN удаляет всю необязательную авторскую пару; обязательные имена не могут стать пустыми. Для изменения русского имени нужен переход в RU.

## UI и проверки

Единый `TagRow` добавляется в существующую строку владельца. Куб1.1em(около17.6pxпри16pxтексте), промежутки2px. Внутри — только выпавшее число; форма различает d6/d12. Тип, назначение и число доступны через aria-label. Видимых d6/d12, страниц, инструкций, новых карточек и изменения отступов текущих карточек нет. Нажатие куба создаёт одну транзакцию,350мсанимация только отображает её; reduced-motion отключает вращение. Повторные клики того же тега350мс подавляются общим lock по стабильному ключу. Результат можно редактировать в существующем editmode; override не подменяет исходный snapshot.

Проверки: расширенный существующий генерационный сценарий контролирует автотеги всех POI;4новых логических Nodeсценария защищают отдельный/составной resolver, импорт, историю и RNG/двойнойклик. Существующие v5контрактные проверки обновлены до текущего v6экспорта. Новый browserсценарий проверяет legacy/fill/reroll/UndoRedo/ширины1500/390/320/клавиатуру/reduced-motion/roundtrip и сохраняет фактические скриншоты в reports/HX-BL-041. CI их прикладывает отдельно. Это не evidence успеха: точные результаты и ограничения фиксируются в developer handoff на SHA.

Score1.2: S08-C04/S09-C04/S07-C05 — кандидаты влияния, исходное значение и delta unknown. Один новый пакет MB не доказывает поддержку других НРИ/SDK. Начисление баллов и независимая приёмка вне полномочий программиста.

## Исправления независимой проверки HX041-SAVE-01 / HX041-R1

Ограничения64тега на владельца и8языков действуют не только при импорте: команды проверяют подготовленный клон до возврата результата. Переполнение отменяет весь roll/edit/fill/automatic reconciliation, не удаляя допустимые неизвестные snapshots и не расходуя сохранённые счётчики. UI сообщает причину отказа в существующем поле ошибки; заполнение недостающего набора обрабатывает отказ целиком. Уже существующий тег можно перебрасывать при заполненной ёмкости; существующий перевод можно править при8языках.

Невидимое доступное имя куба содержит локализованное назначение слота, текущий отображаемый текст с учётом ручной правки, тип и выпавшее значение. Поэтому равные независимыеd12 различимы для экранного диктора. Размеры и плотность видимого интерфейса не меняются.
