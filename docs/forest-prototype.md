# Прототип лесного слоя — только рабочая ветка

Образец проходит через импорт JSON, штатный App и экспорт PNG. Это не отдельная
иллюстрация: `ForestLayer` находится в режиме «Цвет» над фоновой подложкой.
Основной сайт до визуального согласования не обновлять.

- Все леса пока относятся к плотному лесу, все шесть редколесий — к разреженному.
- Общие рёбра плотных лесных гексов удаляются; оставшиеся рёбра собираются в
  контуры. Крупные выемки и выступы дополнены мелкими округлыми кронами.
- Внутренние контуры объединяются через evenodd: поляны и озёра остаются открытыми.
- Кроны `#789F46`, опушка `#2F3D25`; короткие стволы и тень снизу.
- Каждый гекс редколесья содержит 4–5 отдельных рощ, не переходящих в соседний.
  Их координаты зависят от q,r и seed. Дополнительный clip по гексу ограничивает
  штрихи и тени. Сохранение и загрузка не переставляют рощи.
- Рельеф, породы и мёртвый лес пока не различаются графически. Генерация географии,
  режимы Тайлы/Эмоджи и данные сохранений не меняются.
- Прототип: поворот теней вместе с картой пока требует отдельной доработки.

`test/fixtures/forest-review-map.json`: плотный массив со всех сторон окружён
нелесной местностью или редколесьем; отдельно размещены гексы редколесья.
`terrain-color.smoke.mjs` экспортирует PNG из реального интерфейса и сохраняет
в артефакт CI `forest-generator-sample.png`, вариант с поляной и JSON.

## Локальный образец для визуального согласования

Из-за ошибки проверки старого цвета подложки и последующего сбоя обновления PR
браузерный экспорт этой версии не подтверждён. `scripts/render-forest-review.mjs`
рендерит настоящий компонент App через React DOM Server, подставляя только
начальное состояние из тестовой карты. Геометрия и JSX карты не заменяются.
SVG сохраняется отдельно; PNG растеризован Inkscape. Для SVG 1.1 `transparent`
заменён на `none`, rgba-stroke разложен на RGB и opacity, href — на xlink:href.
Это визуальный образец реального рендера App, но не свидетельство проверки
браузерной кнопки экспорта. Основной сайт не обновлён.
