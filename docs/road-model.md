# Модель дорог и троп

Версия 0.1, 23.09.2026. Источник требований — обсуждение с владельцем проекта.
Это целевые правила. Наличие правила в документе не означает, что генератор уже
его выполняет. Проверка реализации: [road-model-audit.md](road-model-audit.md).

## Согласованные правила

| ID | Правило |
| --- | --- |
| ROAD-01 | Карта строится по регионам. Новый регион сразу получает законченную дорожную сеть. |
| ROAD-02 | При расширении карты нельзя добавлять, удалять или перекладывать участки внутри ранее созданных регионов. Соединительный участок через общую границу создаётся вместе с новым регионом. |
| ROAD-03 | Дорога может заканчиваться на крайнем гексе региона, обращённом к ещё не созданной территории. Точка интереса на этом гексе не обязательна. |
| ROAD-04 | Заранее закреплять направление продолжения или конкретный будущий соседний регион не требуется. Продолжение выбирается при генерации соседа. |
| ROAD-05 | При освоении территории за выходом дорога продолжается в новом регионе. Окончание без назначения и без возможности дальнейшего продолжения — нарушение. |
| ROAD-06 | Дороги связывают освоенные регионы. Проходные дороги через дикие регионы допустимы и нужны, в том числе без ранее входящей дороги. Сохраняются существующие условия их создания по размеру региона. |
| ROAD-07 | Сохраняется существующее обязательное количество дорог и троп по типу и размеру региона. Это минимум, а не предел: больше допустимо, меньше — нет. Новые числовые нормы этим документом не вводятся. |
| ROAD-08 | Внутри региона путь имеет назначение: поселение, точку интереса или соединение с другим путём. Случайный пустой внутренний гекс не является назначением. |
| ROAD-09 | Существующие предпочтения выбора маршрута сохраняются. Новые штрафы за высоты, горы, длину и пересечения этим документом не вводятся. |
| ROAD-10 | Пересечение пути с рекой должно иметь соответствующий тип переправы. Изменение правил выбора моста, брода и переправы требует отдельного описания; в этой версии они сохраняются. |

## Как проверять связность

Дорожная сеть — граф гексов, соединённых фактически созданными участками дорог
и троп. Соседство двух гексов с дорогами само по себе не создаёт соединение.
Это способ проверки ROAD-05/06/08, а не дополнительное ограничение маршрута.

Проверяются геометрические участки, а не только идентификаторы `Road`:
одна запись может продолжаться в нескольких регионах. Увеличение такой записи
участками в новом регионе не нарушает ROAD-02, если старые участки сохранены.

Выход к неизвестной территории не считается тупиком. После расширения карты
оценивается, остался ли у него свободный выход или появилось реальное продолжение.
Если один выход касается нескольких будущих регионов, достаточно сохранить
возможность продолжения; предварительно назначать одного соседа нельзя.

Не требуется заранее соединять все ещё разрозненные области карты через
непостроенные регионы. Нельзя ради общей связности достраивать старые регионы.

## Примеры для проверки

| ID | Ситуация | Ожидаемый результат |
| --- | --- | --- |
| ROAD-EX-01 | В освоенном регионе нет POI на границе | Выходы дорог к границе всё равно допустимы. |
| ROAD-EX-02 | Дорога заканчивается у ещё неизвестной территории | Допустимый выход, не ошибка. |
| ROAD-EX-03 | Создан сосед за выходом дороги | Продолжение строится в новом регионе; старые участки неизменны. |
| ROAD-EX-04 | Один конец касается нескольких будущих соседей | Направление выбирается при расширении; заранее не фиксируется. |
| ROAD-EX-05 | Крупный дикий регион без входящих дорог | Сохраняется самостоятельная проходная дорога. |
| ROAD-EX-06 | Для соединений требуется превысить обычное число дорог | Превышение разрешено; число не используется как верхний предел. |
| ROAD-EX-07 | Конец в пустом внутреннем гексе, без POI и соединения | Недопустимый тупик. |
| ROAD-EX-08 | Концы двух дорог в соседних гексах без участка между ними | Соединения нет. |
| ROAD-EX-09 | Расширение окружило прежний выход сушей/водой без продолжения | Недопустимый разрыв; сохранение самих старых участков недостаточно. |
| ROAD-EX-10 | Дорога пересекает реку | Существует связанная запись о типе пересечения. |
| ROAD-EX-11 | Отмена последнего региона и загрузка сохранения | Геометрия сети восстанавливается без добавления путей в старые регионы. |

## Что обнаружено в текущем коде, но не является новой нормой

| Ветка | Текущая реализация |
| --- | --- |
| Обычный освоенный регион | `getSettledMainRoadLimit`: 2 дороги; «Большой регион», «Край», «Обширный край» — 3. Число одновременно применяется как минимум и предел. |
| Дикий регион | Самостоятельная проходная дорога допускается для `large_region`, `land`, `vast_land`. Продолжение входящих дорог обрабатывается отдельно. |
| Тропы дикого региона | 1 попытка построения; в трёх крупных категориях — 2. Попытка не равна гарантированному результату. |
| Тропы освоенного региона | Подключение оставшихся POI; фиксированного числового минимума в этой ветке нет. |
| Аварийное урочище | Отдельная процедура подключения POI тропой к соседнему пути; обычный генератор дорог не вызывается. |

Перед изменением числовых норм нужно уточнить применимость минимума к аварийному
урочищу. Нельзя молча назначить ему две дороги по признаку `biomeLandType`, равно
как нельзя объявить его исключением из ROAD-05. Также нельзя считать число
записей `Road` универсальным числом маршрутов: продолжения могут сохранять старый ID.

## Порядок изменений

1. Для каждого нарушения сохранить воспроизводимый пример.
2. Ввести общую проверку результата по ROAD-02/03/05/08, отделив её от выбора маршрута.
3. Исправлять подтверждённые расхождения с проверкой настоящего обработчика генерации.
4. Проверять расширение в разных направлениях, обычные/дикие регионы, урочища,
   побережье, сохранение и отмену. Конечный набор прогонов не доказывает отсутствие всех ошибок.
