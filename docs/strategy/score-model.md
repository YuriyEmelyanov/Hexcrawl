# Score-модель HexCrawl.ru

> **Навигация по редакциям:** ниже сохранена исходная модель 1.0. [Изменения для согласования (20 пунктов)](score-model-changes.md) и [согласованная модель 1.1](score-model-v1.1-proposed.md) учитывают последующее развитие проекта. Модель 1.1 согласована владельцем 22.10.2026 с измерением производительности по числу гексов; использовать её для новой оценки. Исторические баллы 1.0 с её критериями не смешивать.

**Статус:** точная содержательная транскрипция целевой модели из `HexCrawl_Best_Generator_Scorecard_v1.0(1).docx`, версия 1.0. Изменение весов, критериев и условий лидерства требует отдельного согласования владельца продукта.

**Исторический baseline:** оценка 12.07.2026, репозиторий `YuriyEmelyanov/Hexcrawl`, `main @ 832f079`. Приведённые ниже grades и баллы относятся только к этому baseline. Они не являются текущей подтверждённой оценкой продукта. Текущая оценка должна храниться отдельно с актуальным commit и evidence; до повторного аудита она неизвестна.

## Формула и градации

| Grade | Коэффициент | Определение из исходного Scorecard |
| --- | ---: | --- |
| G0 — отсутствует | 0% | Функции нет. |
| G1 — прототип | 25% | Работает только в отдельных демонстрационных случаях. |
| G2 — рабочая функция | 50% | Работает в обычных сценариях, но полная проверка не проведена. |
| G3 — промышленная функция | 75% | Есть автотесты, обработка ошибок и подтверждение пользователями. |
| G4 — лидер рынка | 100% | Выполнен числовой критерий и функция превосходит выбранные аналоги. |

`points = maximum value критерия × коэффициент G0…G4`. Произвольные оценки 60% или 90% запрещены.

Grade повышается только при наличии проверяемого evidence. Баллы не начисляются за планы, обещания, количество функций или повторно за один результат. G4 требует выполнения числового условия критерия и доказанного превосходства в сравнении с релевантными аналогами.

## Условия цели

- Защищаемое звание «лучший в мире»: общий score ≥950/1000, каждый из десяти шагов ≥80%, шаг 10 ≥60/70, отсутствие критических дефектов карты, сохранений и кампании, внешние benchmark и слепое исследование мастеров.
- Полная цель 1000/1000: все 50 критериев имеют G4 с доказательствами.
- В исходном документе локальный gate шага 10 равен 56/70 (80%); для глобального условия лидерства действует более строгий порог 60/70. Это различие не меняет веса и формулу модели.

## Проверка транскрипции

- Критериев: 50.
- Сумма максимальных весов: 1000.
- Сумма исторических баллов: 262,5.
- Идентификаторы `Sxx-Cxx` добавлены для устойчивых ссылок в задачах; они не изменяют содержимое, порядок и веса критериев.
- Исторические фактические утверждения (например число биомов, наличие функций и структура кода) не переносить в актуальный baseline без проверки.
