- «След Тигрейн», WWN, Mythic Bastionland и Dolmenwood Maps Book изучены выборочно по связанным разделам. Книга карт Dolmenwood не равна Campaign Book. Упомянутый Handbook Group Archetypes Toolkit не найден по точному названию; Ironsworn Delve/Forbidden Lands/Hexroll не были предоставлены для такого аудита.
- Дополнительный HexCrawl_ru.pdf от17.09 не дал читаемого содержимого в full/pages режиме; его содержимое не использовано. Не утверждать, что этот источник сверён.

main автоматически развёртывает GitHub Pages; последний просмотренный успешный запуск11.10: https://github.com/YuriyEmelyanov/Hexcrawl/actions/runs/38122850089 . Рабочие планы не должны обновлять main.

Открытый PR458 — визуальный прототип леса с явным запретом merge/deploy до проверки владельцем. PR320/201/190/146 содержат старые предложения: перед любым продолжением сверить diff с main; наличие открытого PR не доказывает отсутствие функции.

В Trello проект говорит «следующее действие — добавить Mythic Bastionland», но соответствующая карточка уже в «Готово». Указанные там1–2мин и≥80% успешных генераций — прежние цели MVP, не достигнутые метрики и не критерии G4.

## Порядок очистки без потери требований

1. Для каждого источника перечислить уникальные требования, текущий статус, целевой файл и ссылку происхождения.
2. Перенести недублирующиеся положения, согласовать реальные противоречия с владельцем.
3. Обновить AGENTS/README и индекс активных источников, поставить архивные заголовки/ссылки.
4. Убрать архивы из обязательного чтения и активных вложений проекта; удалять только подтверждённые дубли по согласованному списку. Evidence и отрицательные benchmark сохранять.
5. Проверить ссылки и отсутствие конкурирующих текущих правил. Изменение содержимого/specs — отдельный PR с перечнем before/after; merge только с разрешения.

Удаление вложений и редактирование настроек самого ChatGPT-проекта не подтверждено доступными инструментами. Если такого действия нет, подготовить точный список для владельца; не выдавать приоритет нового файла за фактическое удаление старых вложений.
