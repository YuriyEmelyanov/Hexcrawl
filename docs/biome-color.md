# Режим «Цвет»

Третий режим отображения гексов: Тайлы → Эмоджи → Цвет → Тайлы.
По умолчанию остаются тайлы. Панели настроек нет. Генерация и JSON-данные
карты не меняются. Режим работает для классической карты и Mythic Bastionland.

## Палитра

| Биомы | Цвет |
| --- | --- |
| Все обычные леса и редколесья: лиственные, смешанные, хвойные, равнинные, холмистые, горные | `#acb78b` |
| Открытые равнины и открытые холмы | `#c7c69a` |
| Горы без леса | `#beb5a2` |
| Болото и заболоченный лес | `#a4afa0` |
| Полупустыня | `#d5c397` |
| Все четыре мёртвых леса/редколесья, включая холмы и горы | `#b8b09a` |
| Море и озёра | `#97b6bc` |

Полное соответствие всем 24 биомам задаёт `BIOME_GROUND_COLORS` с проверкой
полноты TypeScript. Высота и густота леса не меняют подложку; голые горы
отличаются как каменистая поверхность. Учитываются ручные изменения биомов.

## Смешивание и сетка

Общий SVG-слой суши сглаживается Gaussian blur с sigma 0.17 радиуса гекса,
примерно четверть ширины гекса по каждую сторону границы. Это единое поле,
включая стыки трёх биомов, без отдельных радиальных градиентов в каждом гексе.
Нормализация альфа-канала сохраняет цвет у внешнего края. Результат обрезается
точным контуром суши: озёра, море и пустые клетки не размываются.

Сетка: тёплый серый `rgba(87,82,66,0.22)`, толщина 0.55 единицы карты.
Кандидаты на генерацию сохраняют существующее выделение. Реки, дороги,
границы королевств, препятствия, выделение и POI лежат поверх подложки.
Растительность/рельеф в этом режиме пока отсутствуют. Поворот и PNG используют
тот же SVG-слой, в том числе фильтр смешивания и встроенный стиль сетки.

## Проверка

`npm run check` — типы, регрессии, сборка. Browser smoke расширен на шесть
комбинаций гексов/POI и PNG режима «Цвет»: сохранение центральных оттенков,
промежуточные цвета с обеих сторон границы и отсутствие затекания в озеро.
